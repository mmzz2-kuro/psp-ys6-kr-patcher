# 087. Ys VI 제어 키 기능 정지 메시지 이미지 탐색 계획

상태: 완료

## 목적

- 제공된 화면의 `制御キーの機能停止を確認……` 메시지 이미지 리소스를 정확히 찾는다.
- 이전 081 조사에서 확인했던 `v100`~`v108` 석상 메시지와 같은 이미지 계열인지 확인한다.
- 같은 이벤트에 사용되는 인접 미번역 메시지를 함께 찾아 전체 번역 범위를 파악한다.
- 기존 082 한글 이미지 패치에서 누락된 이유와 추가 적용 경로를 정리한다.

## 우선 후보

이전 전체 이미지 인벤토리에서 다음 독립 이미지가 확인됐다.

- `v140.dds.z`
- `v141.dds.z`
- `v150.dds.z` ~ `v157.dds.z`

모두 256×64 계열이며 `v100`~`v108`과 유사한 화면 중앙 메시지 형식이므로 우선 대조한다. 후보가 일치하지 않으면 전체 `v*.dds.z` 및 아카이브 내부 복제본으로 범위를 확장한다.

## 조사 절차

1. 기존 이미지 인벤토리의 `v140`, `v141`, `v150`~`v157` 원본 PNG를 시각적으로 확인한다.
2. 제공된 화면 문구와 글자 형태·행 배치·투명 배경을 대조한다.
3. 일치 리소스의 ISO 내부 경로, 크기, 픽셀 형식, 컨테이너 SHA-256을 기록한다.
4. 전체 후보 이미지를 접촉 시트로 출력해 관련 메시지 수를 확인한다.
5. 원본 ISO의 `data/arc/*.bin`에서 동일 이름 또는 동일 payload 복제본을 찾는다.
6. 실행 아카이브 경로, 엔트리 인덱스, flags 및 할당 공간을 기록한다.
7. 기존 추가 이미지 매니페스트와 비교해 등록 여부와 누락 범위를 확인한다.
8. 후속 번역·패치에 필요한 리소스 정의와 GUI 캐시 대상 추가 방식을 제시한다.

## 검증

- 화면 문구와 후보 이미지가 픽셀 형태 및 배치상 일치하는지 확인한다.
- 후보 컨테이너를 압축 해제하고 DXT 이미지를 손상 없이 렌더링한다.
- 독립 원본과 실행 아카이브 복제본의 payload SHA-256을 비교한다.
- 단일 이미지만 찾고 끝내지 않고 동일 번호 계열의 미번역 이미지를 모두 확인한다.
- 기존 `zemes_statue_v100`~`v108` 패치와 중복 또는 충돌하지 않는지 확인한다.

## 산출물

- 일치 리소스 ID와 ISO 내부 경로
- 관련 이미지 전체 목록 및 확인용 미리보기
- 원본 문구, 이미지 크기, 유효 영역과 해시
- 실행 아카이브 복제본 위치
- 기존 패치 누락 원인과 후속 번역 적용 범위
- `docs/result/087-ys6-control-key-message-image-discovery.md`

## 변경 범위

- 필요 시 조사 스크립트를 `tools/scripts`에 추가한다.
- 원본 및 접촉 시트는 추가 이미지 작업공간의 별도 조사 폴더에 둔다.
- 이번 단계에서는 번역 이미지를 제작하거나 매니페스트·ISO 패치를 변경하지 않는다.

## 보존 사항

- 원본 ISO와 기존 패치 ISO를 수정하지 않는다.
- 기존 `zemes_statue` 이미지와 매니페스트 정의를 변경하지 않는다.
- 확인 전 이미지 블록 오프셋이나 실행 복제본 위치를 추정하여 등록하지 않는다.

## 완료 기준

- 제공된 화면의 실제 이미지 리소스를 확정한다.
- 같은 이벤트 계열의 전체 미번역 이미지 수를 파악한다.
- 사용자가 확인할 수 있는 전체 미리보기를 출력한다.
- 다음 한글 이미지 제작 및 ISO 적용에 필요한 경로와 범위를 제시한다.
