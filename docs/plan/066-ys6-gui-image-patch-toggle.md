# 066. Ys VI GUI 이미지 패치 적용 체크박스 계획

상태: 완료

## 목적

- GUI에서 `ys6_option_menu`와 `ys6_additional_images` 패치 적용 여부를 각각
  체크박스로 선택할 수 있게 한다.
- 체크박스 상태가 사전 검증과 실제 ISO 빌드에 동일하게 적용되도록 한다.

## 현재 동작

- 편집 PNG가 존재하면 옵션 메뉴 이미지와 추가 이미지가 사전 검증 및 실제
  빌드에 항상 포함된다.
- GUI에서 이미지 폴더를 여는 기능은 있지만 적용 여부를 선택할 수 없다.
- 통합 빌더는 이미지 작업공간 인수가 `None`이면 해당 이미지 처리를 건너뛸 수
  있으나, GUI와 사용자용 빌더가 이 선택 상태를 전달하지 않는다.

## GUI 변경 계획

1. 패치 빌드 화면에 독립 체크박스 두 개를 추가한다.
   - `옵션 메뉴 이미지 적용`
   - `추가 이미지 적용`
2. 기존 동작과의 호환성을 위해 두 체크박스는 기본적으로 선택된 상태로 둔다.
3. `사전 검증`과 `패치 ISO 만들기`를 누를 때 현재 체크 상태를 작업 스레드에
   전달한다.
4. 빌드 진행 중에는 체크박스도 다른 빌드 버튼과 함께 비활성화한다.
5. 데이터 요약에는 각 이미지 기능의 적용/제외 상태와 적용 대상 PNG 개수를
   표시한다.
6. 이미지 폴더 열기 버튼은 체크 상태와 관계없이 계속 사용할 수 있게 한다.

## 빌더 변경 계획

1. `inspect_inputs`와 `run_build`에 다음 선택값을 추가한다.
   - 옵션 메뉴 이미지 포함 여부
   - 추가 이미지 포함 여부
2. 선택된 기능만 관련 경로·파일을 검사하고 PNG 개수를 계산한다.
3. 선택 해제된 기능은 통합 빌더에 작업공간을 `None`으로 전달한다.
4. 이에 따라 사전 검증과 실제 빌드 양쪽에서 다음 처리를 모두 건너뛴다.
   - 편집 PNG 읽기와 크기/형식 검증
   - 이미지 합성 및 DXT 재압축
   - 컨테이너 크기와 할당 공간 검증
   - 독립 리소스, `init.bin` 내장 이미지 및 런타임 복사본 교체
5. 선택 해제해도 편집 PNG 자체는 삭제하거나 변경하지 않는다.
6. 명령행 사용자도 같은 동작을 선택할 수 있도록 제외 옵션을 추가한다.
   - `--no-option-menu-images`
   - `--no-additional-images`

## 보고서 및 검증 계획

1. 사전 검증 요약과 빌드 매니페스트에 두 기능의 활성화 상태를 기록한다.
2. 네 조합을 확인한다.
   - 둘 다 선택
   - 옵션 메뉴만 선택
   - 추가 이미지만 선택
   - 둘 다 해제
3. 각 조합에서 사전 검증과 실제 빌드의 이미지 개수 및 교체 대상이 일치하는지
   검사한다.
4. 둘 다 해제한 빌드에서 이미지 관련 ISO 교체가 생성되지 않는지 확인한다.
5. 기존 이미지 합성 및 통합 빌더 테스트를 포함한 회귀 테스트를 실행한다.
6. GUI 코드 구문 검사와 사용자용 빌더 명령행 도움말을 확인한다.

## 완료 기준

- 두 체크박스가 독립적으로 동작한다.
- 각 체크 상태가 사전 검증과 실제 패치에 동일하게 적용된다.
- 선택 해제된 이미지 기능은 검증·합성·ISO 교체에서 완전히 제외된다.
- 기본 선택 상태에서는 기존 GUI 빌드 결과와 동일하게 두 이미지 기능이 적용된다.
- 편집 이미지와 원본 ISO는 수정되지 않는다.
