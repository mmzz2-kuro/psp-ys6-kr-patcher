# 094. Ys VI 엔딩 영상 한글 대사·화자명 교정 계획

상태: 완료

## 목적

- 093번에서 추출한 엔딩 영상 대사 15개의 한글 번역을 자연스러운 자막 문장으로 교정한다.
- 일본어로 기록된 `speaker` 값을 프로젝트의 기존 인물명 표기에 맞춘 한글 이름으로 변경한다.
- 후속 영상 합성에서 그대로 사용할 수 있도록 CSV·JSON·검수 자료를 다시 생성한다.

## 대상

- `tools/scripts/ys6_movie_dialogue_timeline.py`
- `tools/patchdata/work/current/093-ending-movie-dialogue-timeline`
- `tools/config/dialogue-translations.json`의 다음 두 레코드 묶음
  - `s_45/s_4519/ending.xso.z`의 대사 인덱스 0~9
  - `s_05/s_0563/ending.xso.z`의 대사 인덱스 0~4

## 화자명 기준

`tools/config/cast-names.json`의 현재 표기를 기준으로 다음과 같이 적용한다.

- `ラーバ` → `라바`
- `ラドック船長` → `라독선장`
- `ドギ` → `도기`
- `ガッシュ` → `가슈`
- `テラ` → `테라`
- `イーシャ` → `이샤`
- `ウル` → `울`
- `オード族長` → `오드족장`
- `オルハ` → `오르하`

## 대사 교정 원칙

- `저 안에아돌이`처럼 명백한 띄어쓰기 오류를 수정한다.
- 말줄임표 끝의 불필요한 ASCII 마침표를 제거한다.
- `오르하여`처럼 호격 조사가 어색한 표현은 `오르하,`처럼 자연스럽게 바꾼다.
- `무슨 일인건가`는 맞춤법과 장면 문맥에 맞게 다듬는다.
- 고유명사 `나피쉬팀의 상자`, `아돌`, `알마`, 인물명은 현재 프로젝트 표기를 유지한다.
- 영상의 문장별 줄 수와 표시 시간을 고려해 지나치게 길어지지 않게 한다.
- 순수 말줄임표 대사도 화면 재현용 데이터이므로 삭제하지 않는다.

## 작업 절차

1. 현재 번역 15개와 일본어 원문을 나란히 검토해 교정안을 확정한다.
2. `dialogue-translations.json`에서는 해당 엔딩 대사 레코드만 수정하고 상태와 참조 키는 유지한다.
3. 타임라인 스크립트의 한글 대사와 화자명을 동일하게 갱신한다.
4. CSV, 통합 JSON, 대표 프레임 및 접촉 시트를 다시 생성한다.
5. 타임라인의 번역이 현재 번역 설정과 모두 일치하는지 검증한다.
6. `/docs/result`에 수행 결과와 최종 교정문을 기록한다.

## 검증

- 두 영상의 총 대사 수가 10개와 5개로 유지되는지 확인한다.
- 프레임 번호, 타임코드 및 PTS가 093번 결과에서 바뀌지 않았는지 확인한다.
- 모든 `speaker`가 한글이며 `cast-names.json`의 표기와 일치하는지 확인한다.
- 15개 번역 참조 SHA-256이 기존 레코드와 동일한지 확인한다.
- 타임라인 번역과 `dialogue-translations.json` 번역이 모두 일치하는지 확인한다.
- 전체 JSON 구문과 스크립트 Python 구문을 검사한다.

## 변경하지 않는 범위

- 원본 PMF, 영상 프레임, 오디오, 인코딩은 변경하지 않는다.
- 한글 자막 합성, PMF 재구성 및 ISO 패치는 수행하지 않는다.
- 엔딩 영상과 무관한 번역 레코드는 수정하지 않는다.

- 설정 파일과 타임라인 산출물 사이에 번역 불일치가 없다.
