# 037. Ys VI 대사 GUI 다중 선택 override 기능 계획

## 목적

`/tools/ys6_dialogue_viewer.py`의 대사 탭에서 한 개 또는 여러 개의 행을 선택하고 `override` 버튼을 누르면 선택한 번역의 상태를 한 번에 `override`로 변경할 수 있게 한다.

## 현재 동작

- 대사 목록은 `ttk.Treeview`로 표시된다.
- 편집 영역의 상태 콤보박스에서 `override`를 고른 뒤 `현재 항목 반영`을 눌러야 한다.
- `현재 항목 반영`은 선택 목록의 첫 번째 행만 처리한다.
- 현재 4,628개 번역이 `draft` 상태이므로 개별 상태 변경은 검수 작업에 불편하다.

## 구현 범위

### 1. 다중 선택 명시

- 대사 목록 `Treeview`에 `selectmode="extended"`를 명시한다.
- 일반 클릭은 한 개, `Ctrl+클릭`은 개별 추가·해제, `Shift+클릭`은 범위 선택 방식으로 사용한다.

### 2. 선택 항목 override 버튼

- 대사 편집 영역에 `선택 항목 override` 버튼을 추가한다.
- 한 행을 선택하면 해당 한 행을 처리한다.
- 여러 행을 선택하면 선택된 모든 행을 처리한다.
- 번역문과 메모는 바꾸지 않고 `status`만 `override`로 변경한다.
- 이미 `override`인 항목은 중복 변경 없이 유지한다.
- 번역문이 비어 있는 항목은 패치 승인 대상으로 삼을 수 없으므로 건너뛰고 수량을 알린다.

### 3. 화면 및 변경 상태 갱신

- 처리한 행의 상태 열을 즉시 `override`로 갱신한다.
- 작업공간을 미저장 변경 상태로 표시한다.
- 선택 상태는 가능한 한 유지한다.
- 상태 필터가 `draft`처럼 현재 결과와 맞지 않게 된 경우 목록을 갱신하고 처리 결과를 상태 표시줄에 보여준다.
- 결과 문구에는 변경 수, 이미 override인 수, 빈 번역으로 건너뛴 수를 표시한다.

### 4. 기존 단일 편집 보존

- 번역문·메모·상태를 직접 수정하는 `현재 항목 반영` 기능은 그대로 유지한다.
- 다중 선택 상태에서 상세 편집 영역은 기존과 같이 첫 번째 선택 항목을 보여준다.
- 배치 override는 상세 편집 영역의 현재 텍스트를 다른 선택 행에 복사하지 않는다.
- `번역 저장`을 눌러야 JSON에 기록되는 현재 저장 정책을 유지한다.

## 검증 계획

실제 번역 작업공간을 직접 바꾸지 않고 GUI 로직을 분리하여 임시 레코드로 검증한다.

1. 단일 draft 선택 시 해당 항목만 override가 된다.
2. 다중 draft 선택 시 선택한 항목이 모두 override가 된다.
3. 이미 override인 항목은 그대로 유지되고 중복 변경 수에 포함되지 않는다.
4. 번역문이 빈 항목은 override되지 않는다.
5. 번역문과 메모 내용은 변경되지 않는다.
6. 선택하지 않은 항목은 변경되지 않는다.
7. Python 구문 검사를 통과한다.
8. GUI를 직접 실행할 때 기본 JSON 로딩과 대사 탭 생성에 오류가 없는지 확인한다.
