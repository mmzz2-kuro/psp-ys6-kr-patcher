# 116. Ys VI SPECIAL VERSION 인물·몬스터명 및 아이템 이식 계획

상태: 완료

## 배경

- 115번 조사에서 SPECIAL VERSION의 `castinfo.dat.z`와 `invinfo.dat.z`가 일반판과 같은 내부 고정 레코드 구조를 사용함을 확인했다.
- 독립 압축 파일과 `init.bin` 내부 런타임 복사본의 해제 payload가 각각 일치하며, 압축 컨테이너 왕복도 검증됐다.
- 인물·몬스터명 승인 번역 70개와 기존 아이템 72개는 공간 초과 없이 이식할 수 있다.
- 몬스터 `CAST_M720`, `CAST_M730`은 두 판본에서 이름이 서로 교환돼 ID 기준 복사가 아니라 SPECIAL 원문 기준 대응이 필요하다.
- `ky_09` 알마의 날개는 설명 의미 검토가 필요하고 SPECIAL 전용 아이템 4개는 아직 번역 승인이 없으므로 제외한다.

## 목적

- SPECIAL VERSION에 검증된 인물·몬스터명 70개와 아이템명·설명 72개를 안전하게 적용한다.
- 필요한 신규 한글 글리프 11자를 기존 revision 6 뒤에 append하여 기존 코드 배정을 보존한다.
- 독립 `.dat.z`와 `init.bin`의 런타임 복사본을 함께 교체한다.
- GUI 사전 검증과 패치 생성에서 SPECIAL판 인물·몬스터 및 아이템 적용 수와 제외 항목을 명확히 표시한다.
- 원본 SPECIAL VERSION ISO는 변경하지 않고 별도 테스트 ISO를 생성한다.

## 적용 범위

### 인물·몬스터명

- 일반판 작업공간에서 `reviewed` 상태이며 번역이 입력된 70개
- 직접 대응 68개
- 원문 기준 교차 대응 2개:
  - SPECIAL `CAST_M720` 원문 `ユエ` → `유에`
  - SPECIAL `CAST_M730` 원문 `セラ` → `세라`

### 아이템

- 일반판 작업공간의 `override` 73개 중 SPECIAL 원문 이름·설명이 모두 일치하는 72개
- 이름 32바이트, 메타데이터 44바이트, 설명 108바이트 경계 유지
- 메타데이터와 미선택 레코드는 바이트 단위 보존

### 제외 항목

- `ky_09` 알마의 날개: SPECIAL 설명과 현재 한국어 번역의 의미 재검토 필요
- SPECIAL 전용 아이템:
  - `ky_20`
  - `ky_21`
  - `ky_22`
  - `ky_23`
- 시스템 메시지 전체
- 미승인 인물·몬스터명

## 1. SPECIAL 전용 대응 작업공간 생성

- 115번 대응 보고서를 입력으로 SPECIAL 전용 인물·몬스터 및 아이템 적용 목록을 생성한다.
- 각 행에 SPECIAL 식별자 또는 아이템 ID, 원문, 번역, 대응 방식과 원본 레코드 해시를 기록한다.
- 직접 대응과 원문 기준 교차 대응을 구분한다.
- 제외 5개 아이템은 상태와 제외 사유를 명시해 후속 검수가 가능하게 보존한다.
- 같은 SPECIAL 대상에 여러 번역이 대응하면 생성을 중단한다.

## 2. 안정 매핑 revision 7

- revision 6의 964개 행은 순서·문자·게임 코드·폰트 인덱스를 그대로 보존한다.
- 다음 11자를 현재 확장 테이블 끝에 append한다.
  - 인물·몬스터: `랴`, `쉐`
  - 아이템: `겸`, `듬`, `똬`, `롱`, `링`, `벅`, `볍`, `뿜`, `클`
- 신규 코드는 `0xF2DC` 이후의 사용 가능한 사용자 정의 Shift-JIS 코드를 순서대로 배정한다.
- 신규 폰트 인덱스는 2305 이후 연속 범위를 사용한다.
- 문자, 게임 코드, 폰트 인덱스 중복과 기존 번역 코드 충돌을 전수 검사한다.
- 기존 `코=0x817E`, `쩔=0xF2DB` 배정을 다시 확인한다.

## 3. 인물·몬스터명 패치

- SPECIAL `castinfo.dat.z`를 해제하고 32바이트 이름 필드만 변경한다.
- 직접 대응 68개는 식별자와 원문이 모두 일치할 때만 적용한다.
- 교차 대응 2개는 대상 SPECIAL 식별자의 실제 원문을 다시 확인한 뒤 이름 기준 번역을 적용한다.
- 식별자, 모델·능력치 등 이름 필드 밖 바이트는 보존한다.
- 수정 payload를 재압축하고 다음 두 위치에 함께 적용한다.
  - `PSP_GAME/USRDIR/data/misc/castinfo.dat.z`
  - `PSP_GAME/USRDIR/data/arc/init.bin`의 `castinfo.dat.z`, index 7

## 4. 아이템 패치

- SPECIAL `invinfo.dat.z`를 해제하고 안전 대응 72개의 이름·설명 필드만 변경한다.
- 번역 설명의 LF는 게임 저장 형식인 CRLF로 변환한다.
- 이름과 설명은 NUL 종료 후 필드 끝까지 0으로 채운다.
- 가격·능력치·리소스 ID 등 44바이트 메타데이터를 바이트 단위로 보존한다.
- `ky_09`와 SPECIAL 전용 4개 레코드는 원본 전체를 유지한다.
- 수정 payload를 재압축하고 다음 두 위치에 함께 적용한다.
  - `PSP_GAME/USRDIR/data/misc/invinfo.dat.z`
  - `PSP_GAME/USRDIR/data/arc/init.bin`의 `invinfo.dat.z`, index 9

## 5. 압축 및 할당 공간 검증

- 수정 `.z` 컨테이너를 재해제해 payload와 번역 필드를 비교한다.
- 독립 파일은 기존 ISO 할당 섹터 안에 들어가는지 확인한다.
- `init.bin` 엔트리는 다음 엔트리까지의 실제 할당 공간 안에 들어가는지 확인한다.
- 압축 결과가 기존 할당량을 넘으면 제자리 덮어쓰기를 중단하고 ISO 신규 extent 또는 아카이브 재배치 방식을 별도 판단한다.
- `init.bin`의 비대상 엔트리와 헤더는 변경 전후 비교로 보존을 확인한다.

## 6. SPECIAL 빌더 및 GUI 통합

- SPECIAL 패치 빌더가 revision 7 매핑과 전용 인물·아이템 작업공간을 필수 배포 자산으로 검증하도록 한다.
- GUI의 SPECIAL 프로필에서 다음 수량을 표시한다.
  - 인물·몬스터 적용 70개
  - 아이템 적용 72개
  - 아이템 검토 제외 5개
- `사전 검증`과 `패치 ISO 만들기` 모두 같은 적용 목록, 글리프와 압축 결과를 사용한다.
- 일반판 편집 작업공간이나 상태는 변경하지 않는다.

## 7. 테스트 ISO와 재추출 검증

- 원본 SPECIAL VERSION ISO를 입력으로 다음 작업본을 생성한다.
  - `patched/116-ys6-special-version-cast-item-port/Ys VI Special Version - 116-cast-item-port.iso`
- 생성 ISO에서 BOOT/EBOOT, 독립 `castinfo.dat.z`·`invinfo.dat.z`와 `init.bin`을 다시 추출한다.
- 압축 해제 후 다음을 검증한다.
  - 인물·몬스터명 70개 인코딩 일치
  - 아이템 72개 이름·설명 인코딩 일치
  - `ky_09` 및 SPECIAL 전용 4개 원본 보존
  - 독립 payload와 아카이브 런타임 복사본 일치
  - 비대상 메타데이터 및 레코드 보존
  - revision 7 신규 글리프 11개 비트맵 일치
- 일반판 전체 사전 검증도 다시 실행한다.

## 제외 범위

- `ky_09` 번역 확정 및 적용
- SPECIAL 전용 아이템 4개 신규 번역
- 시스템 메시지 EUC-JP 변환 경로 수정
- 옵션 메뉴·추가 이미지, 엔딩 영상과 XMB 이미지
- 대사 실기 일괄 검수
- 일반판 번역 작업공간 내용 변경

## 안전 조건과 중단 기준

- 원본 ISO는 읽기 전용으로 유지한다.
- SPECIAL 원문, 식별자, 레코드 해시가 대응 작업공간과 다르면 적용하지 않는다.
- 이름·설명 필드 밖 변경이 발생하면 빌드를 중단한다.
- 기존 revision 6 매핑 행 하나라도 바뀌면 빌드를 중단한다.
- 압축 또는 아카이브 할당 공간을 넘으면 임의 절단이나 덮어쓰기를 하지 않는다.
- `ky_09`와 SPECIAL 전용 4개 아이템은 사용자 승인 없이 번역하지 않는다.
- 일반판 회귀 검증이 실패하면 GUI 배포 데이터 갱신을 완료 처리하지 않는다.

## 완료 기준

- SPECIAL 전용 대응 작업공간에 적용 142개와 제외 5개의 근거가 기록된다.
- revision 7이 기존 964개 매핑을 보존하고 신규 11자만 append한다.
- 인물·몬스터명 70개와 아이템 72개가 독립 파일 및 런타임 복사본에 적용된다.
- 압축, 할당 공간, 메타데이터, 재추출 및 글리프 검증이 모두 통과한다.
- GUI 사전 검증과 패치 생성에서 동일 결과가 나온다.
- 일반판 빌드 경로에 회귀가 없다.
