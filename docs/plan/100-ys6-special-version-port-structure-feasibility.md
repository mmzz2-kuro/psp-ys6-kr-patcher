# 100. Ys VI SPECIAL VERSION 한글 패치 이식 구조·난이도 조사 계획

상태: 완료

## 목적

- `ULJM-05155 SPECIAL VERSION`에 현재 `ULJM-05009`용 한글 패치를 다시 맞춰 이식할 수 있는지 구조적으로 조사한다.
- 기존 번역 데이터와 한글 이미지 자산 중 재사용 가능한 범위를 정량화한다.
- 실제 이식에 필요한 작업 단계, 위험 요소와 예상 난이도를 제시한다.

## 조사 대상

- 기존 지원 ISO: `roms/Ys VI - Napishtim no Hako (Japan).iso` (`ULJM-05009`)
- 이식 후보 ISO: `roms/Ys 6 - the ark of napishtim [J].iso` (`ULJM-05155`)
- 현재 번역 작업공간과 런타임 매핑
- 현재 옵션 메뉴, 추가 이미지, 엔딩 영상 및 XMB 자산

## 조사 절차

### 1. SPECIAL VERSION 실행 파일 구조

- `EBOOT.BIN`과 `BOOT.BIN`의 암호화·복호화 상태, ELF/PRX 형식과 로드 주소를 확인한다.
- 기존 한글 폰트 아틀라스, 문자 매핑, 시스템 메시지 영역과 대응 가능한 구조를 검색한다.
- 기존 코드 패치 오프셋을 그대로 쓸 수 있는지 판단하지 않고 함수·데이터 시그니처 기준으로 대응 후보를 찾는다.

### 2. 게임 데이터 및 아카이브 구조

- 새 버전의 `data/arc/*.bin` 형식과 엔트리 테이블을 파싱한다.
- 기존 독립 파일이 새 버전에서 어느 아카이브로 이동했는지 파일명, 압축 payload 해시와 구조 해시로 추적한다.
- `init.bin`, 인물명, 아이템 정보, 시스템·옵션 리소스의 실제 실행 복사본을 식별한다.

### 3. 대사·맵 데이터 대응률

- 두 버전에서 동일한 XSO payload와 동일 코드·다른 문자열 XSO를 구분한다.
- 기존 번역 레코드를 `경로+인덱스`가 아니라 원문, 코드 구조와 주변 문맥으로 새 버전에 대응시킨다.
- 자동 이식 가능, 검토 후 이식 가능, 신규 번역 필요 항목의 수를 집계한다.
- 공유 payload와 중복 런타임 복사본 관계를 새 버전 기준으로 다시 작성해야 하는지 확인한다.

### 4. 이미지 자산 대응률

- 옵션 메뉴와 추가 이미지 대상의 동일 payload, 재압축 변형, 좌표·텍스처 규격 변경 여부를 비교한다.
- 기존 한글 PNG를 그대로 재삽입할 수 있는 자산과 새로 분할·조판해야 하는 자산을 구분한다.
- 독립 이미지와 런타임 아카이브 복사본을 새 버전에서 다시 매핑한다.

### 5. 엔딩 영상과 XMB 자산

- 새 버전 PMF의 프레임 수, PTS, PES/AU 구조와 원본 AU 할당을 기존 한글 PMF 방식과 비교한다.
- 기존 자막 합성 원본을 재인코딩해 새 PMF에 넣을 수 있는지 확인한다.
- `PIC0.PNG`은 새 버전 원본 해시와 할당 공간을 기준으로 별도 manifest가 필요한지 판단한다.

### 6. 최소 이식 시험

- 원본 ISO를 수정하지 않고 작업 경로에 핵심 파일을 추출한다.
- 안전하게 대응되는 대사 XSO 또는 이미지 자산 소수로 읽기·재구성 왕복 시험을 수행한다.
- 이 단계에서는 전체 패치 ISO를 만들지 않는다.

### 7. 난이도 및 단계별 제안

- 다음 구성별로 재사용률과 난이도를 정리한다.
  - EBOOT·폰트·시스템 메시지
  - 일반 대사
  - 인물·몬스터명과 아이템
  - 옵션 메뉴 및 추가 이미지
  - 엔딩 영상
  - XMB 이미지
- 전체 이식을 한 번에 진행할지, 텍스트 → 이미지 → 영상 순으로 분리할지 권장안을 제시한다.

## 안전 조건

- 두 원본 ISO는 읽기 전용으로만 사용한다.
- 구조와 대응 관계가 확인되지 않은 파일을 새 ISO에 덮어쓰지 않는다.
- 이번 단계에서는 전체 패치 및 배포용 ISO를 생성하지 않는다.
- 자동 대응은 원문 일치만으로 확정하지 않고 코드 구조, 인접 문자열과 런타임 위치를 함께 검증한다.

## 완료 기준

- SPECIAL VERSION의 실행 파일, 대사, 아카이브, 이미지와 영상 구조를 현재 패치 구조와 비교할 수 있다.
- 기존 자산의 재사용 가능 범위와 신규 작업 범위를 수치로 제시한다.
- 이식 가능 여부와 현실적인 작업 순서·난이도를 명확히 설명한다.
