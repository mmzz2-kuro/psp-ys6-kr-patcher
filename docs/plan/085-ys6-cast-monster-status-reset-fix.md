# 085. Ys VI GUI 인물·몬스터명 상태 초기화 오류 수정 계획

상태: 완료

## 목적

- 인물·몬스터명 항목을 `reviewed`로 변경한 뒤 다른 항목이 `untranslated`로 되돌아가는 문제를 수정한다.
- 단일 선택, 다중 선택, 검색 및 상태·분류 필터가 적용된 상태에서도 변경 대상만 수정되게 한다.
- 저장·검증·다시 열기 과정에서 상태와 번역이 안정적으로 유지되게 한다.

## 수정 범위

### 선택 항목 reviewed 처리

1. 현재 우측 편집 내용을 먼저 정확한 식별자에 커밋한다.
2. 트리에서 선택한 항목의 고유 식별자 목록을 저장한다.
3. 번역이 있는 선택 항목만 `reviewed`로 변경한다.
4. 목록 갱신 후 필터에 남아 있는 변경 항목을 다시 선택한다.
5. 우측 편집기는 대표 선택 항목의 갱신된 실제 값으로 다시 채운다.
6. 변경 항목이 필터에서 모두 사라지면 현재 식별자와 우측 필드를 초기화한다.

### 선택 상태 안전 처리

- `refresh()`가 선택을 복원하지 않을 때 stale `_selected_identifier`가 남지 않게 한다.
- 트리를 다시 만들면서 발생하는 선택 이벤트가 오래된 편집 값을 커밋하지 않게 한다.
- 다른 인물명 작업공간을 열 때 이전 파일의 선택 식별자를 초기화한다.
- 선택이 없는 상태에서 저장·검증을 실행해도 과거 항목이 다시 커밋되지 않게 한다.

### 다중 선택

- 다중 선택된 모든 항목을 식별자 기준으로 변경한다.
- 갱신 후 현재 필터에 남아 있는 항목만 다시 선택한다.
- 우측 편집 기준은 다시 선택된 첫 항목으로 고정한다.
- 다중 선택 중 현재 편집 행이 선택 집합과 달라도 다른 행을 덮어쓰지 않게 한다.

## 검증

1. 인물 단일 항목 `reviewed` 변경 후 다른 행 선택: 상태 유지
2. 몬스터 단일 항목에서 동일 검증
3. 인물 다중 선택: 대상만 모두 `reviewed` 유지
4. 몬스터 다중 선택: 대상만 모두 `reviewed` 유지
5. `미번역` 필터에서 변경된 행이 사라진 뒤 다른 행 선택: 되돌림 없음
6. 검색 필터 적용 중 변경: 올바른 식별자만 변경
7. 인물·몬스터 분류 필터 전환 후 상태 유지
8. 다른 작업공간 열기: 이전 선택 식별자 초기화
9. 저장 및 재로드: 변경 상태 유지
10. 변경 대상 외 모든 행의 번역·상태·메모 불변
11. 현재 실제 작업공간은 수정하지 않고 임시 복사본으로 회귀 테스트
12. Python 구문 검사와 인물명 작업공간 검증 성공

## 예상 변경 파일

- `tools/ys6_dialogue_viewer.py`
- 필요 시 GUI와 분리된 선택 상태 보조 함수 또는 회귀 테스트
- `docs/result/085-ys6-cast-monster-status-reset-fix.md`

## 보존 사항

- 실제 `tools/config/cast-names.json`의 현재 번역과 상태는 수정하지 않는다.
- 원본 ISO와 패치 ISO는 사용하거나 변경하지 않는다.
- 인물·몬스터명의 패치 적용 상태가 `reviewed`인 기존 규칙은 변경하지 않는다.
- 아이템·시스템 메시지·대사 편집기의 상태 처리에는 영향을 주지 않는다.

## 완료 기준

- 인물과 몬스터 모두 `reviewed` 변경 후 상태가 되돌아가지 않는다.
- 다중 선택과 필터 조합에서도 변경 대상 외 행이 바뀌지 않는다.
- 다른 작업공간을 열 때 이전 선택 상태가 남지 않는다.
- 실제 작업공간이 변경되지 않았음을 해시로 확인한다.
- 결과 문서에 재현 전후와 회귀 검증 결과를 기록한다.
