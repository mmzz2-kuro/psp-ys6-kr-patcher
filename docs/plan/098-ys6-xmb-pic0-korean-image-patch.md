# 098. Ys VI XMB PIC0 한글 이미지 패치 계획

상태: 완료

## 목적

- PSP XMB 게임 선택 화면의 `PSP_GAME/PIC0.PNG`에 포함된 일본어 제목과 게임 소개 문구를 한글로 교체한다.
- `PIC1.PNG` 배경과 `ICON0.PNG` 아이콘은 변경하지 않는다.
- 완성된 이미지를 GUI 사전 검증과 ISO 패치에 선택적으로 포함할 수 있게 연결한다.

## 대상

- 원본 ISO 경로: `PSP_GAME/PIC0.PNG`
- 원본 규격: 310×180, 8비트 RGBA PNG
- 원본 크기: 56,082바이트
- ISO 할당 공간: 57,344바이트
- 원본 SHA-256: `31E69F974EE5517BCD541DC1305256C1379F53A19543C0353D740DC1800851A0`

## 번역 초안

원문의 의미와 좁은 표시 영역을 고려해 다음 문구를 사용한다.

```text
이스 ~나피쉬팀의 상자~

전해지는 「다정함」,
펼쳐지는 「모험심」―.

무대는 대륙에서 아득히 먼 서쪽, 바다 끝자락――.
절해의 외딴섬에서 펼쳐지는 아돌의 새로운 모험!
성장하는 세 자루의 에메라스 검과 다채로운 액션을 구사해,
밀려오는 적을 모조리 물리치자!
```

- 하단의 `© 2005 Konami Digital Entertainment`와 `© 2003 Nihon Falcom Corporation. All rights reserved.`는 원문 그대로 보존한다.
- 실제 조판 시 310×180 영역에서 가독성이 부족하면 의미를 유지하는 범위에서 줄바꿈과 문장 길이를 조정한다.

## 작업 절차

1. 원본 `PIC0.PNG`의 알파 채널과 일본어 문자 영역을 분석한다.
2. 일본어 픽셀만 제거하고 투명 배경과 하단 저작권 문구를 보존한다.
3. 기존 프로젝트의 한글 글꼴을 사용해 제목과 소개 문구를 조판한다.
4. 310×180 실제 크기 및 `PIC1.PNG` 위 합성 미리보기를 출력해 가독성을 확인한다.
5. 사용자가 이미지를 확인하면 최종 PNG를 패치 자산 경로에 확정한다.
6. 빌더에서 원본 SHA-256, PNG 규격과 ISO 할당 공간을 사전 검증한다.
7. GUI에 `XMB 한글 이미지 적용` 체크박스를 추가하거나 기존 이미지 선택 영역에 독립 항목으로 연결한다.
8. 체크 시 사전 검증과 ISO 빌드 모두 `PIC0.PNG`을 포함하고, 해제 시 모두 제외하도록 한다.
9. 별도 테스트 ISO를 생성한 뒤 출력 ISO에서 `PIC0.PNG`을 재추출하여 자산과 일치하는지 확인한다.

## 산출물

- 편집 작업 경로: `tools/patchdata/work/current/098-xmb-pic0-korean`
- 최종 패치 자산: `tools/patchdata/ys6_xmb/PIC0.PNG`
- 필요한 비GUI 이미지 생성 스크립트: `tools/scripts`
- 테스트 ISO: `patched/098-xmb-pic0-korean`
- 결과 문서: `docs/result/098-ys6-xmb-pic0-korean-image-patch.md`

## 안전 조건

- 원본 ISO와 원본 추출 이미지는 수정하지 않는다.
- 최종 PNG는 RGBA와 310×180 규격을 유지한다.
- 최종 파일은 57,344바이트를 넘지 않아야 한다.
- `PARAM.SFO`, `PIC1.PNG`, `ICON0.PNG`은 변경하지 않는다.
- 이미지 확인 전에는 최종 ISO에 적용하지 않는다.

## 검증

- 원본 일본어 픽셀이 남지 않았는지 확대 이미지로 확인한다.
- 글자 잘림, 겹침, 알파 경계와 하단 저작권 문구 보존 여부를 확인한다.
- `PIC1.PNG`과 합성한 480×272 미리보기에서 실제 XMB 표시 가독성을 확인한다.
- GUI 선택 상태가 사전 검증과 빌드 양쪽에 동일하게 반영되는지 확인한다.
- 출력 ISO의 변경 범위가 `PIC0.PNG` 데이터와 파일 크기 필드로 제한되는지 확인한다.

## 완료 기준

- 사용자가 승인한 한글 `PIC0.PNG`이 생성된다.
- GUI에서 적용 여부를 선택할 수 있고 사전 검증과 ISO 빌드가 동일한 선택을 따른다.
- 테스트 ISO에서 재추출한 이미지가 최종 자산과 일치한다.
