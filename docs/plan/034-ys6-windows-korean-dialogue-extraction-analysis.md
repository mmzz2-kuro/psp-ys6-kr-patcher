# 034. Ys VI Windows 한국어 패치 대사 추출 분석 계획

## 목적

`/windowVersion`에 보관된 Windows(Steam)판 Ys VI 한국어 패치에서 한글 대사를 추출할 수 있는지 확인하고, 추출 결과를 PSP판 대사 초벌 번역에 안전하게 활용할 수 있는지 판단한다.

## 배경

- PSP판 전체 대사 작업공간은 `/tools/config/dialogue-translations.json`에 관리 중이다.
- 현재 번역은 `draft`로만 추가하고 사용자가 검토한 항목만 `override`로 전환한다.
- Windows판과 PSP판은 파일 구조, 이벤트 분할, 제어문자 및 대사 순서가 다를 수 있다.
- 따라서 Windows판 번역을 인덱스로 직접 덮어쓰지 않고, 가능한 경우 일본어 원문 또는 문맥을 기준으로 대응해야 한다.

## 분석 범위

1. `/windowVersion`과 하위 `release`의 파일 목록, 크기, 확장자 및 헤더를 읽기 전용으로 조사한다.
2. 패치 설명 문서에서 설치 대상과 변경 파일을 확인한다.
3. 실행 파일·데이터 파일에 평문 UTF-8/UTF-16/CP949 한글이 존재하는지 탐색한다.
4. 압축 또는 전용 아카이브라면 컨테이너 구조와 기존 추출 도구 적용 가능성을 확인한다.
5. 추출 가능한 대사의 다음 속성을 확인한다.
   - 대사 본문과 화자명 분리 여부
   - 줄바꿈 및 색상·루비·변수 같은 제어문자
   - 일본어 원문 또는 식별 키 포함 여부
   - PSP판 대사와 자동·반자동 대응 가능한 비율
6. 추출·대응이 가능하면 후속 구현 계획과 데이터 배치 경로를 제안한다.

## 안전 원칙

- `/windowVersion` 원본 파일은 수정하지 않는다.
- 분석 산출물은 `.work/ys6-windows-korean-analysis` 아래에 둔다.
- 실제 PSP 번역 작업공간에는 이번 분석 단계에서 병합하지 않는다.
- Windows판 한국어 패치의 문장은 참고 데이터로만 취급하며, 대응이 불확실한 항목은 자동 반영하지 않는다.

## 예상 산출물

- 파일 구조 및 문자열 인코딩 조사 결과
- 추출 가능 여부와 추출 대상 파일 목록
- PSP판 대응 방식 및 위험 요소
- 필요 시 `/tools/scripts`에 작성할 비GUI 추출기의 후속 계획
- `/docs/result` 결과 문서

## 확인 기준

- 실제 한국어 문자열 샘플을 원본 파일에서 재현 가능하게 찾는다.
- 문자열의 경계와 인코딩을 설명할 수 있다.
- PSP판 원문과 최소 표본을 비교해 재사용 가능성을 판단한다.
- 원본 파일의 해시 또는 수정 시각이 분석 전후 바뀌지 않았음을 확인한다.
