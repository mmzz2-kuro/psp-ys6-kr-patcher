# 056. Ys VI 추가 이미지 편집·재삽입 및 GUI 빌드 연동 계획

## 상태

- 완료

## 목적

055에서 확인한 일본어 이미지 리소스를 사용자가 PNG로 편집할 수 있도록 문구 및
화면 단위로 분리하고, 수정 이미지를 원래 텍스처에 재삽입해 GUI 패치 ISO 빌드에
자동 포함한다.

## 대상

- 세이브·로드·삭제 확인 문구
- 지역명 22개
- 월드맵 일본어 지명
- 아이템 사용 확인 및 아이템 메시지
- 검 강화 확인·부족·최대 레벨 메시지
- 상점 구매·판매·취소·부족 메시지

## 작업 단계

1. `/tools/patchdata/ys6_additional_images`에 다음 구조를 만든다.
   - `source_images`: 원본 확인용 이미지
   - `source_parts`: 문구·행·버튼별 원본 조각
   - `edited_parts`: 사용자가 수정할 조각
   - `manifest.json`: 원본 경로, 좌표, 크기, 형식과 중복 사본 관계
2. 큰 아틀라스를 문구 또는 버튼 단위 PNG로 분리한다.
3. 수정 조각의 크기와 모드를 검사하고 원본 텍스처 좌표에 RGBA 픽셀을 그대로
   복사한다.
4. PSP DXT1/DXT3 텍스처에서 실제 변경된 4×4 블록만 다시 인코딩한다.
5. DXT1은 054에서 검증한 고품질 RGB565 끝점 탐색을 재사용한다.
6. DXT3은 알파값을 보존하고 RGB 오차가 작은 블록을 선택하는 인코더를 구현한다.
7. 컨테이너를 재압축하고 각 ISO 파일의 할당 공간을 넘지 않는지 검사한다.
8. 중복 사본을 함께 갱신한다.
   - `saveicon2.dds.z`와 `init.bin/static_tex.dds.z` 그림 index 69
   - `itemcursor.dds.z`와 `static_tex` 그림 index 62
   - `itemwin.dds.z`와 `static_tex` 그림 index 61
   - 추가로 확인되는 동일 사본
9. `/tools/ys6_dialogue_viewer.py` 패치 빌드 탭에 추가 이미지 폴더와 인식 개수를
   표시하고, 사전검사 및 ISO 생성에 포함한다.

## 편집 단위 원칙

- 지역명은 한 행당 하나의 PNG로 분리한다.
- 확인창은 세이브·로드·삭제 문구를 각각 분리한다.
- 선택지와 상태 문구는 의미 단위로 분리하되 배경과 테두리를 포함하여 사용자가
  그대로 편집할 수 있게 한다.
- 월드맵은 글자가 배경에 직접 그려져 있으므로 우선 전체 이미지 편집본을 지원하고,
  필요하면 후속 단계에서 지명별 마스크를 추가한다.
- 원본 PNG는 수정하지 않고 `edited_parts`만 패치 입력으로 사용한다.

## 검증

- 모든 원본 조각을 수정 없이 재조립했을 때 디코딩 RGBA가 원본과 일치한다.
- 수정되지 않은 압축 블록은 원본 바이트를 유지한다.
- 수정 블록은 PNG 대비 복원 오차와 알파 보존 여부를 보고한다.
- 독립 파일과 `init.bin` 내장 사본이 필요한 대상은 같은 편집 결과를 포함한다.
- 모든 재압축 컨테이너가 기존 ISO 할당 공간 안에 들어간다.
- GUI 사전검사와 전체 패치 ISO 생성이 통과한다.
- 원본 ISO SHA-256은 변경되지 않는다.

## 이번 단계에서 제외

- 자동 한글 번역 이미지 생성
- 사용자 확인 없이 모든 원본 조각을 한글 이미지로 교체
- 원본 ISO 직접 수정
- 최종 이미지 디자인 확정

## 위험 및 대응

- DXT 압축 얼룩: 수정 블록만 고품질 인코딩하고 PNG·왕복 이미지를 함께 제공한다.
- 알파 손상: DXT3의 4비트 알파를 별도 보존·검증한다.
- 컨테이너 용량 초과: 빌드 전 최적 압축과 할당 크기 검사를 수행한다.
- 중복 사본 누락: 매니페스트에 동기화 대상을 명시하고 빌드에서 필수 검사한다.
