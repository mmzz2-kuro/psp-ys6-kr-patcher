# 048. 아이템 가격·능력치 필드 경계 수정 계획

## 배경

아이템 이름을 적용한 ISO에서 상점 가격이 전부 0으로 표시되는 문제가 확인됐다.

실제 생성 ISO `roms/Ys VI - Korean Patched.iso`의 `invinfo.dat`를 원본과 비교한 결과:

- 파일 크기와 헤더는 원본과 같음
- 독립 `invinfo.dat`와 `init.bin` 내부 복사본은 서로 같음
- 기존 구현이 메타데이터로 정의한 상대 위치 `0x34..0x4B`는 원본과 같음
- 그러나 상대 위치 `0x20..0x33`의 가격·능력치 20바이트가 이름 패딩으로 오인되어 0으로 변경됨

예를 들어 방패 계열의 가격 `80`, `410`, `1500`, `4600`, `18000`, `85000` 등이 모두 0으로 지워졌다.

## 원인

047 구현에서 `invinfo.dat` 레코드를 다음과 같이 잘못 해석했다.

- 이름: 52바이트
- 메타데이터: 24바이트
- 설명: 108바이트

실제 구조는 다음과 같다.

- 이름: 상대 위치 `0x00..0x1F`, 32바이트
- 가격·능력치·리소스 메타데이터: `0x20..0x4B`, 44바이트
- 설명: `0x4C..0xB7`, 108바이트

이름 교체 시 52바이트 전체를 0으로 채우면서 `0x20..0x33`에 있던 가격과 일부 능력치를 함께 삭제한 것이 직접 원인이다.

## 수정 범위

### 1. `invinfo.dat` 구조 수정

- `NAME_SIZE`를 52에서 32로 변경한다.
- `METADATA_SIZE`를 24에서 44로 변경한다.
- 설명 시작 위치 `0x4C`와 설명 크기 108바이트는 유지한다.
- 이름 교체 시 상대 위치 `0x00..0x1F`만 변경한다.
- 상대 위치 `0x20..0x4B`는 원본에서 한 바이트도 바꾸지 않는다.

### 2. 작업공간 검증 수정

- 아이템 이름은 NUL 포함 32바이트 이내로 검증한다.
- GUI의 이름 길이 표시를 `/32`로 변경한다.
- 기존 72개 override 이름이 32바이트 안에 들어가는지 전수 검사한다.
- 길이를 초과하는 항목이 있으면 자동 축약하지 않고 `conflict` 후보로 보고한다.

### 3. 통합 빌더 수정

- 수정된 44바이트 메타데이터 경계를 기준으로 원본 보존을 검증한다.
- 독립 `PSP_GAME/USRDIR/data/misc/invinfo.dat`와 `init.bin` 인덱스 10 복사본을 동일하게 수정한다.
- 결과 파일 크기 13,448바이트를 유지한다.
- 빌드 보고서에 메타데이터 SHA-256 또는 전체 불일치 개수를 기록한다.

### 4. 기존 잘못된 ISO 처리

- 대상: `roms/Ys VI - Korean Patched.iso`
- 이 파일은 가격 필드가 손상된 빌드로 결과 문서에 기록한다.
- 사용자 확인 없이 삭제하지 않는다.
- 수정 검증에는 반드시 원본 일본판 ISO를 입력으로 사용하며, 손상된 ISO를 재패치하지 않는다.

## 검증 계획

1. 원본 73개 레코드의 상대 위치 `0x20..0x4B`를 보존 기준으로 수집한다.
2. 아이템 1개 override 시험에서 이름·설명 외 바이트 변경이 없는지 확인한다.
3. 현재 실제 작업공간의 72개 override를 적용한다.
4. 73개 레코드의 44바이트 메타데이터가 원본과 바이트 단위로 완전히 같은지 확인한다.
5. 알려진 가격 표본을 비교한다.
   - 인덱스 4: 80
   - 인덱스 5: 410
   - 인덱스 6: 1500
   - 인덱스 7: 4600
   - 인덱스 8: 18000
   - 인덱스 9: 85000
6. 독립 `invinfo.dat`와 `init.bin` 내부 복사본이 같은지 확인한다.
7. 이름 31바이트 + NUL은 허용하고 32바이트 + NUL은 거부하는 역테스트를 수행한다.
8. 설명과 다른 대사·인물명 패치에 회귀가 없는지 통합 preflight를 수행한다.
9. 사용자가 요청하면 원본 ISO로 새 수정 ISO를 빌드한다.

## 완료 조건

- 아이템 이름 교체가 32바이트 영역에만 적용된다.
- 73개 가격·능력치·리소스 메타데이터 44바이트가 원본과 완전히 같다.
- 현재 72개 override가 검증을 통과하거나 초과 항목이 명확히 보고된다.
- 통합 preflight가 통과한다.
- 새 ISO를 만들 경우 원본 일본판 ISO를 기준으로 생성한다.
- 수행 및 검증 결과가 `/docs/result`에 기록된다.
