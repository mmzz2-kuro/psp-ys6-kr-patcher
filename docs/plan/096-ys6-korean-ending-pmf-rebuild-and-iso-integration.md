# 096. Ys VI 한글 엔딩 PMF 재구성·ISO 통합 계획

상태: 완료

## 목적

- 095번에서 확정한 두 한글 영상 미리보기를 PSP가 재생할 수 있는 PMF로 재구성한다.
- 원본 ISO의 두 엔딩 영상 파일을 한글 PMF로 교체한 테스트 ISO를 만든다.
- 검증이 끝난 영상 자산을 GUI 빌드와 사전 검증에 선택적으로 연결한다.

## 대상

- `PSP_GAME/USRDIR/data/movie/im03a_kaizoku.pmf`
- `PSP_GAME/USRDIR/data/movie/im03b_kazaminooka.pmf`
- 095번 한글 합성 설정과 타임라인

## 현재 확인된 구조

- 두 원본 파일은 `PSMF0012` 헤더를 가진 PSP PSMF 컨테이너다.
- 헤더 크기는 `0x800`이며 이후 MPEG Program Stream 패킷이 이어진다.
- FFmpeg에서 인식되는 영상은 H.264 Main Profile, 480×272, `30000/1001`fps, 1 reference frame, B-frame 없음이다.
- 시작 PTS는 90,000, 즉 1.0초다.
- FFmpeg에서는 별도 오디오 스트림이 검출되지 않았다. 바이너리 패킷 조사로 실제 오디오·보조 스트림 부재 여부를 다시 확인한다.
- 원본 크기는 각각 11,786,240바이트와 10,774,528바이트이며 ISO 고정 extent 안에서 교체해야 한다.

## 작업 절차

### 1. PMF 구조 조사

- PSMF 헤더의 스트림 정보, 전체 길이, 시작·종료 PTS 및 패킷 크기를 해석한다.
- `0x800` 이후 MPEG-PS의 pack, system, PES 패킷과 stream id를 전수 조사한다.
- 영상 외 스트림이 존재하면 원본에서 그대로 보존할 수 있는지 확인한다.

### 2. PSP 호환 영상 인코딩

- 095번 합성 결과를 480×272, `30000/1001`fps H.264로 다시 인코딩한다.
- Main Profile, level 2.1, B-frame 없음, reference frame 1 등 원본 제약을 따른다.
- 원본 ISO 할당 공간을 넘지 않도록 영상별 목표 비트레이트를 계산한다.
- 프레임 수는 각각 2,458개와 2,278개로 유지한다.

### 3. PMF 재구성

- 재사용 가능한 비GUI PMF 검사·재구성 스크립트를 `tools/scripts`에 작성한다.
- 가능한 경우 원본 PSMF 헤더·패킷 구조와 타임스탬프를 보존하면서 영상 PES만 교체한다.
- 패킷 재구성이 필요하면 헤더의 스트림 크기와 종료 타임스탬프를 새 데이터에 맞게 갱신한다.
- 외부 전용 도구가 필요한 경우 도구명, 버전, 라이선스와 재현 절차를 결과 문서에 기록한다.

### 4. PMF 검증

- `PSMF0012` 서명, `0x800` 헤더, MPEG-PS 패킷 연속성을 검사한다.
- H.264 프로필·레벨·해상도·fps·프레임 수·PTS를 원본과 비교한다.
- 전체 영상을 디코딩해 손상 프레임이 없는지 확인한다.
- 원본 ISO의 각 파일 할당 크기 안에 들어가는지 확인한다.
- 가능하면 PPSSPP에서 독립 재생 또는 게임 내 재생을 확인할 수 있는 형태로 준비한다.

### 5. 테스트 ISO 적용

- 원본 ISO를 직접 수정하지 않고 `/patched/096-korean-ending-movie` 아래에 별도 테스트 ISO를 만든다.
- 기존 다중 ISO 패치의 원본 파일 크기·SHA-256 검증과 원자적 출력 방식을 사용한다.
- 두 PMF 외 허용되지 않은 ISO 영역이 변경되지 않았는지 차이 범위를 검사한다.
- 테스트 ISO 파일명과 정리 대상을 결과 문서에 기록한다.

### 6. GUI 및 빌드 연결

- GUI 이미지 옵션 영역에 `엔딩 영상 적용` 체크박스를 별도로 추가한다.
- 체크 시 사전 검증과 실제 빌드에 두 PMF를 모두 포함한다.
- 체크 해제 시 두 단계 모두 영상 검증·교체를 수행하지 않는다.
- 영상 자산 해시, 파일 크기 및 PMF 구조 오류를 GUI에서 명확하게 표시한다.
- 기존 추가 이미지와 옵션 메뉴 체크박스 동작은 변경하지 않는다.

## 산출물 배치

- 최종 한글 PMF 자산은 `tools/patchdata/ys6_ending_movies` 아래에 둔다.
- 조사·시험 중간 파일은 `tools/patchdata/work/current/096-korean-ending-pmf` 아래에 둔다.
- 테스트 ISO는 `patched/096-korean-ending-movie` 아래에 둔다.
- PMF 검사·재구성 스크립트는 `tools/scripts`에 둔다.
- 결과는 `docs/result/096-ys6-korean-ending-pmf-rebuild-and-iso-integration.md`에 기록한다.

## 실패 시 처리

- FFmpeg의 일반 MPEG-PS 출력물을 확장자만 PMF로 바꾸어 사용하지 않는다.
- 유효한 PSMF 재구성이 불가능하면 손상 가능성이 있는 파일을 ISO나 GUI에 연결하지 않는다.
- 이 경우 조사 결과와 막힌 구조를 문서화하고, 필요한 PSP SDK 계열 또는 PSMF 전용 도구를 명시한 뒤 중단한다.
- 실패한 PMF와 테스트 ISO는 최종 자산으로 승격하지 않는다.

## 검증

- PMF 두 개가 원본과 같은 영상 프레임 수와 시간축을 갖는지 확인한다.
- 시작 PTS 1.0초 및 종료 시간이 영상 길이와 모순되지 않는지 확인한다.
- 각 PMF가 ISO 할당 공간을 초과하지 않는지 확인한다.
- 생성 ISO의 크기가 원본과 같고 두 PMF extent 및 디렉터리 크기 필드 밖에 변경이 없는지 확인한다.
- GUI 체크 상태에 따라 사전 검증과 빌드 결과가 동일하게 포함·제외되는지 회귀 검사한다.

## 완료 기준

- PSP/PPSSPP에서 재생 가능한 것으로 판단되는 한글 PMF 두 개가 생성된다.
- 두 PMF가 적용된 별도 테스트 ISO가 생성되고 구조 검증을 통과한다.
- GUI에서 엔딩 영상 적용 여부를 선택할 수 있으며 사전 검증과 빌드가 같은 선택을 따른다.
- 원본 PMF와 원본 ISO는 변경되지 않는다.
