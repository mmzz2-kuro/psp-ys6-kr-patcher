# 095. Ys VI 엔딩 영상 한글 대화창 합성 미리보기 계획

상태: 완료

## 목적

- 094번에서 확정한 한글 화자명과 대사를 두 엔딩 영상의 기존 대화창에 합성한다.
- 일본어 화자명과 본문을 제거하면서 초상화, 대화창 테두리 및 장식은 보존한다.
- PMF 재구성 전에 MP4 미리보기와 정지 프레임으로 가독성·위치·표시 시간을 검증한다.

## 대상 영상

- `im03a_kaizoku.pmf`
- `im03b_kazaminooka.pmf`
- 093번의 프레임 단위 타임라인과 094번의 교정 번역을 입력으로 사용한다.

## 합성 방식

1. 원본 PMF를 480×272, `30000/1001`fps 순서대로 디코딩한다.
2. 대사 프레임에서 일본어 화자명 영역과 본문 영역만 마스킹한다.
3. 각 프레임의 대화창 내부 색과 질감을 이용해 마스킹 영역을 복원한다.
   - 대화창 바깥 배경, 인물 초상화, 금색 테두리와 오른쪽 장식은 건드리지 않는다.
   - 반투명 대화창 아래에서 움직이는 배경이 지나치게 정지해 보이지 않도록 프레임별로 처리한다.
4. 한글 화자명과 본문을 흰색 계열 글자와 어두운 외곽선으로 합성한다.
5. 094번 데이터의 `\\n`을 실제 두 줄 배치로 변환한다.
6. 각 대사의 기존 시작·종료 프레임을 그대로 사용한다.

## 글꼴 및 배치

- 초기 미리보기는 시스템 한글 글꼴인 맑은 고딕을 사용한다.
- 화자명은 기존 이름 표시줄 안에 중앙 또는 기존 일본어 이름 기준 위치로 배치한다.
- 본문은 기존 PC판 대화창의 왼쪽 정렬과 두 줄 간격을 기준으로 한다.
- 원본 해상도에서 글자가 뭉개지지 않도록 정수 좌표와 외곽선 두께를 사용한다.
- 긴 문장은 대화창 오른쪽 장식을 침범하지 않는지 검사한다.

### 사용자 검수 후 위치 조정

- 최초 미리보기 검수 의견에 따라 화자명과 본문을 모두 기존 시안보다 4px 아래로 이동한다.
- 후속 검수 의견에 따라 화자명과 본문 마스크의 위쪽 경계를 각각 2px 아래로 내린다.
- 추가 검수 의견에 따라 화자명 마스크의 위쪽 경계를 1px 더 내려 최종 `y=170`으로 조정한다.
- PMF 디코딩 검수에서 페이드 프레임에 일본어가 남는 현상이 확인되면, 안정 프레임의 글자 모양 마스크를 재사용하고 한글을 대화창 밝기에 맞춰 함께 페이드한다.
- 글꼴 크기, 줄 간격과 대사 타이밍은 변경하지 않는다.

## 구현

- 비GUI 합성 스크립트를 `tools/scripts`에 추가한다.
- 입력 타임라인 JSON과 영상 경로를 인자로 받아 반복 실행할 수 있게 한다.
- 텍스트 내용만 바뀐 경우 전체 조사 과정을 반복하지 않고 합성 출력만 갱신할 수 있게 한다.
- 렌더링 설정과 사용 글꼴 경로를 결과 메타데이터에 기록한다.

## 검증

- 출력 영상이 480×272, `30000/1001`fps이며 원본과 프레임 수가 같은지 확인한다.
- 15개 구간 모두에서 일본어 화자명과 본문이 남지 않는지 대표 프레임을 확인한다.
- 한글 화자명과 본문이 대화창 테두리·초상화·오른쪽 장식을 침범하지 않는지 확인한다.
- 두 줄 대사의 줄바꿈과 글자 폭을 확인한다.
- 대사 시작 전과 종료 후 프레임이 원본과 동일한지 픽셀 비교한다.
- 합성 대상 밖 프레임이 변경되지 않았는지 검사한다.

## 이번 단계에서 하지 않는 작업

- 원본 PMF를 덮어쓰지 않는다.
- PSP용 PMF 재인코딩과 멀티플렉싱은 수행하지 않는다.
- ISO 및 GUI 패치 자산에는 아직 반영하지 않는다.
- 사용자 미리보기 확인 전에는 최종 글꼴·위치로 확정하지 않는다.

## 후속 단계

- 미리보기 확인 후 글꼴 크기, 좌표, 줄 간격 및 마스크 영역을 조정한다.
- 승인된 영상으로 PSP 호환 PMF 재구성 가능성을 검증한다.
- PMF 검증이 끝난 뒤 GUI 빌드와 ISO 패치 경로에 연결한다.

## 완료 기준

- 두 영상의 모든 대화가 한글 화자명과 한글 본문으로 식별 가능하게 표시된다.
- 원본 대화창의 주요 장식과 초상화가 보존된다.
- 사용자가 최종 PMF 작업 여부를 판단할 수 있는 MP4 미리보기가 준비된다.
