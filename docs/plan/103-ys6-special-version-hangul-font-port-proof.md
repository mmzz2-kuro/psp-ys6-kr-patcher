# 103. Ys VI SPECIAL VERSION 한글 폰트 이식 검증 계획

상태: 완료

## 목적

- `ULJM-05155 SPECIAL VERSION` 실행 파일에서 한글 폰트 패치에 필요한 구조와 위치를 다시 찾는다.
- 기존 `ULJM-05009`용 한글 글리프 생성·문자 매핑 방식을 재사용할 수 있는지 검증한다.
- 전체 대사 이식에 들어가기 전에 SPECIAL VERSION에서 실제 한글 표시가 가능한 최소 실행 파일을 만든다.

## 대상

- 기존 지원 ISO: `roms/Ys VI - Napishtim no Hako (Japan).iso` (`ULJM-05009`)
- 이식 대상 ISO: `roms/Ys 6 - the ark of napishtim [J].iso` (`ULJM-05155`)
- 기존 한글 폰트 빌더와 문자 매핑 자료
- SPECIAL VERSION의 복호화 ELF인 `PSP_GAME/SYSDIR/BOOT.BIN`
- SPECIAL VERSION의 암호화 실행 파일인 `PSP_GAME/SYSDIR/EBOOT.BIN`

## 작업 범위

### 1. 실행 파일 기준점 재탐색

- 두 버전의 ELF 섹션, 로드 주소와 실행 코드 범위를 비교한다.
- 기존 폰트 아틀라스, 글리프 폭 테이블, 문자 코드 변환 및 렌더링 관련 데이터의 참조 위치를 시그니처와 교차 참조로 추적한다.
- 기존 고정 오프셋은 재사용하지 않고 SPECIAL VERSION에서 찾은 위치를 별도 프로필로 기록한다.

### 2. 폰트 저장 공간과 문자 매핑 검증

- SPECIAL VERSION의 원본 일본어 글리프 수, 셀 규격과 저장 공간을 확인한다.
- 기존 한글 패치와 같은 12픽셀 표시 폭 및 글리프 생성 방식을 적용할 수 있는지 검증한다.
- 기존 `seed-mapping.json`을 그대로 쓰지 않고, 시험 문구에 필요한 최소 한글 문자만 별도 매핑한다.
- 실행 코드나 다른 데이터와 겹치지 않는지 변경 범위를 검사한다.

### 3. 최소 한글 출력 시험 데이터

- 기존 일본어 시스템 문자열 중 위치와 길이가 명확한 한 항목을 시험 대상으로 고른다.
- 해당 문자열을 짧은 한글 시험 문구로 바꾸고 필요한 글리프만 삽입한다.
- 시험 문구는 원문 할당 공간을 넘지 않게 구성하며, 일반 대사와 이미지 자산은 변경하지 않는다.

### 4. PSP 실행 파일 적용 방식 조사

- 수정한 `BOOT.BIN`을 SPECIAL VERSION ISO에서 실제로 실행 가능한 형태로 적용할 수 있는지 확인한다.
- 암호화 `EBOOT.BIN` 재구성이 필요한지, 복호화 ELF를 대체 실행 파일로 사용할 수 있는지 현재 ISO 구조와 PSP/PPSSPP 로딩 조건을 구분해 검증한다.
- 실기용 암호화·서명 처리가 확보되지 않으면 PPSSPP 전용 시험과 실기 적용 가능성을 명확히 분리한다.

### 5. 최소 테스트 ISO

- 실행 파일 적용 방식이 안전하게 확인되는 경우에만 별도 테스트 ISO를 생성한다.
- 출력 후보: `patched/103-special-version-font-test/Ys VI Special Version - 103-hangul-font-test.iso`
- 원본 ISO는 읽기 전용으로 유지한다.
- 실행 파일 적용 방식이 확정되지 않으면 ISO를 억지로 만들지 않고 수정 ELF와 분석 결과까지만 산출한다.

## 구현 방향

- SPECIAL VERSION 전용 실행 파일 프로필을 기존 ULJM-05009 프로필과 분리한다.
- 공통으로 재사용할 수 있는 글리프 렌더링 로직과 버전별 주소·해시는 분리한다.
- 분석 및 자동 검증 스크립트는 `/tools/scripts` 아래에 작성한다.
- 이번 단계에서는 GUI에 SPECIAL VERSION 선택지를 추가하지 않는다.

## 산출물

- 분석·시험 자료: `tools/patchdata/work/current/103-special-version-font-port`
- SPECIAL VERSION 실행 파일 분석 또는 최소 폰트 패치 스크립트: `tools/scripts`
- 실행 가능성이 확인된 경우 테스트 ISO: `patched/103-special-version-font-test`
- 결과 문서: `docs/result/103-ys6-special-version-hangul-font-port-proof.md`

## 검증

- 입력 ISO와 추출 실행 파일의 SHA-256을 기록한다.
- SPECIAL VERSION에서 찾은 각 폰트·문자 처리 위치의 원본 바이트를 검증한다.
- 수정 전후 파일 크기, SHA-256과 변경 바이트 범위를 기록한다.
- 글리프 아틀라스를 이미지로 출력해 한글 시험 문자의 형태와 셀 경계를 확인한다.
- 생성한 ISO가 있으면 ISO에서 실행 파일을 재추출해 작업본과 일치하는지 확인한다.
- PPSSPP 실행이 가능한 환경이면 부팅과 시험 문구 표시 여부를 확인하고, 불가능하면 사용자 실기 시험 항목을 제공한다.

## 제외 범위

- 기존 7,424개 대사의 SPECIAL VERSION 재매핑
- 인물·몬스터명 및 아이템 이식
- 옵션 메뉴와 추가 이미지 이식
- 엔딩 영상 및 XMB 이미지 이식
- GUI의 SPECIAL VERSION 정식 빌드 프로필 추가
- 배포용 패치 또는 완성판 ISO 생성

## 위험 요소

- `BOOT.BIN`은 분석 가능한 ELF지만 실제 PSP는 암호화 `EBOOT.BIN`을 사용할 수 있어 별도 실행 파일 처리 방식이 필요할 수 있다.
- SPECIAL VERSION은 실행 파일 크기와 코드 배치가 달라 기존 폰트 패치 주소를 잘못 적용하면 부팅 실패가 발생한다.
- PPSSPP에서 동작해도 실제 PSP에서 동일하게 실행된다고 단정할 수 없다.
- 안전한 실행 파일 적용 경로가 확보되지 않으면 이번 단계의 결론은 폰트 데이터 이식 가능성과 수정 ELF 생성까지로 제한될 수 있다.

## 완료 기준

- SPECIAL VERSION의 폰트 아틀라스와 문자 처리 구조를 식별한다.
- 최소 한글 시험 문자를 포함한 수정 ELF를 재현 가능하게 생성한다.
- 변경 범위가 의도한 폰트·문자·시험 문자열 영역으로 제한됐음을 검증한다.
- PPSSPP 또는 실기에서 사용할 테스트 ISO 생성 가능 여부를 명확히 결론 낸다.
- 성공하면 후속 단계로 SPECIAL VERSION 대사 카탈로그 및 안전 대응 1,169개 이식 계획을 세울 수 있다.
