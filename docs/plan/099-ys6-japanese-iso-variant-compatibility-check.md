# 099. Ys VI 일본판 ISO 변형 호환성 비교 계획

상태: 완료

## 목적

- 기존 지원 원본 `Ys VI - Napishtim no Hako (Japan).iso`와 새로 추가한 `Ys 6 - the ark of napishtim [J].iso`의 차이를 확인한다.
- 새 ISO에 현재 GUI 한글 패치를 동일하게 적용할 수 있는지 판단한다.
- 단순 파일명 차이, 패딩·정렬 차이, ISO 파일 시스템 차이, 게임 데이터 리비전 차이를 구분한다.

## 대상

- `roms/Ys VI - Napishtim no Hako (Japan).iso`
- 저장소 안의 `Ys 6 - the ark of napishtim [J].iso`

새 ISO의 실제 경로가 다르면 저장소 안에서 파일명으로 찾아 읽기 전용 비교 대상으로 사용한다.

## 조사 절차

1. 두 ISO의 파일 크기와 SHA-256을 비교한다.
2. 완전 바이트 동일 여부와 최초·최종 차이 오프셋, 차이 범위 수를 확인한다.
3. ISO9660 디렉터리와 각 파일의 내부 경로, LBA, 크기 및 SHA-256 목록을 비교한다.
4. 현재 패치가 직접 검증·교체하는 핵심 파일을 별도로 비교한다.
   - `PSP_GAME/SYSDIR/EBOOT.BIN`
   - 대사·시스템·아이템·이미지 아카이브 및 독립 리소스
   - 엔딩 PMF 2개
   - `PSP_GAME/PIC0.PNG`
5. 새 ISO를 현재 GUI 빌더의 사전 검증에 입력해 원본 ISO 해시 검사와 각 자산 검증 결과를 확인한다.
6. 차이가 컨테이너 메타데이터나 패딩뿐인지, 실제 패치 대상 payload까지 다른지 분류한다.
7. 다음 중 하나로 결론을 낸다.
   - 완전 동일: 현재 패치에 그대로 사용 가능
   - 논리적으로 동일하지만 ISO 해시만 다름: 안전한 별칭 해시 지원 가능 여부 제시
   - 일부 리소스 차이: 추가 리비전 지원에 필요한 범위 제시
   - 다른 버전 또는 비정상 덤프: 현재 패치 적용 불가

## 안전 조건

- 두 ISO는 읽기 전용으로만 검사하고 수정하지 않는다.
- 호환성이 확인되기 전에는 새 ISO로 패치 ISO를 생성하지 않는다.
- 단순히 실행 가능하다는 이유만으로 호환된다고 판단하지 않고, 패치 대상 파일의 해시와 할당 공간까지 확인한다.

## 완료 기준

- 두 ISO의 실제 차이를 파일 및 패치 대상 단위로 설명할 수 있다.
- 새 ISO에 현재 한글 패치를 그대로 적용 가능한지 명확히 판정한다.
- 그대로 사용할 수 없다면 필요한 지원 변경과 위험을 정리한다.
