# 055. Ys VI 추가 이미지 리소스 탐색 계획

## 상태

- 완료

## 목적

옵션 메뉴 외에 일본어가 이미지로 포함된 화면 리소스를 추가로 찾아 한글화
대상 목록과 추출·재삽입 가능 여부를 정리한다.

우선 확인할 기준 화면은 다음과 같다.

- 세이브 데이터 확인창: `このデータをロードしますか？`
- 지역명 표시: `クアテラの樹海`

## 작업 범위

1. 원본 ISO와 기존 추출 작업본에서 이미지 및 이미지 컨테이너 후보를 조사한다.
2. `data/image`, `data/arc`, 맵별 리소스와 실행 중 사용하는 중복 사본을 함께 확인한다.
3. DDS 및 압축된 `*.dds.z`를 우선 탐색하고, 알려지지 않은 이미지 형식도 헤더와
   참조 관계를 기준으로 후보에 포함한다.
4. 후보 이미지를 원래 팔레트·알파·블록 배치를 유지한 PNG 미리보기로 추출한다.
5. 두 기준 화면과 일치하는 리소스의 ISO 경로, 아카이브 항목, 오프셋, 압축 형식,
   크기와 화면 내 배치를 기록한다.
6. 같은 방식으로 발견되는 다른 일본어 이미지도 화면 종류별로 분류한다.
7. 각 대상에 대해 수정 PNG를 다시 넣을 수 있는지 무손상 왕복 검증을 수행한다.

## 산출물

- 분석용 비GUI 스크립트: `/tools/scripts`
- 추출된 편집 대상과 설정 데이터: `/tools/patchdata`
- 분석 중간 파일과 미리보기: `/tools/patchdata/work/current`
- 결과 문서: `/docs/result/055-ys6-additional-image-resource-discovery.md`

## 검증 기준

- 원본 ISO는 읽기 전용으로 사용하고 해시가 변하지 않아야 한다.
- 기준 화면 2종의 실제 런타임 리소스 위치를 특정한다.
- 발견한 일본어 이미지 후보를 사람이 확인할 수 있는 PNG 및 목록으로 제공한다.
- 추출 후 수정하지 않고 재삽입한 결과가 원본과 동일하거나, 손실이 불가피한 경우
  형식과 오차 원인을 기록한다.
- 중복 리소스가 있으면 실제 사용 사본과 동기화가 필요한 사본을 구분한다.

## 제외 범위

- 이번 단계에서는 한글 이미지 제작과 ISO 반영을 진행하지 않는다.
- 발견된 모든 이미지를 즉시 번역하지 않는다.
- 원본 ISO를 직접 수정하지 않는다.

## 예상 위험

- 화면 합성용 이미지가 여러 조각 또는 여러 아틀라스에 나뉘어 있을 수 있다.
- 동일한 이미지가 아카이브와 독립 파일에 중복 저장되어 런타임 사본 확인이 필요할
  수 있다.
- 지역명은 맵별 텍스처이거나 글자 조각을 조합하는 방식일 수 있다.
- DXT 계열 재인코딩 시 색상 손실이 생길 수 있으므로 원본 블록 보존을 우선한다.
