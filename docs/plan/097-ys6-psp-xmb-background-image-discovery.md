# 097. Ys VI PSP XMB 배경 이미지 조사 계획

상태: 완료

## 목적

- PSP 실기에서 게임을 실행하기 전, XMB의 게임 목록에서 Ys VI ROM을 선택했을 때 표시되는 배경 이미지를 찾는다.
- 이미지의 ISO 내부 경로, 형식, 크기와 패치 가능 여부를 확인한다.
- 현재 GUI 패치 과정에서 해당 파일이 유지되거나 교체되는 방식도 함께 확인한다.

## 예상 대상

- `PSP_GAME/PIC1.PNG`: 게임 선택 시 화면 전체에 표시되는 배경 이미지 후보
- `PSP_GAME/PIC0.PNG`: 배경 위에 겹쳐 표시되는 설명·장식 이미지 후보
- `PSP_GAME/ICON0.PNG`: 게임 목록 아이콘 후보
- `PSP_GAME/SND0.AT3`: 선택 화면 배경음 후보이며 이미지 조사 범위에서는 존재 여부만 구분한다.
- `PSP_GAME/PARAM.SFO`: XMB 표시 제목 확인용이며 수정하지 않는다.

## 작업 절차

1. 검증된 원본 ISO의 루트 및 `PSP_GAME` 디렉터리 레코드를 조사한다.
2. `PIC0.PNG`, `PIC1.PNG`, `ICON0.PNG`의 존재 여부, LBA, 크기와 SHA-256을 확인한다.
3. 후보 이미지를 원본 그대로 별도 작업 경로에 추출한다.
4. 각 이미지의 해상도, 색상 형식, 알파 채널과 실제 표시 내용을 확인한다.
5. 사용자 설명과 일치하는 이미지를 식별하고 미리보기 이미지를 출력한다.
6. 현재 ISO 빌더가 해당 영역을 변경하지 않는지 확인하고, 향후 안전하게 교체할 수 있는 조건을 정리한다.

## 산출물

- 조사·추출 스크립트가 필요하면 `tools/scripts` 아래에 작성한다.
- 추출 이미지는 `tools/patchdata/work/current/097-psp-xmb-images` 아래에 둔다.
- 조사 결과는 `docs/result/097-ys6-psp-xmb-background-image-discovery.md`에 기록한다.

## 안전 조건

- 원본 ISO는 읽기만 하며 직접 수정하지 않는다.
- 이번 단계에서는 이미지 식별과 추출만 수행한다.
- 한글 이미지 제작, ISO 교체 및 GUI 패치 연동은 후보 확인 후 별도 계획으로 진행한다.

## 완료 기준

- PSP XMB에서 보이는 배경과 아이콘 파일을 실제 이미지로 확인한다.
- 각 파일의 ISO 경로와 교체 시 지켜야 할 크기·형식 조건을 문서화한다.
- 사용자가 확인할 수 있는 후보 이미지 파일을 제공한다.
