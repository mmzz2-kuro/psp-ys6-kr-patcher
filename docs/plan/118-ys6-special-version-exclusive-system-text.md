# 118. Ys VI SPECIAL VERSION 전용 시스템 문구 번역 계획

상태: 사용자 확인 대기

## 배경

- 117번에서 일반판 승인 번역과 대응되는 SPECIAL 시스템 메시지 138개를 적용했다.
- 실기 확인 중 `Quick Save` 계열처럼 SPECIAL VERSION에 추가된 영문 시스템 문구가 한글과 섞여 표시되는 것이 확인됐다.
- 실행 파일에서 현재 확인한 관련 문자열은 다음과 같다.
  - `QUICK SAVE` (`0x14715C`)
  - `Quick Save Data` (`0x14B150`)
  - `Quick Save.` (`0x15834C`)
  - `Media Player.` (`0x15838C`)
  - `Priceless` (`0x158644`)
  - `Sell Price` (`0x158674`)
- `Quick Kill After Appearing`처럼 사용자용 문구가 아닐 가능성이 높은 내부 문자열도 있으므로 영문 전체를 일괄 교체하면 안 된다.
- 117번 작업공간에는 아직 일본어 상태로 남은 SPECIAL 전용·미대응 후보 194개가 있다.

## 목적

- SPECIAL VERSION에서 실제 화면에 표시되는 전용 영문·일본어 시스템 문구를 전수 조사한다.
- 사용자 표시 문구와 내부 디버그·개발 문자열을 구분한다.
- 검수한 전용 문구만 번역해 기존 117번 시스템 패치에 추가한다.
- GUI 사전 검증과 테스트 ISO에서 동일한 적용 결과를 사용한다.

## 작업 범위

### 1. 영문 시스템 문자열 추출 확장

- 기존 일본어 판정 외에 NUL 종료 ASCII 문자열을 별도 추출한다.
- 실행 파일의 읽기 전용 데이터 영역, 문자열 길이, 주변 참조 및 인접 메뉴 문자열을 근거로 후보를 분류한다.
- `Quick Save`, `Media Player`, 가격 관련 표기 등 사용자 표시 가능성이 높은 항목을 우선한다.
- 함수명, 디버그 문구, 개발용 상태명 및 파일 경로는 적용 대상에서 제외한다.

### 2. 일본어 미대응 후보 재분류

- 117번의 미번역 194개를 다음으로 나눈다.
  - SPECIAL 전용 사용자 표시 문구
  - 일반판과 문구가 달라 자동 대응되지 않은 항목
  - 저장·불러오기 및 메모리스틱 관련 문구
  - 내부·미사용·판별 보류 문구
- 실제 화면과 연결되는 위치, 인접 문자열 및 형식 토큰을 기록한다.

### 3. 번역 작업공간 작성

- 영문·일본어 원문, 오프셋, 원시 바이트, 할당 크기 및 번역을 기록한다.
- 우선 용어는 다음과 같이 통일한다.
  - `Quick Save` / `QUICK SAVE`: `빠른 저장`
  - `Quick Save Data`: `빠른 저장 데이터`
  - `Media Player`: `미디어 플레이어`
- `Priceless`, `Sell Price` 등은 실제 화면 문맥을 확인한 뒤 자연스러운 게임 용어로 확정한다.
- 고정 길이에 맞지 않으면 문구 축약안을 기록하고 임의로 주변 데이터를 이동하지 않는다.

### 4. 시스템 별칭 및 길이 검증

- 신규 번역에 필요한 글자는 117번 시스템 전용 별칭 자산에 추가한다.
- 기존 45개 별칭과 공용 revision 7 매핑은 변경·재배정하지 않는다.
- 별칭 대상 일본어 글리프가 잔존 사용자 문구에서 사용되지 않는지 다시 감사한다.
- 형식 토큰, 개행, 제어 바이트, NUL 종료 및 할당 크기를 검증한다.

### 5. 빌더·GUI 통합 및 ISO 검증

- SPECIAL 공용 빌더가 117번 승인 문구와 118번 전용 문구를 함께 적용하게 한다.
- GUI 사전 검증에 전용 문구 적용 수와 제외·보류 수를 표시한다.
- BOOT.BIN과 EBOOT.BIN에 같은 결과를 적용한다.
- 기존 대사 6,156개, 인물명 70개, 아이템 72개 및 시스템 메시지 138개를 회귀 검증한다.
- `/patched/118-ys6-special-version-exclusive-system-text`에 테스트 ISO를 생성한다.

## 제외 범위

- 익명 화자명 적용
- 이미지·영상·음성 자산 변경
- 내부 디버그 문자열의 번역
- 기존 한글 매핑과 시스템 별칭의 재배정
- 사용자 확인 전 배포 패치 데이터 및 ISO 변경

## 안전 조건과 중단 기준

- 원본 ISO는 직접 수정하지 않는다.
- 대상 원문 바이트와 오프셋이 다르면 빌드를 중단한다.
- 사용자 표시 여부를 확인하지 못한 영문·일본어 문자열은 자동 적용하지 않는다.
- 길이 초과, 토큰 불일치 또는 별칭 충돌 항목은 제외한다.
- 기존 117번 한글 출력이 회귀하면 118번 전체 적용을 중단한다.

## 완료 기준

- SPECIAL 전용 사용자 표시 영문·일본어 문구 목록이 확정된다.
- 검수된 문구가 고정 길이와 인코딩 검증을 통과한다.
- GUI 사전 검증과 ISO 빌드가 같은 적용 수를 보고한다.
- 테스트 ISO에서 `Quick Save` 계열과 대표 전용 문구가 한글로 표시된다.
- 결과 문서에 적용·제외·보류 항목과 검증 결과가 기록된다.
