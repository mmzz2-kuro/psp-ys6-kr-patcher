# 105. Ys VI SPECIAL VERSION 확인용 대사 한글 글리프 테스트 계획

상태: 완료

## 목적

- 103번 테스트보다 접근하기 쉬운 이샤 대사 화면에서 SPECIAL VERSION의 한글 글리프 출력을 확인한다.
- 사용자가 제시한 `なんだか…… 風がざわめいた気がして……` 문장에서 한자를 한글 글리프로 바꿔 즉시 식별할 수 있게 한다.
- 이 시험으로 SPECIAL VERSION의 평문 ELF 적용과 16×14 한글 폰트 렌더링이 실제 게임 화면에서 작동하는지 판단한다.

## 시험 방식

- 외부 XSO 대사 데이터는 변경하지 않는다.
- SPECIAL VERSION 내장 폰트에서 다음 두 기존 한자 글리프의 비트맵만 시험용 한글로 교체한다.
  - `風` (`0x9597`) → `한`
  - `気` (`0x8B43`) → `글`
- 원문 대사는 그대로 유지되지만 화면에서는 해당 부분이 `한がざわめいた글がして……`처럼 표시된다.
- 두 한자는 제시된 화면에 동시에 나타나므로 한글 출력 여부와 기준선·크기를 한 화면에서 확인할 수 있다.

## 확인된 위치

- SPECIAL VERSION 폰트 테이블: `0x15EB2A`
- 셀 규격: 16×14, 레코드 크기 30바이트
- `風` 폰트 인덱스: 1,493
  - 레코드 위치: `0x169A20`
  - 비트맵 위치: `0x169A22`
- `気` 폰트 인덱스: 554
  - 레코드 위치: `0x162C16`
  - 비트맵 위치: `0x162C18`

## 구현

1. 103번 전용 스크립트를 확장하거나 105번 시험 프로필을 추가한다.
2. 원본 `BOOT.BIN`의 두 폰트 코드와 원본 비트맵 위치를 검증한다.
3. 굴림 글꼴로 `한`, `글` 16×14 비트맵을 생성한다.
4. 코드 값은 유지하고 28바이트 비트맵만 각각 교체한다.
5. 수정 `BOOT.BIN`과 기존 크기를 보존한 평문 ELF `EBOOT.BIN`을 만든다.
6. 원본 ISO를 변경하지 않고 별도 테스트 ISO를 생성한다.

## 출력

- 테스트 ISO: `patched/105-special-version-visible-font-test/Ys VI Special Version - 105-visible-hangul-font-test.iso`
- 작업 자료: `tools/patchdata/work/current/105-special-version-visible-font-test`
- 결과 문서: `docs/result/105-ys6-special-version-visible-dialogue-font-test.md`

## 검증

- 입력 ISO, BOOT와 EBOOT SHA-256을 검증한다.
- 변경 범위가 `風`, `気`의 비트맵 영역으로 제한되는지 확인한다.
- 글리프 코드와 실행 코드 및 외부 대사 파일이 변경되지 않았음을 확인한다.
- 생성한 한글 글리프를 확대 이미지로 출력해 셀 경계를 확인한다.
- ISO에서 BOOT와 EBOOT를 재추출해 작업본과 바이트 단위로 비교한다.
- ISO 허용 범위 밖 변경이 없는지 확인한다.

## 사용자 확인 항목

1. 제시한 이샤 대사 장면으로 이동한다.
2. `風` 위치에 `한`, `気` 위치에 `글`이 표시되는지 확인한다.
3. 글자가 잘리거나 다른 높이로 표시되지 않는지 확인한다.
4. 해당 대사 전후 진행과 게임 동작이 정상인지 확인한다.

## 주의 사항

- `風`과 `気`는 일반적으로 사용되는 한자이므로 테스트 ISO의 다른 일본어 문장에서도 각각 `한`, `글`로 표시될 수 있다.
- 이는 폰트 출력 검증을 위한 의도된 전역 변경이며 완성 패치 방식은 아니다.
- 한글 출력이 확인되면 후속 정식 이식에서는 사용량을 분석한 안전 슬롯과 한글 전용 매핑을 사용한다.
- 103번 테스트 ISO와 원본 SPECIAL VERSION ISO는 변경하지 않는다.

## 완료 기준

- 접근하기 쉬운 이샤 대사에서 확인 가능한 별도 테스트 ISO가 생성된다.
- 두 한글 글리프와 ISO 실행 파일의 변경 범위가 검증된다.
- 사용자가 실제 화면에서 폰트 출력 여부를 판단할 수 있는 명확한 확인 지점이 제공된다.
