# 064. Ys VI 상점 선택 이미지 분할 수정 계획

## 상태

- 완료 (2026-08-21)

## 문제

- `shop_choice`의 현재 원본 조각은 256×128 이미지를 256×32 크기 네 줄로
  단순 분할한다.
- 실제 텍스처는 장식 프레임 안에 질문 문구와 구매·판매·그만두기 버튼이 서로
  다른 좌표로 배치된 아틀라스다.
- 현재 조각에는 불필요한 프레임과 인접 UI가 섞이고 `売る`와 `やめる`가 분할
  경계에 걸려 정상적인 독립 편집이 어렵다.

## 확인 사항

- `shop_choice.block_offset: 1`은 현재 정상 적용된 값으로 유지한다.
- 사용자 확인을 거쳐 다음 좌표를 최종 후보로 확정했다.

| 조각 | 원문 | 좌표 | 크기 |
|---|---|---|---:|
| `line_01` | `どうしますか？` | `(44, 8)–(160, 36)` | 116×28 |
| `line_02` | `買う` | `(68, 32)–(136, 60)` | 68×28 |
| `line_03` | `売る` | `(68, 60)–(136, 88)` | 68×28 |
| `line_04` | `やめる` | `(68, 88)–(136, 116)` | 68×28 |

- 질문 영역은 최초 후보보다 아래쪽을 4픽셀 확장했다.
- 세 버튼은 동일한 68×28 크기로 맞춰 글자와 버튼 테두리가 잘리지 않는다.
- 모든 좌표와 크기는 4×4 DXT 블록 경계에 정렬돼 있다.

## 목표

- `source_parts/shop_choice`를 실제 질문과 버튼 위치에 맞는 네 조각으로 다시
  생성한다.
- GUI에서 네 조각을 독립적으로 편집하고 원래 아틀라스 좌표에 정확히 합성한다.
- 편집 영역 밖의 장식 프레임과 미사용 영역은 원본 압축 블록 그대로 유지한다.

## 수정 범위

1. `tools/patchdata/ys6_additional_images/manifest.json`의
   `shop_choice.regions`를 확정 좌표와 크기로 변경한다.
2. `block_offset: 1`과 `source_block_offset_applied: true`는 유지한다.
3. 현재 `source_images/shop-choice.png`에서 다음 파일을 다시 추출한다.
   - `source_parts/shop_choice/line_01.png`: 116×28
   - `source_parts/shop_choice/line_02.png`: 68×28
   - `source_parts/shop_choice/line_03.png`: 68×28
   - `source_parts/shop_choice/line_04.png`: 68×28
4. 향후 `prepare` 재실행에서도 256×32 균등 분할로 돌아가지 않도록 명시적 영역
   정의를 유지한다.
5. 기존 직사각형 영역 합성 경로를 사용하고 `pieces` 확장은 하지 않는다.
6. `edited_parts/shop_choice`에 기존 사용자 파일이 있으면 자동으로 덮어쓰지 않는다.

## 검증

1. 원본 조각 검사
   - 크기가 116×28, 68×28, 68×28, 68×28인지 확인
   - 질문 문구와 세 버튼이 각각 하나씩만 포함되는지 확인
   - 글자와 버튼 테두리가 잘리지 않는지 확인
   - `売る`와 `やめる`가 서로 섞이지 않는지 확인
2. 좌표 검사
   - 네 영역의 좌표와 크기가 모두 4픽셀 정렬인지 확인
   - 버튼 영역이 서로 겹치지 않는지 확인
   - `block_offset: 1` 유지 확인
   - 질문 영역과 구매 버튼 영역의 DXT 블록 범위가 y=32–36에서 겹치므로,
     각 조각을 개별 편집할 때 누적 합성 결과가 보존되는지 확인
3. 격리 편집 검사
   - 임시 작업공간에서 네 조각에 각각 식별 변경 적용
   - 변경 블록이 네 영역 합집합 안에만 존재하는지 확인
   - 장식 프레임과 다른 아틀라스 요소가 바뀌지 않는지 확인
   - 임시 파일 정리 확인
4. GUI 통합 검사
   - 네 편집 이미지 인식
   - 독립 `PSP_GAME/USRDIR/data/menu/shopp0.dds.z` 교체 목록 포함
   - 컨테이너 할당 공간 초과 없음
5. 생성 ISO 재추출 검사
   - 네 편집 결과가 정확한 좌표에 나타나는지 확인
   - 편집 영역 밖 미변경 블록 유지 확인
   - 원본 ISO SHA-256 유지 확인

- 원본 ISO 직접 수정

## 위험 및 대응

- 질문 영역과 구매 버튼 영역은 `(68,32)–(136,36)`에서 겹친다. 두 조각은 같은
  원본에서 추출되며 합성 순서상 구매 조각이 겹친 영역의 최종 픽셀을 결정한다.
  질문 번역은 아래쪽 4픽셀 여백을 침범하지 않도록 검증한다.
- 기존 편집 PNG가 있으면 새 크기와 맞지 않을 수 있으므로 발견 시 자동으로
  덮어쓰지 않고 이전 필요성을 먼저 보고한다.

## 복구 방법

- 매니페스트 영역과 네 원본 조각을 이전 256×32 분할로 복원하면 063 상태로
  돌아간다.
- 별도 064 테스트 ISO만 생성하며 원본 ISO는 수정하지 않는다.
