# 093. Ys VI 엔딩 영상 대사·타임코드 추출 계획

상태: 완료

## 목적

- `im03a_kaizoku.pmf`와 `im03b_kazaminooka.pmf`의 PC판 대화 장면을 프레임 단위로 분석한다.
- 각 대화의 인물명, 일본어 원문, 시작·종료 타임코드와 대표 프레임을 목록화한다.
- 현재 한글 번역 데이터에서 동일 원문을 찾아 재사용 가능한 번역을 연결한다.

## 대상

- `PSP_GAME/USRDIR/data/movie/im03a_kaizoku.pmf`
- `PSP_GAME/USRDIR/data/movie/im03b_kazaminooka.pmf`

## 작업 절차

1. 원본 PMF의 정확한 프레임률, 시작 PTS와 총 프레임 수를 기록한다.
2. 대화창이 나타나는 후반 구간을 프레임 PNG로 추출한다.
3. 대화창 본문·인물명 영역의 영상 차이를 기준으로 문장 전환 후보 프레임을 검출한다.
4. 페이드·반투명 전환 프레임을 제외하고 실제 표시 시작·종료 프레임을 확정한다.
5. 각 구간의 가장 선명한 대표 프레임을 저장한다.
6. 대표 프레임에서 인물명과 일본어 대사를 사람이 확인 가능한 크기로 잘라낸다.
7. 일본어 원문을 전사하고 현재 번역 설정·대화 카탈로그에서 동일하거나 유사한 원문을 검색한다.
8. 자동 일치, 유사 일치, 신규 번역 필요 항목을 구분한다.
9. 영상별 시간순 CSV·JSON과 대사 접촉 시트를 생성한다.

## 타임코드 형식

- 시작·종료 프레임 번호
- 시작·종료 PTS
- `HH:MM:SS.mmm` 표시 시간
- 표시 지속 시간
- 원본 29.97fps 기준 프레임 정확도

## 산출물

- `tools/patchdata/work/current/093-ending-movie-dialogue-timeline/im03a_kaizoku-dialogues.csv`
- `tools/patchdata/work/current/093-ending-movie-dialogue-timeline/im03b_kazaminooka-dialogues.csv`
- 통합 JSON 보고서
- 대사별 대표 프레임 및 대화창 잘라낸 이미지
- 영상별 시간순 접촉 시트
- 기존 번역 일치 결과와 신규 번역 필요 목록
- `docs/result/093-ys6-ending-movie-dialogue-timeline-extraction.md`

## 검증

- 각 대화 구간 전후 프레임을 비교해 누락·중복을 확인한다.
- 대화창이 유지되는 동안 중간 애니메이션 변화가 새 대사로 잘못 분류되지 않는지 확인한다.
- 두 영상의 첫 대사부터 마지막 대사까지 시간 순서가 연속적인지 확인한다.
- 원문 일치는 일본어 문자열 완전 일치를 우선하고, 유사 일치는 별도로 표시한다.
- 영상 전체 재생 시간과 마지막 대사 종료 시간이 모순되지 않는지 확인한다.

## 변경 범위

- 필요 시 타임라인 검출·프레임 추출용 비GUI 스크립트를 `tools/scripts`에 추가한다.
- 조사 출력은 `tools/patchdata/work/current/093-ending-movie-dialogue-timeline`에 둔다.
- 이번 단계에서는 영상 프레임 수정, 번역 합성, 재인코딩, PMF 재구성과 ISO 교체를 하지 않는다.

## 보존 사항

- 092번에서 추출한 원본 PMF는 변경하지 않는다.
- 기존 번역 데이터는 읽기 전용으로 대조하며 자동 수정하지 않는다.
- 확신할 수 없는 원문이나 인물명은 추정으로 확정하지 않고 검토 대상으로 남긴다.

## 완료 기준

- 두 영상의 모든 일본어 대화 구간이 프레임 단위 타임라인으로 정리된다.
- 각 항목에 판독 가능한 대표 이미지와 일본어 원문이 연결된다.
- 기존 한글 번역의 재사용 가능 여부가 분류된다.
- 후속 한글 영상 합성에 바로 사용할 수 있는 입력 자료가 준비된다.
