# 106. Ys VI SPECIAL VERSION 안전 한글 폰트 및 1차 대사 이식 계획

상태: 선행 작업 대기

선행 조건: 107번 옵션 메뉴 이미지 캐시 전환과 108번 ULJM-05009 한글 글리프 매핑 고정 완료 후 진행한다.

## 배경

- 100번 조사에서 SPECIAL VERSION으로 구조상 대응 가능한 기존 번역 레코드 1,169개를 확인했다.
  - payload 완전 동일: 205개
  - 코드 구조와 문자열 수 동일: 964개
- 105번 실기 시험에서 SPECIAL VERSION의 16×14 내장 폰트에 삽입한 `한글`이 실제 대사 화면에 정상 표시되는 것을 확인했다.
- 따라서 다음 단계에서는 임시 한자 치환이 아닌 SPECIAL VERSION 전용 안전 문자 매핑을 만들고, 대응이 확실한 대사부터 실제 이식한다.

## 목적

- SPECIAL VERSION의 모든 실제 텍스트 자산을 기준으로 폰트 코드 사용량을 다시 조사한다.
- 기존 일본어 표시를 불필요하게 훼손하지 않는 안전한 한글 글리프 슬롯을 확보한다.
- 자동 대응 신뢰도가 높은 기존 번역 1,169개를 SPECIAL VERSION 전용 작업공간으로 이식한다.
- 전용 한글 폰트와 1차 번역이 포함된 테스트 ISO를 만들어 실기에서 일반 대사 출력을 검증한다.

## 1. SPECIAL VERSION 텍스트 인벤토리 구축

- 다음 위치의 XSO와 문자열 데이터를 모두 수집한다.
  - 독립 `*.xso.z`
  - `data/arc/*.bin` 내부 `*.xso.z`
  - SPECIAL VERSION 실행 파일의 시스템 문자열
  - 인물·아이템 데이터는 이번 단계에서 번역하지 않지만 폰트 코드 사용량에는 포함 가능한 범위에서 반영한다.
- 같은 payload의 독립 파일과 아카이브 복사본을 묶어 실제 런타임 관계를 기록한다.
- SPECIAL VERSION 전용 대사 카탈로그와 런타임 아카이브 맵을 생성한다.

## 2. 안전 폰트 슬롯 산출

- SPECIAL VERSION 폰트 테이블 1,771개 코드를 기준으로 전체 텍스트 사용량을 집계한다.
- 다음 슬롯은 한글 후보에서 제외한다.
  - 실행 파일 또는 XSO에서 실제 사용되는 코드
  - 제어 코드와 UI 기호
  - 파일명, 아이템명 및 기타 아직 완전히 조사되지 않은 구조에서 충돌 가능성이 높은 코드
  - 코드 중복 또는 폰트 검색 순서를 깨뜨릴 수 있는 슬롯
- 안전 슬롯 수와 필요한 한글 고유 문자 수를 비교한다.
- 슬롯이 부족하면 이번 1차 번역에 필요한 문자만 배정하고, 정식 전체 이식을 위한 폰트 확장 또는 동적 매핑은 별도 후속 과제로 분리한다.

## 3. SPECIAL VERSION 전용 문자 매핑과 폰트 빌더

- ULJM-05009의 `seed-mapping.json`과 매핑을 직접 재사용하지 않는다.
- SPECIAL VERSION 전용 다음 자료를 만든다.
  - 폰트 사용량 보고서
  - 안전 슬롯 목록
  - 시험 번역 전용 문자 매핑
  - 16×14 한글 글리프 아틀라스
- 기존 글리프 렌더링 코드는 공통화할 수 있지만 다음 값은 버전 프로필로 분리한다.
  - 폰트 오프셋 `0x15EB2A`
  - 글리프 수 1,771
  - 레코드 크기 30바이트
  - 글리프 크기 16×14
- 105번의 `風`, `気` 전역 치환은 제거하고 안전 슬롯 기반 매핑만 사용한다.

## 4. 1차 대사 자동 이식

- 기존 번역 7,424개 중 100번에서 확인된 다음 레코드를 우선 대상으로 한다.
  - 새 버전 payload가 완전히 동일한 205개
  - 파일명, 코드 구조와 문자열 수가 동일한 964개
- payload 완전 동일 항목은 기존 인덱스와 원문 해시를 다시 확인한 뒤 자동 이식한다.
- 코드 구조 동일 항목은 다음 조건을 모두 만족할 때만 이식한다.
  - SPECIAL VERSION의 대상 파일이 한 후보로 확정됨
  - 문자열 인덱스가 유효함
  - 해당 인덱스의 일본어 원문이 기존 레코드와 일치함
  - 공유 payload 및 런타임 복사본 관계에 충돌이 없음
- 조건을 만족하지 않는 항목은 억지로 포함하지 않고 검토 대기 목록으로 분리한다.
- 기존 번역 상태가 `override`인 항목만 실제 패치 대상으로 사용한다.

## 5. SPECIAL VERSION 전용 빌드 프로필

- 기존 ULJM-05009 빌드 구성과 완전히 분리된 시험용 프로필을 만든다.
- 입력 ISO SHA-256은 SPECIAL VERSION 원본 `C7BFF86BB7AA9DE025B4717BE34516A3E52D88EF8AD9AA3696F048D4ECCAE1A9`로 고정한다.
- 수정 `BOOT.BIN`과 기존 크기를 유지한 평문 ELF `EBOOT.BIN`을 사용한다.
- XSO 재압축과 아카이브 교체에는 기존 `ys6_z`, `ys6_xso`, `ys6_arc`, ISO 패치 로직을 재사용한다.
- 이번 단계에서는 기존 GUI에 SPECIAL VERSION 선택 기능을 추가하지 않고 별도 명령줄 시험 빌더로 유지한다.

## 6. 테스트 ISO

- 출력: `patched/106-special-version-first-dialogue-port/Ys VI Special Version - 106-first-dialogue-port.iso`
- 원본 SPECIAL VERSION ISO는 읽기 전용으로 유지한다.
- 105번의 임시 한자 치환은 포함하지 않는다.
- 1차 대사, 안전 슬롯 한글 폰트와 실행에 필요한 최소 변경만 포함한다.

## 검증

### 데이터 검증

- 모든 입력 ISO·실행 파일·XSO payload의 SHA-256을 기록한다.
- 새 카탈로그의 XSO 수, 런타임 복사본 수와 파싱 실패 항목을 기록한다.
- 1,169개 후보 중 자동 이식 성공, 제외, 충돌 및 원문 불일치 수를 집계한다.
- 같은 SPECIAL VERSION payload와 문자열 인덱스에 서로 다른 번역이 들어가는 공유 payload 충돌을 차단한다.

### 폰트 검증

- 배정된 모든 한글 코드가 안전 슬롯 목록에 있는지 확인한다.
- 사용 중인 일본어 코드와 중복되지 않는지 확인한다.
- 모든 한글 비트맵이 16×14 셀을 넘거나 공백이 아닌지 검사한다.
- 전체 한글 아틀라스를 확대 이미지로 출력한다.

### 빌드 검증

- 수정 EBOOT의 크기, SHA-256과 허용 변경 범위를 검사한다.
- 재구성 XSO를 다시 파싱해 각 번역 바이트가 의도한 인덱스에 들어갔는지 확인한다.
- 아카이브와 독립 런타임 복사본이 모두 교체됐는지 확인한다.
- 할당 공간 초과가 한 건이라도 있으면 ISO 생성을 중단한다.
- 생성 ISO에서 EBOOT 및 표본 XSO를 재추출해 작업본과 비교한다.
- ISO 허용 범위 밖 변경이 없는지 확인한다.

## 사용자 실기 확인 항목

1. SPECIAL VERSION이 정상 부팅되는지 확인한다.
2. 초반부에서 이식된 일반 대사에 한글이 표시되는지 확인한다.
3. 한글 글자의 높이, 기준선, 자간과 잘림을 확인한다.
4. 일본어로 남겨둔 대사의 글리프가 임의로 한글로 바뀌지 않았는지 확인한다.
5. 맵 전환과 같은 대사의 반복 출력 후에도 진행이 정상인지 확인한다.

## 제외 범위

- 자동 대응이 확정되지 않은 나머지 대사 약 6,255개
- 인물·몬스터명, 아이템과 시스템 메시지 번역
- 옵션 메뉴 및 추가 이미지
- 엔딩 영상과 XMB 이미지
- SPECIAL VERSION GUI 정식 지원
- 배포용 완성 패치 생성

## 위험 및 중단 조건

- 안전 슬롯 수가 1차 번역의 고유 한글 수보다 부족하면 전체 1,169개를 억지로 적용하지 않고 가능한 안전 부분집합만 산출한다.
- 코드 구조가 같더라도 원문 또는 인덱스가 일치하지 않으면 자동 이식하지 않는다.
- 새 XSO가 기존 할당 공간을 넘으면 해당 번역을 제외하거나 별도 확장 방식을 후속 계획으로 분리한다.
- 평문 EBOOT, 폰트 테이블 또는 아카이브 검증이 실패하면 테스트 ISO 생성을 중단하고 원인을 결과 문서에 기록한다.

## 완료 기준

- SPECIAL VERSION 전용 XSO 카탈로그와 런타임 맵이 재현 가능하게 생성된다.
- 안전한 한글 슬롯 목록과 16×14 한글 매핑이 검증된다.
- 1,169개 후보의 실제 자동 이식 가능 수와 제외 사유가 확정된다.
- 안전하게 이식된 1차 대사와 한글 폰트를 포함한 테스트 ISO가 생성된다.
- 사용자가 실기에서 일반 대사의 한글 출력과 일본어 글리프 보존 여부를 확인할 수 있다.
