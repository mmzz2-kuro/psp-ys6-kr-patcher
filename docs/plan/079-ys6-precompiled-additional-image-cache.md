# 079. Ys VI 추가 이미지 사전 컴파일 캐시 최적화 계획

상태: 사용자 확인 대기

## 문제

- GUI 사전검증과 ISO 빌드는 현재 수정 PNG를 매번 DXT1/DXT3로 다시 인코딩한다.
- 타블라스 14페이지는 총 112개 MIG 그림과 약 5만 8천 개의 변경 DXT1 블록을 포함한다.
- 고품질 DXT 블록 탐색 인코더가 각 블록의 색상 후보를 반복 평가하므로 사전검증과 빌드에 각각 수분이 걸린다.
- PNG가 바뀌지 않았는데도 동일한 결과물을 매번 다시 계산한다.

## 목표

- 검증된 추가 이미지 결과 컨테이너를 사전 컴파일 캐시로 보관한다.
- GUI 사전검증과 ISO 빌드에서는 입력 해시가 일치하면 DXT 재인코딩을 생략한다.
- PNG 또는 매니페스트가 변경되면 오래된 캐시를 사용하지 않고 자동 재생성하거나 명확히 실패하도록 한다.
- 기존 `추가 이미지 적용` 체크박스 동작과 최종 ISO 결과는 유지한다.

## 1단계: 캐시 형식

각 리소스의 캐시에 다음 정보를 기록한다.

- 리소스 ID와 ISO 경로
- 원본 `.dds.z` SHA-256
- 매니페스트 내 해당 리소스 정의 SHA-256
- 적용된 수정 PNG 목록과 각 SHA-256
- 생성된 패치 `.dds.z` SHA-256 및 크기
- 원본 ISO 할당 공간과 잔여 공간
- 변경 블록 수

예상 경로:

- `tools/patchdata/ys6_additional_images/precompiled/*.dds.z`
- `tools/patchdata/ys6_additional_images/precompiled/manifest.json`

## 2단계: 사전 컴파일 명령

1. 원본 ISO를 입력으로 추가 이미지 리소스를 한 번 인코딩한다.
2. 압축 해제 payload, 이미지 크기, MIG picture 구조 및 할당 공간을 검증한다.
3. 결과 컨테이너와 입력 해시 메타데이터를 `precompiled`에 저장한다.
4. 타블라스 14개뿐 아니라 기존 추가 이미지 리소스도 같은 캐시 형식을 사용할 수 있게 한다.

## 3단계: GUI 빌더 캐시 사용

1. 사전검증 시 현재 매니페스트와 수정 PNG 해시를 캐시 메타데이터와 비교한다.
2. 모두 일치하면 DXT 인코딩 없이 캐시 컨테이너의 압축 해제·크기·할당 공간만 검증한다.
3. ISO 빌드 시 동일한 캐시 컨테이너를 독립 리소스와 런타임 복제본에 바로 적용한다.
4. 캐시가 없거나 입력 해시가 다르면 다음 중 안전한 동작을 적용한다.
   - 개발용 명령: 해당 리소스만 재인코딩하여 캐시 갱신
   - 사용자 GUI: 오래된 캐시임을 명확히 알리고 빌드 중단
5. 체크박스 해제 시 캐시 검사와 적용을 모두 생략한다.

## 4단계: 중복 작업 제거

- 사전검증 직후 같은 입력으로 빌드하면 결과를 다시 계산하지 않는다.
- 리소스별 캐시를 사용해 수정된 PNG가 있는 리소스만 재생성한다.
- 타블라스처럼 런타임 복제본이 없는 독립 리소스는 캐시 파일을 ISO에 한 번만 기록한다.

## 검증

1. 기존 실시간 인코딩 결과와 사전 컴파일 컨테이너 SHA-256 일치
2. 14개 타블라스 컨테이너 압축 해제 및 480×272 재렌더 일치
3. 기존 추가 이미지 런타임 복제본 49개 교체 검증
4. PNG 한 개 변경 시 해당 캐시만 무효화되는지 확인
5. 매니페스트 변경 시 잘못된 캐시 사용 차단 확인
6. `추가 이미지 적용` 체크 해제 시 캐시 미사용 확인
7. 기존 방식과 최적화 방식으로 만든 ISO의 패치 대상 파일 SHA-256 비교
8. 사전검증 및 ISO 빌드 소요 시간 비교

## 예상 변경 파일

- `tools/scripts/ys6_additional_image_patch.py`
- `tools/scripts/ys6_integrated_build.py`
- `tools/scripts/ys6_patch_builder.py`
- 필요 시 GUI 상태·오류 메시지 처리 파일
- `tools/patchdata/ys6_additional_images/precompiled/`
- 캐시 생성 보고서
- `docs/result/079-ys6-precompiled-additional-image-cache.md`

## 보존 사항

- 원본 ISO와 기존 패치 ISO는 수정하지 않는다.
- 캐시 유효성을 해시로 확인하지 못하면 임의로 사용하지 않는다.
- 캐시 도입으로 이미지 품질, DXT 인코더 설정 또는 적용 리소스 범위를 변경하지 않는다.
- 기존 수정 PNG는 정본으로 유지하고 사전 컴파일 파일은 파생 산출물로 취급한다.
- 성능 검증용 ISO가 필요하면 `/patched/079-ys6-precompiled-additional-image-cache/`에 한 개만 생성한다.

## 완료 기준

- 변경되지 않은 추가 이미지의 DXT 재인코딩이 GUI 빌드에서 생략된다.
- 캐시 입력과 결과가 SHA-256으로 검증된다.
- 기존 방식과 동일한 이미지 컨테이너가 ISO에 적용된다.
- 사전검증과 빌드 시간이 유의미하게 단축된다.
- 결과 문서에 변경 파일, 검증 결과와 시간 비교를 기록한다.

## 완료 기록

- 타블라스를 포함한 추가 이미지 리소스 27개를 사전 컴파일했다.
- 입력·결과 SHA-256 검증과 GUI 캐시 적용 경로를 구현했다.
- 사전검증 60.874초, ISO 빌드 87.593초로 단축했다.
- 최적화 전후 ISO SHA-256이 일치함을 확인했다.
- 상세 결과는 `docs/result/079-ys6-precompiled-additional-image-cache.md`에 기록했다.
