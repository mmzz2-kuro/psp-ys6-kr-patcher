# 075. Ys VI 월드맵 한글 가독성 및 일본어 잔존 수정 계획

상태: 완료

## 목적

- 074 월드맵에서 한글을 알아보기 어려운 문제와 일본어 외곽선이 남은 문제를
  수정한다.
- ISO를 반복 생성하기 전에 최종 크기 이미지와 확대 이미지를 먼저 출력해 사용자
  확인을 받는다.

## 확인된 원인

1. 074에서 사용한 굴림 7px 글꼴은 `320x240` 게임 화면에서 획이 뭉개져 읽기 어렵다.
2. 일본어 제거 영역이 글자의 밝은 본문 위주로 잡혀 어두운 외곽선과 그림자 일부가
   남았다.
3. 하단 지역명은 공간이 좁아 단순히 글꼴만 키우면 서로 겹칠 수 있다.

## 수정 방향

1. 일본어 지명 13개의 제거 영역을 외곽선과 그림자까지 포함하도록 다시 확장한다.
2. 원본 지도·영문·빨간 위치 표식과 겹치지 않도록 영역을 개별 조정한다.
3. 한글은 굵은 고딕 계열 9px을 기본으로 사용하고, 긴 지명만 8px 또는 두 줄 배치를
   적용한다.
4. 흰색 본문과 1px 검은 외곽선을 사용하며 빨간 원문이었던 두 지명은 빨간색을
   유지한다.
5. 좁은 하단 영역은 다음과 같이 분리한다.
   - `레다마을`, `기도의 샘`, `달의 해변`의 기준점과 줄 높이를 서로 겹치지 않게 조정
   - `쿠아테라의 수해`, `바람개비언덕`, `다리`도 각 위치 표식과 분리
6. `imagegen` 배경 제거 결과는 보조 참고로만 사용하고 최종 지도 전체에는 사용하지
   않는다.

## 단계별 진행

### 1단계: 이미지 재제작 및 미리보기

- 수정 스크립트의 제거 마스크, 글꼴 크기와 좌표를 갱신한다.
- 다음 두 미리보기를 출력한다.
  - 실제 게임 크기 `320x240`
  - 최근접 확대 `1280x960`
- 일본어 잔존, 한글 판독성, 겹침 및 표식 보존을 확인한다.
- 이 단계에서는 ISO를 생성하지 않는다.

### 2단계: 사용자 확인 후 ISO 적용

- 사용자가 미리보기를 확인한 뒤에만 사전 검증과 075 ISO 빌드를 실행한다.
- 출력 ISO에서 월드맵을 다시 추출·렌더링하고 미리보기와 비교한다.

## 고정 표기

- 그라나바리스
- 태양의 후미
- 카난평원
- 녹수동
- 제메스의 성지
- 항구도시 리모쥬
- 해안길
- 바람개비언덕
- 쿠아테라의 수해
- 다리
- 기도의 샘
- 레다마을
- 달의 해변

영문 표기는 원본 그대로 유지한다.

## 검증

1. 일본어 본문·외곽선·그림자 잔존 여부
2. 실제 `320x240` 크기에서 13개 한글을 판독할 수 있는지 확인
3. 글자끼리 또는 빨간 위치 표식과 겹치지 않는지 확인
4. 글자 제거 영역 밖 원본 픽셀과 알파 채널 보존
5. 사용자 미리보기 승인 후 DXT1 변경 블록, 할당 공간 및 ISO 내부 렌더링 검증

## 보존 사항

- 원본 월드맵과 영문 표기는 수정하지 않는다.
- 매니페스트 좌표와 블록 오프셋은 변경하지 않는다.
- 사용자 확인 전에는 075 ISO를 생성하지 않는다.
- 기존 073·074 ISO는 덮어쓰지 않는다.

## 완료 기준

- 실제 크기에서 한글 13개를 읽을 수 있고 일본어 흔적이 남지 않는다.
- 사용자 미리보기 확인 후 새 ISO가 생성된다.
- ISO 내부 재렌더링 결과가 승인된 미리보기와 일치한다.
- 결과 문서에 최종 좌표·글꼴·변경 블록과 ISO 해시를 기록한다.
