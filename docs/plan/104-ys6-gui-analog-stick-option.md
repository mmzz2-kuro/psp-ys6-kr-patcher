# 104. Ys VI GUI 아날로그 스틱 패치 옵션 반영 계획

상태: 완료

## 목적

- 102번에서 실기 동작이 확인된 ULJM-05009 아날로그 스틱 패치를 GUI에서 선택해 적용할 수 있게 한다.
- GUI의 사전 검증과 ISO 빌드가 동일한 체크박스 상태를 사용하도록 연결한다.
- 명령줄 빌더의 기존 `--analog-stick` 동작과 GUI 동작을 일치시킨다.

## GUI 변경

- 패치 빌드 영역에 `아날로그 스틱 적용` 체크박스를 추가한다.
- 102번 실기 검증 결과를 반영해 체크박스 기본값은 선택 상태로 둔다.
- 체크 시:
  - 사전 검증에서 아날로그 패치 입력과 8개 원본 명령을 검사한다.
  - ISO 빌드에서 최종 한글 EBOOT에 아날로그 모드 패치를 적용한다.
- 체크 해제 시:
  - 사전 검증과 ISO 빌드 모두 아날로그 패치를 제외한다.
  - 기존 ULJM-05009 디지털 입력 모드 명령을 유지한다.
- 빌드 또는 검증 실행 중에는 다른 패치 옵션과 함께 체크박스를 비활성화한다.

## 상태 표시

- GUI 새로고침 결과에 아날로그 스틱 패치의 `적용` 또는 `제외` 상태를 표시한다.
- 사전 검증 결과와 빌드 manifest에 `analog_stick_patch_enabled` 값을 기록한다.
- 적용 시 8개 명령과 변경 바이트 수를 아날로그 패치 보고서에 기록한다.
- 제외 시 이전 실행에서 남은 아날로그 보고서를 현재 빌드 결과로 오인하지 않도록 정리하거나 manifest 기준으로 무효화한다.

## 구현 대상

- `tools/ys6_dialogue_viewer.py`
- `tools/scripts/ys6_patch_builder.py`
- `tools/scripts/ys6_integrated_build.py`
- 필요한 GUI 및 빌더 검증 코드

102번에서 만든 `tools/scripts/ys6_analog_mode_patch.py`의 검증·패치 함수를 재사용한다.

## 호환성

- 대상은 현재 GUI가 지원하는 `ULJM-05009` 원본 ISO로 제한한다.
- 103번의 `ULJM-05155 SPECIAL VERSION`에는 이 옵션을 적용하지 않는다.
- 아날로그 패치는 102번과 동일하게 8개 모드 전환 명령만 변경한다.
- SPECIAL VERSION의 반경형 데드존 코드는 추가하지 않는다.

## 검증

1. Python 문법 검사를 수행한다.
2. 체크 상태로 입력 검사와 사전 검증을 실행한다.
3. 체크 해제 상태로 입력 검사와 사전 검증을 실행한다.
4. 체크 상태의 EBOOT에서 8개 명령이 모두 `0x24040001`인지 확인한다.
5. 체크 해제 상태의 EBOOT에서 8개 명령이 모두 `0x00002021`인지 확인한다.
6. 두 상태의 preflight 및 build manifest 값이 GUI 선택과 일치하는지 확인한다.
7. GUI 작업 시작·종료 시 체크박스 활성 상태가 다른 패치 옵션과 동일하게 전환되는지 확인한다.
8. 기존 이미지, 영상, XMB 옵션 전달에 회귀가 없는지 확인한다.

전체 ISO를 두 개 만들 필요가 없다면 사전 검증과 EBOOT 산출물 비교로 선택 상태를 검증한다. ISO 검증이 필요하면 기존 원본을 수정하지 않고 `/patched/104-gui-analog-stick-option` 아래에 한 개만 생성한다.

## 완료 기준

- 사용자가 GUI 체크박스로 아날로그 스틱 패치 적용 여부를 선택할 수 있다.
- 선택 상태가 사전 검증과 실제 ISO 패치에 동일하게 전달된다.
- 기본 선택 상태에서 102번과 같은 8개 명령 변경이 적용된다.
- 체크 해제 시 아날로그 관련 변경이 발생하지 않는다.
- 기존 GUI 패치 옵션과 빌드 동작에 회귀가 없다.
