# 092. Ys VI 최종 보스 이후 동영상 탐색·추출 계획

상태: 완료

## 목적

- 최종 보스 클리어 후 재생되는 PC판 플레이 영상의 PSP ISO 내 저장 위치와 형식을 찾는다.
- 원본 영상 스트림을 손상 없이 추출하고 PC에서 확인 가능한 미리보기를 만든다.
- 영상 속 일본어 자막·대사가 영상에 합성된 것인지 별도 자막·오버레이 리소스인지 구분한다.

## 조사 범위

1. ISO9660 파일 목록의 영상 후보
   - `.pmf`, `.mps`, `.pss`, `.mpg`, `.mpeg`, `.avi` 및 대용량 무확장 파일
2. `PSP_GAME/USRDIR/data/arc/*.bin` 내부 대용량 엔트리
3. PMF/PSMF, MPEG Program Stream, H.264·ATRAC 계열 시그니처
4. 엔딩 이벤트와 연결될 가능성이 높은 `s_0002` 및 최종 보스·엔딩 맵 아카이브
5. 영상 프레임에 포함된 일본어 글자와 별도 이미지·대사 리소스의 관계

## 작업 절차

1. 원본 ISO의 전체 파일 크기·확장자 목록을 만든다.
2. 알려진 PSP 영상 매직과 MPEG start code를 기준으로 독립 파일 및 아카이브 payload를 탐색한다.
3. 후보의 컨테이너, 영상 코덱, 음성 코덱, 해상도, 프레임 수와 재생 시간을 판별한다.
4. 원본 컨테이너를 그대로 추출한다.
5. 필요한 경우 FFmpeg로 검사용 MP4 또는 프레임 PNG를 생성한다.
6. 최종 보스 이후 영상인지 대표 프레임 접촉 시트로 확인한다.
7. 일본어가 영상 프레임에 박혀 있는지, 별도 텍스트·이미지로 겹쳐지는지 판정한다.
8. 향후 한글화 가능 방식과 재삽입 시 크기·코덱 제약을 정리한다.

## 산출물

- 영상 후보 목록과 ISO/아카이브 위치
- 원본 영상 추출본
- 재생 확인용 MP4 또는 대표 프레임 접촉 시트
- 코덱·해상도·재생 시간·용량 보고서
- 자막·대사 합성 여부 및 한글화 권장 방식
- `docs/result/092-ys6-ending-movie-discovery-and-extraction.md`

## 변경 범위

- 필요 시 탐색·추출용 비GUI 스크립트를 `tools/scripts`에 추가한다.
- 조사 출력은 `tools/patchdata/work/current/092-ending-movie-discovery`에 둔다.
- 이번 단계에서는 영상 번역, 재인코딩 패치, 매니페스트 등록과 ISO 적용을 하지 않는다.

## 보존 사항

- 원본 ISO와 기존 패치 ISO를 수정하지 않는다.
- 원본 영상은 재인코딩하지 않은 추출본을 별도로 보존한다.
- FFmpeg 변환본은 확인용 파생 파일로 구분한다.

## 완료 기준

- 최종 보스 이후 영상 리소스의 위치와 형식을 확정한다.
- 원본 스트림을 추출해 재생 또는 프레임 확인에 성공한다.
- 영상 속 일본어를 한글화할 수 있는 현실적인 후속 작업 방식을 제시한다.
