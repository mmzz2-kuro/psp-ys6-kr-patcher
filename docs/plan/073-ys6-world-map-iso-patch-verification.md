# 073. Ys VI 월드맵 이미지 ISO 패치 및 검증 계획

상태: 완료

## 목적

- 072에서 만든 월드맵 한글 이미지가 실제 게임 ISO의 월드맵 리소스에 반영되도록
  통합 패치를 다시 생성한다.
- 단순히 빌드 성공 여부만 확인하지 않고 출력 ISO에서 `map.dds.z`를 다시 읽어 한글
  이미지가 들어갔는지 검증한다.

## 현재 확인 사항

- 수정 이미지 `edited_parts/world_map/line_01.png`은 추가 이미지 입력 목록에서
  정상 인식된다.
- 월드맵 리소스는 독립 파일
  `PSP_GAME/USRDIR/data/menu/map.dds.z`이며 런타임 아카이브 복사본은 없다.
- 현재 `roms/Ys VI - Korean Patched.iso`의 `map.dds.z`는 원본과 해시가 다르지만,
  이것만으로 072 한글 이미지가 반영됐다고 판단할 수 없으므로 새 출력물을 격리해
  검증한다.
- 원본 후보 `roms/Ys VI - Napishtim no Hako (Japan).iso`의 SHA-256은 빌더가 요구하는
  원본 해시와 일치한다.

## 작업 범위

1. 현재 번역 작업공간과 모든 활성화된 이미지 패치에 대해 사전 검증을 실행한다.
2. 원본 ISO를 입력으로 사용하고 기존 ISO를 덮어쓰지 않은 채 다음 위치에 새 ISO를
   생성한다.
   - `patched/073-world-map-iso-patch-verification/`
3. 빌드 보고서에서 `world_map`의 적용 region과 변경 블록 수를 확인한다.
4. 출력 ISO에서 `PSP_GAME/USRDIR/data/menu/map.dds.z`를 다시 추출·압축 해제하고
   논리 화면 순서로 렌더링한다.
5. 렌더링 결과를 `320x240` PNG로 저장해 072 수정본과 함께 육안 검토할 수 있게 한다.
6. 출력 ISO의 리소스 해시가 원본과 달라졌고, 빌드 중 생성된 월드맵 컨테이너와
   바이트 단위로 같은지 확인한다.

## 검증

1. 사전 검증과 ISO 통합 빌드 성공 여부
2. `world_map/line_01.png` 입력 인식 여부
3. 월드맵 적용 region이 `line_01`인지 확인
4. 변경 블록 수가 0보다 큰지 확인
5. 출력 ISO 내부 `map.dds.z`와 빌드 산출 컨테이너의 동일성 확인
6. 출력 ISO에서 다시 렌더링한 이미지의 한글 표기와 배치 확인

## 변경 및 생성 대상

- `patched/073-world-map-iso-patch-verification/` 아래의 패치 ISO 및 검증 이미지
- 통합 빌드 작업 산출물과 검증 보고서
- `docs/result/073-ys6-world-map-iso-patch-verification.md`

## 보존 사항

- 원본 ISO와 기존 `roms/Ys VI - Korean Patched.iso`는 덮어쓰지 않는다.
- 월드맵 매니페스트의 좌표와 `block_offset`은 변경하지 않는다.
- 072 한글 이미지는 이번 단계에서 다시 생성하거나 수정하지 않는다.
- 검증 결과 좌표 또는 블록 순서 문제가 확인되면 즉시 임의 변경하지 않고 원인을
  기록한 뒤 계획을 갱신한다.

## 완료 기준

- 새 ISO가 격리된 073 폴더에 생성된다.
- 출력 ISO 내부 월드맵 컨테이너가 빌드 산출물과 일치한다.
- 출력 ISO에서 렌더링한 월드맵에 072 한글 이미지가 표시된다.
- 결과 문서에 ISO 해시, 리소스 해시, 변경 블록 수 및 검증 이미지 경로를 기록한다.
