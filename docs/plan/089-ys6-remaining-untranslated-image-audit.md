# 089. Ys VI 잔여 미번역 이미지 전수 점검 계획

상태: 완료

## 목적

- 원본 ISO의 화면 표시 이미지 중 일본어 문자가 남아 있는 리소스를 전수 점검한다.
- 현재 추가 이미지 패치 46개 및 옵션 메뉴 이미지에서 이미 번역된 항목은 제외한다.
- 이벤트 전용 이미지, 컬렉션 내부 그림, 실행 아카이브에만 있거나 독립 원본과 다른 이미지까지 확인한다.
- 발견 항목별 실제 실행 위치와 번역 우선순위를 정리한다.

## 현재 기준

- 기존 이미지 인벤토리: 1,170개 이미지 레코드, 렌더링 880개
- 현재 추가 이미지 캐시: 46개 리소스
- 이미 처리된 주요 범위:
  - 저장·상점·아이템·검 강화 관련 UI
  - 지역명과 월드맵
  - 보스명
  - 타블라스 설명
  - 제메스 석상 `v100`~`v108`
  - 제어 키·나피쉬팀 메시지 `v140`, `v141`, `v150`~`v157`
  - 옵션 메뉴 이미지

## 점검 범위

1. `PSP_GAME/USRDIR/data/image/*.dds.z`
2. `PSP_GAME/USRDIR/data/menu/*.dds.z`
3. `PSP_GAME/USRDIR/data/title/*.dds.z`
4. `PSP_GAME/USRDIR/data/arc/*.bin` 내부 이미지 엔트리
5. 다중 picture를 가진 MIG 컬렉션
6. 독립 원본이 없거나 독립 원본과 payload가 다른 실행 전용 이미지

## 조사 절차

1. 기존 이미지 인벤토리를 현재 원본 ISO 기준으로 재검증한다.
2. 현재 추가 이미지 매니페스트의 ISO 경로와 picture 인덱스를 처리 완료 목록으로 만든다.
3. 파일명과 번호 계열을 기준으로 아직 확인하지 않은 후보를 분류한다.
   - `v*.dds.z` 이벤트 메시지
   - `t*.dds.z` 이벤트·연출 텍스처
   - 메뉴 및 시스템 UI 텍스트
   - 엔딩·타이틀·도움말 이미지
4. 접촉 시트를 시각적으로 확인해 일본어 글자가 보이는 후보를 표시한다.
5. 단색·투명 배경 때문에 접촉 시트에서 놓치기 쉬운 작은 이미지도 확대 미리보기로 확인한다.
6. 후보마다 독립 원본과 실행 아카이브 복제본을 찾는다.
7. 동일 payload의 중복은 하나의 번역 리소스로 묶고 실제 교체 대상 수를 별도로 기록한다.
8. 이미지처럼 보이지만 실제로는 런타임 글꼴 조합인 항목은 별도 분류한다.
9. 현재 패치 ISO 또는 캐시와 대조해 이미 한글화된 항목을 중복 보고하지 않는다.

## 후보 분류

- `confirmed_untranslated`: 일본어 문자가 명확하고 게임에서 표시될 가능성이 확인됨
- `likely_untranslated`: 일본어 문자는 있으나 실제 실행 경로 확인이 더 필요함
- `already_localized`: 현재 패치에 등록되거나 옵션 메뉴 패치로 처리됨
- `non_text`: 문자처럼 보이지만 장식·아이콘·배경임
- `english_keep`: 영어이므로 기존 방침에 따라 유지
- `unused_or_unknown`: 실제 참조 여부가 확인되지 않음

## 검증

- 모든 후보에 원본 PNG 또는 확대 미리보기를 제공한다.
- 일본어 판독 내용과 파일 경로를 함께 기록한다.
- 실행 복제본이 있으면 아카이브 경로·인덱스·flags·해시를 확인한다.
- 현재 매니페스트 46개와 중복되지 않는지 확인한다.
- 전체 인벤토리의 각 텍스트 후보가 어떤 분류에 들어갔는지 기록한다.
- 자동 문자 판정만으로 확정하지 않고 최종 이미지를 시각적으로 확인한다.

## 산출물

- 잔여 미번역 이미지 목록
- 후보별 원문, ISO 경로, 크기, picture 인덱스와 실행 복제본
- 우선순위별 접촉 시트 또는 개별 미리보기
- 이미 처리됨·영어 유지·미사용 후보 분류표
- 후속 번역 이미지 패치 권장 묶음
- `docs/result/089-ys6-remaining-untranslated-image-audit.md`

## 변경 범위

- 필요 시 조사·분류 스크립트를 `tools/scripts`에 추가한다.
- 조사 출력은 `tools/patchdata/work/current/089-untranslated-image-audit` 또는 안정적인 원본 조사 폴더에 둔다.
- 이번 단계에서는 번역 이미지를 생성하거나 추가 이미지 매니페스트·캐시·ISO를 변경하지 않는다.

## 보존 사항

- 원본 ISO와 기존 테스트 ISO를 수정하지 않는다.
- 현재 편집 PNG와 추가 이미지 캐시를 변경하지 않는다.
- 영어로 된 부분은 기존 방침대로 번역 대상으로 잡지 않는다.
- 실제 표시 여부가 불명확한 후보는 미번역 확정 항목과 구분한다.

## 완료 기준

- 원본 ISO의 렌더링 가능한 이미지 범위를 다시 점검한다.
- 현재 패치에서 누락된 일본어 이미지 후보를 목록화한다.
- 각 확정 후보의 실제 실행 경로와 번역 우선순위를 제시한다.
- 사용자가 다음 번역 작업 대상을 미리보기로 선택할 수 있게 한다.
