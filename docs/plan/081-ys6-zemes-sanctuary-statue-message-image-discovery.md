# 081. Ys VI 제메스의 성지 석상 메시지 이미지 탐색 계획

상태: 사용자 확인 대기

## 목적

- 제메스의 성지 석상 이벤트에서 화면 중앙에 표시되는 일본어 메시지의 원본 리소스를 찾는다.
- 일반 대사 문자열인지, 이미지 텍스처인지, 글꼴 조합형 특수 메시지인지 형식을 확정한다.
- 번역 이미지 제작과 ISO 패치에 필요한 파일 경로, 좌표, 크기 및 재삽입 방식을 정리한다.

## 화면 기준 문구

제공된 화면에서 다음 문구를 기준 표식으로 사용한다.

- `我が名はアルマ……`
- `大いなる《匣》を封印せし者……`

문자 판독 결과는 탐색 키로만 사용하며, 실제 바이너리와 이미지 후보를 대조해 확정한다.

## 조사 절차

1. 기존 대사·시스템 메시지 작업공간에서 해당 일본어 문자열과 유사 문구를 검색한다.
2. 문자열이 없으면 원본 ISO와 추출 리소스에서 Shift-JIS, UTF 계열 및 프로젝트 고유 인코딩 형태를 검색한다.
3. 기존 추가 이미지 조사 도구와 매니페스트를 이용해 미등록 `.dds.z` 및 이미지 컨테이너 후보를 추린다.
4. 후보 이미지를 PNG 또는 접합 미리보기로 출력한다.
5. 제공된 화면과 글자 모양, 행 배치, 투명 배경 및 크기를 비교한다.
6. 이미지가 여러 조각으로 저장됐다면 조각 좌표와 결합 순서를 확인한다.
7. 동일 이벤트에 이어지는 다른 석상 메시지 이미지가 있는지 인접 리소스와 연속 번호를 함께 조사한다.
8. 번역·재삽입에 필요한 매니페스트 항목과 패치 적용 범위를 제안한다.

## 산출물

- 확인된 ISO 내부 파일 경로 또는 아카이브 위치
- 리소스 ID와 원본 SHA-256
- 원본 메시지 이미지 및 확인용 미리보기
- 이미지 크기, 실제 유효 영역, 조각 배치 정보
- 관련 메시지 이미지의 전체 후보 목록
- 후속 번역·패치 계획에 필요한 적용 방식

## 검증

- 제공된 화면 문구와 후보 이미지가 픽셀 형태 및 행 배치상 일치하는지 확인한다.
- 후보 컨테이너를 다시 디코딩했을 때 손상 없이 출력되는지 확인한다.
- 기존 추가 이미지 리소스와 중복 등록되지 않았는지 확인한다.
- 단일 화면만 찾고 끝내지 않고 동일 계열의 인접 메시지를 함께 점검한다.

## 변경 범위

- 조사용 스크립트가 필요하면 `tools/scripts`에 추가한다.
- 확인용 출력 이미지는 `tools/patchdata/ys6_additional_images/source_images` 또는 별도 조사 하위 폴더에 둔다.
- 이번 단계에서는 번역 이미지 제작이나 ISO 패치를 수행하지 않는다.
- 조사 완료 후 `docs/result/081-ys6-zemes-sanctuary-statue-message-image-discovery.md`에 결과를 기록한다.

## 보존 사항

- 원본 ISO와 기존 패치 ISO는 수정하지 않는다.
- 기존 이미지 블록 오프셋과 매니페스트는 후보가 확정되기 전 변경하지 않는다.
- 대량 추출 임시 파일은 위치와 용도를 기록하고 결과 문서에서 정리 대상을 명시한다.

## 완료 기준

- 화면에 나온 석상 메시지의 실제 데이터 위치와 저장 형식을 확정한다.
- 번역 대상으로 묶어야 할 동일 계열 이미지 수를 파악한다.
- 사용자가 확인할 수 있는 원본 또는 접합 미리보기를 출력한다.
- 다음 번역·재삽입 작업에 필요한 좌표와 패치 방식을 제시한다.
