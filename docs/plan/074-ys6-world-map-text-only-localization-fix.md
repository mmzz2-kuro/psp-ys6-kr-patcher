# 074. Ys VI 월드맵 글자 영역 한정 현지화 수정 계획

상태: 완료

## 목적

- 072에서 생성형 편집이 지도 전체를 다시 그려 월드맵의 모든 DXT1 블록이 변경된
  문제를 바로잡는다.
- 원본 월드맵 픽셀을 보존하고 일본어 글자 주변만 최소한으로 변경한 한글 이미지를
  다시 만든다.
- 새 이미지를 ISO에 적용하고 실제 변경 블록과 ISO 재렌더링 결과를 검증한다.

## 원인 및 수정 방향

- 072 수정본은 원본과 전체 화면에서 차이가 발생해 `320x240` 텍스처의 4,800개
  DXT1 블록이 모두 교체됐다.
- 이번에는 원본 이미지를 최종 합성의 기준으로 사용한다.
- `imagegen`은 일본어 글자 아래의 지도 질감을 복원하는 제한된 편집 보조에만
  사용하고, 생성된 전체 지도는 사용하지 않는다.
- 한글 문구는 정확한 문자열과 좌표를 사용해 별도 글자 레이어로 합성한다.

## 고정 표기

- 그라나바리스
- 태양의 후미
- 카난평원
- 녹수동
- 제메스의 성지
- 항구도시 리모쥬
- 해안길
- 바람개비언덕
- 쿠아테라의 수해
- 다리
- 기도의 샘
- 레다마을
- 달의 해변

영문 지도 제목과 `Canaan`, `Zemeth`, `Quatera`는 원본 픽셀 그대로 유지한다.

## 구현 범위

1. 원본과 072 생성본을 비교하고 일본어 지명 13개의 글자 영역을 각각 정의한다.
2. 각 일본어 글자 영역에서 배경 질감을 복원하되 영역 밖 원본 픽셀은 변경하지
   않는다.
3. 한글 문구를 흰색 계열 글자와 어두운 외곽선으로 원래 지명 위치에 합성한다.
4. 합성 결과를
   `tools/patchdata/ys6_additional_images/edited_parts/world_map/line_01.png`에 교체한다.
5. 원본 대비 변경 픽셀 경계와 변경 DXT1 블록 수를 집계한다.
6. 기존 073 ISO를 덮어쓰지 않고 074 전용 폴더에 새 테스트 ISO를 생성한다.
7. 출력 ISO에서 월드맵을 다시 추출·렌더링해 최종 이미지를 검증한다.

## 검증

1. 최종 PNG 크기 `320x240` 및 원본 불투명 알파 유지
2. 영문 표기와 지도 외곽·섬 윤곽·표식·나침반의 원본 픽셀 보존
3. 한글 13개 문구의 오탈자, 잘림 및 겹침 확인
4. 변경 DXT1 블록 수가 4,800개 전체가 아니며 글자 주변으로 제한되는지 확인
5. 사전 검증과 ISO 빌드 통과
6. ISO 내부 컨테이너와 빌드 산출물의 바이트 단위 일치
7. ISO 재렌더링 이미지에서 월드맵과 한글 지명이 함께 보이는지 확인

## 변경 및 생성 대상

- `tools/patchdata/ys6_additional_images/edited_parts/world_map/line_01.png`
- `tools/scripts/ys6_world_map_localize.py`
- `patched/074-world-map-text-only-localization-fix/` 아래 테스트 ISO와 검증 이미지
- `docs/result/074-ys6-world-map-text-only-localization-fix.md`

## 보존 사항

- `source_parts/world_map/line_01.png` 원본은 변경하지 않는다.
- 매니페스트 좌표와 `block_offset=1`은 변경하지 않는다.
- 기존 073 테스트 ISO와 사용자의 기존 패치 ISO는 덮어쓰지 않는다.
- 월드맵 이외 번역 데이터와 이미지 리소스는 변경하지 않는다.

## 완료 기준

- 원본 지도 기반의 글자 영역 한정 한글 이미지가 생성된다.
- 전체 4,800블록 재작성 문제가 해소된다.
- 새 ISO에서 월드맵 이미지와 한글 지역명이 모두 표시 가능한 형태로 재구성된다.
- 결과 문서에 영역, 변경 블록 수, 출력 ISO·리소스 해시와 검증 결과가 기록된다.
