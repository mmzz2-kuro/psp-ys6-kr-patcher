# 091. Ys VI 엔딩 메시지 v130~v132 한글 이미지 패치 계획

상태: 완료

## 목적

- 엔딩 장면에 표시되는 `v130.dds.z`~`v132.dds.z` 일본어 이미지 문장을 한글화한다.
- 독립 이미지와 실제 실행 아카이브 복제본을 함께 교체한다.
- `p901.dds.z`, `p902.dds.z`는 PS2판 치트 안내이므로 번역 대상에서 제외한다.

## 대상과 권장 번역

| 리소스 | 일본어 원문 | 권장 번역 |
|---|---|---|
| `v130` | `多くの因果を呑み込んできた / 宿業の渦は、もはや無く。` | `수많은 인과를 집어삼켜 온 / 숙업의 소용돌이는 이제 사라지고.` |
| `v131` | `海も、空も、どこまでも青く広がっていた。` | `바다도, 하늘도, 끝없이 푸르게 펼쳐져 있었다.` |
| `v132` | `新たなる世界の幕開け―― / いま再び、アドルの冒険が始まる。` | `새로운 세계의 막이 오르고―― / 지금 다시, 아돌의 모험이 시작된다.` |

## 작업 절차

1. 090번에서 확정한 합성 규칙으로 `v130`~`v132` 원본을 준비한다.
2. 원문의 흰 글자와 어두운 외곽선, 투명 배경 및 중앙 배치를 유지해 한글 이미지를 제작한다.
3. 합성 이미지를 원본 경계 `256+128+64+32`로 다시 분할한다.
4. 각 picture의 선행 16바이트 블록과 원래 압축 형식을 보존해 MIG 컨테이너를 생성한다.
5. 추가 이미지 매니페스트에 세 리소스를 등록한다.
6. 실행 복제본 `s_0002.bin` index 26~28도 동일 컨테이너로 교체하도록 등록한다.
7. GUI 원버튼 이미지 캐시 갱신과 패치 사전 검증을 확인한다.
8. 별도 테스트 ISO를 생성하고 독립 원본·실행 복제본을 재추출해 비교한다.

## 실행 복제본

- `PSP_GAME/USRDIR/data/arc/s_0002.bin`, index 26: `v130.dds.z`
- `PSP_GAME/USRDIR/data/arc/s_0002.bin`, index 27: `v131.dds.z`
- `PSP_GAME/USRDIR/data/arc/s_0002.bin`, index 28: `v132.dds.z`

## 검증

- 세 합성 이미지의 문장 잘림, 조각 경계와 투명도를 시각적으로 확인한다.
- 원본 picture 크기와 압축 형식을 유지한다.
- 사전 컴파일 캐시의 세 컨테이너가 원본 할당 공간 안에 들어가는지 확인한다.
- 테스트 ISO의 독립 원본 3개와 실행 복제본 3개가 캐시 payload와 일치하는지 확인한다.
- 기존 추가 이미지 캐시 항목이 불필요하게 재압축되지 않는지 확인한다.

## 산출물

- `source_parts`와 `edited_parts`의 `ending_message_v130`~`v132`
- 엔딩 메시지 한글 미리보기
- 갱신된 추가 이미지 매니페스트와 사전 컴파일 캐시
- `patched/091-ys6-ending-message-v130-v132-korean-image-patch` 테스트 ISO
- `docs/result/091-ys6-ending-message-v130-v132-korean-image-patch.md`

## 보존 사항

- 원본 ISO는 수정하지 않는다.
- `p901`, `p902`는 매니페스트와 캐시에 추가하지 않는다.
- 기존 번역 이미지와 캐시 항목은 유지한다.

## 완료 기준

- `v130`~`v132` 한글 이미지가 독립 원본과 `s_0002.bin` 실행 복제본에 모두 적용된다.
- GUI 빌드 사전 검증과 테스트 ISO 생성·재추출 검증이 성공한다.
- 결과 문서에 생성 파일, 검증 결과와 테스트 ISO를 기록한다.
