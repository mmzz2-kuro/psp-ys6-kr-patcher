# 088. Ys VI 제어 키·나피쉬팀 메시지 한글 이미지 패치 계획

상태: 완료

## 목적

- 087에서 확인한 `v140`, `v141`, `v150`~`v157` 메시지 이미지 10개를 한글화한다.
- 사용자가 제공한 번역을 원문과 대조해 다듬은 권장 번역을 적용한다.
- 독립 원본과 실행 아카이브 복제본을 함께 교체한다.
- GUI 추가 이미지 적용, 사전 검증, ISO 빌드 및 증분 캐시 갱신 대상에 포함한다.

## 용어 기준

- `アトラス洋`: 아틀라스해
- `気象制御機構`: 기상 제어 기구
- `ナピシュテム`: 나피쉬팀
- `アルマ`: 기존 082 이미지와 통일해 알마
- `エルディーン`: 기존 타블라스 번역과 통일해 엘딘
- `エレシア`: 에레시아
- `力場`: 역장
- `水壁`: 수벽

## 이미지 제작

1. 원본 256×64 RGBA 이미지의 행 수와 유효 영역을 기준으로 배치한다.
2. 기존 `zemes_statue` 이미지와 동일한 굴림 계열 글꼴, 흰색 글자, 검은 외곽선 및 투명 배경을 사용한다.
3. 문구 길이에 따라 글자 크기를 자동 조절하되 256픽셀 폭을 넘지 않게 한다.
4. 한 줄과 두 줄 메시지의 수직 중심을 각각 확인한다.
5. `source_parts`에 원본 10개, `edited_parts`에 한글 이미지 10개를 생성한다.
6. 전체 이미지를 한눈에 확인할 수 있는 미리보기를 생성한다.

## 패치 등록

- 독립 원본:
  - `PSP_GAME/USRDIR/data/image/v140.dds.z`
  - `PSP_GAME/USRDIR/data/image/v141.dds.z`
  - `PSP_GAME/USRDIR/data/image/v150.dds.z` ~ `v157.dds.z`
- 실행 복제본:
  - `v140`, `v141`: `s_7499.bin` 인덱스 107~108
  - `v150`~`v155`: `s_7599.bin` 인덱스 86~91
  - `v156`, `v157`: `s_7599.bin` 인덱스 84~85
- flags와 할당 공간은 087 조사 결과를 그대로 사용한다.
- 추가 이미지 매니페스트에 10개 리소스를 등록한다.
- GUI 증분 캐시 갱신에서 신규 리소스 10개만 압축되는지 확인한다.

## 검증

1. 한글 미리보기의 잘림, 겹침, 배경 및 용어 확인
2. PNG를 DXT3로 재인코딩한 뒤 다시 디코딩해 가독성 확인
3. 컨테이너 10개가 각 원본 할당 공간 안에 들어가는지 확인
4. 증분 캐시 갱신 결과: 기존 36개 재사용, 신규 10개 압축
5. 캐시 상태 `최신`, 전체 46개 확인
6. GUI 공통 빌더 사전 검증 및 캐시 46/46개 사용 확인
7. 독립 원본 10개와 실행 복제본 10개 교체 확인
8. 테스트 ISO 한 개 생성 후 내부 컨테이너 해시 대조
9. 테스트 ISO에서 10개 이미지를 재추출해 최종 미리보기 확인
10. 기존 추가 이미지 36개 회귀 검증

## 예상 변경 파일

- 한글 이미지 생성 스크립트
- `tools/patchdata/ys6_additional_images/manifest.json`
- `source_parts` 및 `edited_parts` 아래 신규 이미지 10개
- 갱신된 `precompiled` 캐시와 매니페스트
- `docs/result/088-ys6-control-key-napishtim-message-korean-image-patch.md`

## 보존 사항

- 원본 ISO를 수정하지 않는다.
- 기존 36개 추가 이미지 리소스 정의와 편집 PNG를 변경하지 않는다.
- 실행 복제본의 확인된 인덱스와 flags 외 다른 아카이브 엔트리를 변경하지 않는다.
- 테스트 ISO는 `/patched/088-ys6-control-key-napishtim-message-korean-image-patch/`에 한 개만 생성한다.
- 캐시 및 ISO 적용은 전체 이미지 미리보기가 정상인 것을 확인한 뒤 진행한다.

## 완료 기준

- 메시지 10개가 승인된 권장 번역으로 제작된다.
- 독립 원본과 실행 복제본이 모두 패치 대상에 포함된다.
- GUI 증분 캐시와 사전 검증에서 전체 46개 리소스가 정상 처리된다.
- 테스트 ISO 내부 해시와 재추출 이미지가 예상 결과와 일치한다.
- 결과 문서에 변경 파일, 압축 크기, 캐시 결과 및 테스트 ISO를 기록한다.
