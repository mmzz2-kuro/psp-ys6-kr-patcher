# 054. Ys VI 시스템 옵션 메뉴 이미지 한글화

## 상태

- 사용자 계획 확인 완료
- 버튼별 원본 PNG 분리 추출 완료
- 사용자 수정 이미지 2개 런타임 적용 확인 완료
- GUI 패치 빌드 자동 연동 완료
- 나머지 이미지 편집 및 최종 검증 진행 중

## 배경

053에서 시스템 설정 화면의 메뉴 문구가 들어 있는 실제 런타임 리소스와 안전한 재삽입 경로를 검증했다.

- 런타임 아카이브: `PSP_GAME/USRDIR/data/arc/init.bin`
- 엔트리: index 29, `static_tex.dds.z`
- 해제 payload의 아틀라스 시작: `0x106130`
- 포맷: PSP DXT1
- 논리 크기: 256×256
- 압축 데이터 크기: 32,768바이트
- 블록 크기: 8바이트
- 블록 인덱스: `block_y * 64 + block_x`

v11 테스트에서 `효과음のボリューム` 위치에 넣은 16×16 마젠타 사각형이 PPSSPP에서 정확히 출력됐다. 이제 진단 표식 대신 실제 한글 메뉴 이미지를 제작하고 GUI 패치 빌드에 연결한다.

## 대상 문구

우선 다음 여섯 문구를 한글화한다.

| 일본어 | 1차 한글안 |
|---|---|
| `BGMのボリューム` | `BGM 음량` |
| `効果音のボリューム` | `효과음 음량` |
| `標準に戻す` | `기본값으로 복원` |
| `キーコンフィグ` | `키 설정` |
| `操作説明` | `조작 설명` |
| `タイトル画面に戻る` | `타이틀 화면으로` |

번역 문구는 미리보기 확인 과정에서 사용자가 수정할 수 있게 구성한다.

## 목표

1. 검증된 DXT1 아틀라스를 정상 PNG로 복원한다.
2. 사용자가 쉽게 편집할 수 있도록 메뉴 버튼을 항목별 독립 PNG로 분리 추출한다.
3. 사용자가 수정한 개별 버튼 PNG를 원래 좌표에 정확히 재합성한다.
4. 변경된 PNG 블록만 PSP DXT1으로 재인코딩한다.
5. 독립 `data/image/static_tex.dds.z`와 `init.bin` 내부 사본에 동일한 결과를 반영한다.
6. 기존 GUI 도구의 패치 빌드 탭에서 수정된 버튼 이미지도 자동 적용한다.
7. PPSSPP에서 선택·비선택 상태와 모든 메뉴 항목을 검증한다.

## 작업 절차

### 1. 원본 아틀라스와 버튼 영역 정의

- 검증된 `static_tex.dds.z`에서 전체 256×256 아틀라스를 무손실 PNG로 추출한다.
- 실제 버튼 경계를 조사해 각 버튼의 좌표와 크기를 JSON에 기록한다.
- 버튼은 일본어 글자만 자르는 것이 아니라 사용자가 바로 편집할 수 있도록 버튼 배경과 글자를 포함한 완전한 사각 영역으로 추출한다.
- 선택·비선택 상태가 아틀라스에 별도 이미지로 존재하면 서로 다른 파일로 분리한다.
- UI 조각이 아틀라스 경계를 넘어 분할 배치된 경우, 논리적으로 이어 붙인 정상 방향의 PNG로 제공하고 재삽입 시 원래 조각 좌표로 되돌린다.
- 비선택 다이얼로그/메시지 창은 오른쪽에 세로 저장된 54×62 조각 4개를 가로로 합친 216×62 PNG로 제공하고, 재삽입 시 다시 4등분한다.
- Yes/No, 볼륨 바, 아이템·장비 이미지 등 대상 밖 영역은 보존한다.

### 2. 버튼별 PNG 분리 추출

- 편집 원본은 `tools/patchdata/ys6_option_menu/source_buttons/`에 둔다.
- 파일명은 용도와 상태를 식별할 수 있게 구성한다. 예:
  - `bgm_volume_normal.png`
  - `bgm_volume_selected.png`
  - `se_volume_normal.png`
  - `se_volume_selected.png`
  - `reset_default_normal.png`
  - `reset_default_selected.png`
- 실제 아틀라스에 선택 상태가 공통 배경 레이어로만 존재한다면 중복 PNG를 만들지 않고, 확인된 구조를 JSON과 안내 문서에 명시한다.
- 각 PNG는 원래 픽셀 크기를 유지하고 리사이즈하지 않는다.
- 전체 아틀라스 PNG와 버튼 위치를 표시한 진단 PNG도 함께 생성해 추출 좌표를 검증한다.

### 3. 사용자 이미지 편집

- 사용자는 분리된 원본 버튼 PNG를 이미지 편집 프로그램에서 직접 한글화한다.
- 수정본은 `tools/patchdata/ys6_option_menu/edited_buttons/`에 원본과 동일한 파일명으로 저장한다.
- 도구는 이미지 크기, 색상 모드와 알파 채널을 검사하고 조건이 맞지 않으면 어떤 파일이 문제인지 알려준다.
- 원본 일본어 제거, 배경 복원, 한글 글꼴·외곽선·그림자 제작은 자동 렌더링의 필수 단계로 두지 않는다. 최종 디자인은 사용자가 편집한 PNG를 정본으로 사용한다.
- 원본 파일은 덮어쓰지 않아 언제든 다시 편집할 수 있게 한다.

### 4. 수정 PNG 재합성 및 사용자 검토

- `edited_buttons`에 존재하는 파일만 전체 아틀라스의 원래 좌표에 합성한다.
- 수정본이 없는 버튼은 원본 픽셀을 그대로 유지한다.
- 분할 배치된 UI 조각은 추출 때 수행한 결합의 역변환으로 정확히 되돌린다.
- 다음 검토 자료를 생성한다.
  - 재합성된 전체 256×256 아틀라스
  - 원본/수정 버튼 나란히 비교한 이미지
  - 변경 픽셀 및 4×4 DXT1 변경 블록을 표시한 차이 이미지
- 사용자가 재합성 결과를 확인하기 전에는 최종 패치 ISO에 포함하지 않는다.

### 5. PSP DXT1 재인코딩

- 재합성된 아틀라스의 변경 영역을 4×4 단위 PSP DXT1 블록으로 인코딩한다.
- 변경 대상 블록만 원본 payload에 덮어쓴다.
- 알파, RGB565 endpoint, color index 순서를 PPSSPP 검증 결과에 맞춘다.
- 편집본을 다시 디코딩한 PNG와 입력 PNG를 비교해 압축 손실 및 경계 번짐을 확인한다.
- 대상 블록 밖 payload 변경이 0바이트인지 검사한다.

### 6. 패치 데이터 및 GUI 연동

- 사용자 편집 데이터는 `/tools/patchdata` 아래에서 관리한다.
- 비GUI 처리기는 `/tools/scripts`에 작성한다.
- 기존 Python GUI에 버튼 이미지 추출, 편집 폴더 열기, 입력 검사, 재합성 미리보기 기능을 연결한다.
- 패치 빌드 탭은 `edited_buttons`의 수정 PNG를 기본으로 읽고, 수정본이 하나도 없으면 메뉴 이미지를 변경하지 않는다.
- 빌드 시 다음 두 사본을 같은 컨테이너로 갱신한다.
  - `PSP_GAME/USRDIR/data/image/static_tex.dds.z`
  - `PSP_GAME/USRDIR/data/arc/init.bin` 내부 `static_tex.dds.z`
- 원본 ISO는 읽기 전용으로 유지하고 결과 ISO만 `/patched` 아래에 생성한다.

### 7. 검증

- 정적 검증:
  - PNG 크기 256×256
  - DXT1 payload 32,768바이트
  - `.z` 재해제 결과 일치
  - standalone과 archive 내부 컨테이너 일치
  - ISO 할당 범위 초과 없음
  - 대상 블록 밖 변경 없음
- PPSSPP 검증:
  - 여섯 문구 정상 출력
  - 선택·비선택 상태 모두 정상
  - 글자 잘림·겹침·과도한 번짐 없음
  - 볼륨 바, 버튼 배경, Yes/No 및 다른 이미지 손상 없음
  - 옵션 화면 진입·조작·종료 정상

## 구현 예정 파일

- 신규 또는 확장: `/tools/scripts/ys6_runtime_static_atlas_marker.py`
  - 진단 표식 전용 이름을 실제 DXT1 편집·삽입 용도에 맞게 분리하거나 공통 모듈화
- 신규: `/tools/scripts/ys6_option_menu_image.py`
  - 아틀라스 추출, 버튼별 PNG 분리, 수정 PNG 검사·재합성, DXT1 선택 블록 인코딩 및 검증
- 변경: `/tools/ys6_dialogue_viewer.py`
  - 패치 빌드 탭에 메뉴 이미지 적용 상태 및 빌드 연동 추가
- 신규: `/tools/patchdata/ys6_option_menu/`
  - 전체 원본 PNG, 버튼 좌표 JSON, `source_buttons`, `edited_buttons`
- 작업 자료: `/.work/ys6-option-menu-korean/`
- 테스트 ISO: `/patched/054-option-menu-korean/`
- 결과 문서: `/docs/result/054-ys6-system-option-menu-image-korean.md`

구현 중 실제 GUI 파일 구성이 다르면 기존 구조를 확인한 뒤 최소 범위로 조정하고 결과 문서에 기록한다.

## 제외 범위

- 시스템 옵션 화면 외 모든 이미지의 일괄 한글화
- 하단 시스템 메시지 번역 수정
- 키 설정 및 조작 설명의 별도 상세 화면 한글화
- 원본에 없는 신규 UI 디자인
- 테스트 완료 전 기존 정식 패치 ISO 덮어쓰기

## ROM 처리

- 원본 ISO는 수정하지 않는다.
- 054 테스트 ISO는 `/patched/054-option-menu-korean/`에 둔다.
- 디자인 검토용 중간 PNG는 `.work`에 두고 최종 적용 데이터만 `tools/patchdata`에 둔다.
- 작업 완료 후 불필요한 테스트 ISO를 결과 문서에 삭제 후보로 기록한다.

## 완료 기준

1. 메뉴 버튼이 편집 가능한 개별 PNG로 정확히 분리 추출된다.
2. 사용자가 수정한 버튼 PNG가 원래 좌표와 크기로 재합성된다.
3. 재합성 결과를 사용자가 확인한다.
4. 수정 아틀라스가 검증된 PSP DXT1으로 재인코딩된다.
5. standalone과 `init.bin` 내부 사본이 동일하게 갱신된다.
6. GUI에서 추출·검사·미리보기가 가능하고 패치 빌드에서 메뉴 이미지가 자동 적용된다.
7. PPSSPP에서 선택·비선택 상태와 메뉴 동작이 정상이다.
8. 결과 문서가 `/docs/result`에 작성된다.
