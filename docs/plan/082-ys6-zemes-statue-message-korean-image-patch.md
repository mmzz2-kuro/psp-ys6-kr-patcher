# 082. Ys VI 제메스의 성지 석상 메시지 한글 이미지 패치 계획

상태: 완료

## 목적

- `v100`~`v108` 석상 메시지 이미지 9개를 자연스러운 한국어로 제작한다.
- 원본 이미지의 투명 배경, 글자 인상, 화면 배치와 표시 순서를 유지한다.
- 독립 이미지와 `s_6600.bin` 내부 실행 복제본을 함께 교체한다.
- GUI의 추가 이미지 체크박스, 사전 검증, 패치 생성 및 이미지 캐시 갱신 흐름에 포함한다.

## 번역 초안

| 리소스 | 번역 초안 |
|---|---|
| `v100` | `……잘 왔도다……` |
| `v101` | `내 이름은 알마…… / 위대한 《상자》를 봉인한 자……` |
| `v102` | `내 육신은 이곳에서 스러질지라도 / 그 혼은 후손들에게 이어지리라……` |
| `v103` | `검사여…… / 머나먼 땅에서 동포들을 구한 자여……` |
| `v104` | `마지막 《열쇠》를 그대에게 맡기리라……` |
| `v105` | `검사여……명심하라……` |
| `v106` | `……빼앗긴 《검은 열쇠》가 / 《상자》의 뚜껑을 열려 하고 있다……` |
| `v107` | `……사악한 꿈이……되살아나기 전에……` |
| `v108` | 원문과 동일한 점 전환 표시 유지 |

게임 내 기존 번역 용어가 따로 있으면 그 표기를 우선한다. 특히 `《匣》`, `《鍵》`, `《黒の鍵》`은 기존 대사·아이템 번역과 대조해 `상자`, `열쇠`, `검은 열쇠` 표기를 확정한다.

## 이미지 제작

1. 원본 256×64 RGBA 이미지를 기준으로 글자 유효 영역과 행 배치를 측정한다.
2. 기존 이미지 번역에 사용한 한글 글꼴과 외곽선·그림자 방식을 재사용한다.
3. 긴 문구는 화면 폭을 넘지 않도록 행별 글자 크기와 자간을 조절한다.
4. 투명 영역의 불필요한 RGB 및 알파 변화를 최소화한다.
5. `edited_parts/zemes_statue_messages`에 편집용 PNG를 생성한다.
6. 전체 9개를 한눈에 확인할 수 있는 미리보기를 출력한다.

## 패치 등록

1. 추가 이미지 매니페스트에 `v100`~`v108` 리소스를 등록한다.
2. 독립 원본 경로 `PSP_GAME/USRDIR/data/image/v1xx.dds.z`를 교체한다.
3. `v100`~`v107`은 `PSP_GAME/USRDIR/data/arc/s_6600.bin`의 인덱스 143~150 복제본도 교체한다.
4. `v108`은 실행 참조 경로를 추가 조사해 실제 참조되는 위치만 안전하게 교체한다.
5. 기존 추가 이미지 패치의 할당 공간 검사와 압축 컨테이너 검증을 적용한다.
6. GUI `추가 이미지 적용` 체크 시 사전 검증과 패치 생성에 포함한다.
7. GUI `이미지 캐시 갱신` 버튼으로 새 리소스까지 원버튼 갱신되게 한다.

## 검증

1. 번역 미리보기에서 9개 이미지의 잘림, 행 겹침 및 불필요한 배경 확인
2. PNG를 DXT3로 재인코딩한 뒤 압축 해제하여 픽셀 및 알파 검증
3. 각 컨테이너가 원본 ISO 할당 공간을 넘지 않는지 확인
4. 독립 원본 및 `s_6600.bin` 실행 복제본 교체 수 확인
5. GUI 캐시 갱신 후 새 리소스를 포함한 캐시 상태 `최신` 확인
6. GUI 사전 검증 성공 및 모든 추가 이미지 캐시 사용 확인
7. 테스트 ISO 한 개 생성 후 메시지 리소스 해시와 아카이브 복제본 대조
8. 기존 추가 이미지 패치 리소스가 변하지 않았는지 회귀 검증

## 예상 변경 파일

- `tools/patchdata/ys6_additional_images/edited_parts/zemes_statue_messages/*.png`
- 필요 시 한글 이미지 생성 스크립트
- 필요 시 추가 이미지 패치 및 런타임 복제본 처리 코드
- 갱신된 `precompiled` 캐시
- `docs/result/082-ys6-zemes-statue-message-korean-image-patch.md`

## 보존 사항

- 원본 ISO를 수정하지 않는다.
- 기존 이미지 블록 오프셋이나 다른 리소스 정의를 변경하지 않는다.
- 원본 컨테이너의 할당 공간을 초과하면 ISO 배치를 임의로 변경하지 않고 작업을 중단한다.
- 테스트 ISO는 `/patched/082-ys6-zemes-statue-message-korean-image-patch/`에 한 개만 생성한다.
- 번역 및 레이아웃 미리보기를 확인한 뒤 최종 ISO 패치를 검증한다.

## 완료 기준

- 석상 메시지 9개가 자연스러운 한글 이미지로 준비된다.
- 독립 원본과 실제 실행 복제본이 모두 패치 대상에 포함된다.
- GUI 캐시 갱신, 사전 검증 및 ISO 생성 흐름에서 자동 적용된다.
- 테스트 ISO 내부의 모든 대상 해시와 복제본이 예상 결과와 일치한다.
- 결과 문서에 생성 파일, 검증 결과 및 테스트 ISO를 기록한다.
