# 071. Ys VI 시스템 메시지 선택 상태 되돌림 수정 계획

상태: 완료

## 목적

- 시스템 메시지 편집기에서 `선택 항목 override` 실행 후 다른 항목을 선택할 때 이전
  항목의 상태가 `untranslated` 등 편집창의 오래된 값으로 되돌아가는 문제를 수정한다.
- 목록 새로고침과 상세 편집창의 대상 레코드를 항상 동일하게 유지한다.

## 원인

1. `override_selected`가 작업공간 레코드를 `override`로 변경한 뒤 목록을 새로 그린다.
2. 목록은 갱신되지만 `_selected_identifier`와 상세 편집창에는 변경 전 값이 남는다.
3. 다음 항목 선택 시 `_commit_selected`가 오래된 상세 편집창 값을 이전 레코드에 다시
   기록해 방금 변경한 상태를 되돌린다.

## 구현 범위

1. 시스템 메시지 목록 새로고침 시 선택 항목을 식별자로 복원할 수 있게 한다.
2. `선택 항목 override` 실행 전에 현재 편집값을 반영하고, 변경 후에는 대표 선택
   항목을 다시 선택해 상세 편집창을 최신 레코드 값으로 동기화한다.
3. 필터 때문에 변경된 항목이 목록에서 사라지는 경우에는 내부 선택 식별자와 상세
   편집 상태를 안전하게 초기화한다.
4. 다중 선택 override 동작과 길이 초과 시 `conflict` 처리 규칙은 유지한다.
5. 시스템 메시지 이외의 대사·인물명·아이템 편집기는 변경하지 않는다.

## 검증

1. `untranslated` 항목을 선택해 번역을 입력하고 override로 변경한 뒤 다른 항목을
   선택해도 상태가 유지되는지 확인한다.
2. 이미 번역이 있는 여러 항목을 다중 선택해 override로 바꾼 뒤 선택을 이동해도
   변경 상태가 유지되는지 확인한다.
3. 상태 필터 사용 중 변경 항목이 목록에서 사라지는 경우 이전 편집값이 다른 항목이나
   이전 항목에 재적용되지 않는지 확인한다.
4. 빈 번역 제외와 길이 초과 conflict 처리가 기존과 동일한지 확인한다.
5. Python 구문 검사와 비GUI 상태 전이 검증을 수행한다.

## 변경 대상

- `tools/ys6_dialogue_viewer.py`
- 필요 시 상태 동기화 검증용 테스트 코드
- `docs/result/071-ys6-system-message-selection-state-fix.md`

## 보존 사항

- `tools/config/system-messages.json`의 현재 번역과 상태는 직접 변경하지 않는다.
- 패치 빌드 및 ISO 적용 로직은 변경하지 않는다.
- 원본 ISO와 패치 ISO는 생성하거나 수정하지 않는다.

## 완료 기준

- override 변경 후 다른 항목을 선택해도 이전 항목 상태가 되돌아가지 않는다.
- 목록, 내부 선택 식별자, 상세 편집창이 동일한 레코드 상태를 표시한다.
- 기존 다중 선택과 검증 규칙에 회귀가 없다.
- 결과 문서에 수행 내용과 검증 결과가 기록된다.
