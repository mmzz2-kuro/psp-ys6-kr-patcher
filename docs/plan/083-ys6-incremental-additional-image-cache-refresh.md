# 083. Ys VI 추가 이미지 캐시 증분 갱신 계획

상태: 완료

## 목적

- 추가 이미지 PNG 한 장을 변경했을 때 전체 36개 리소스를 다시 압축하지 않는다.
- 변경된 PNG가 속한 리소스와 정의가 변경된 리소스만 다시 압축한다.
- 변경되지 않은 기존 캐시는 검증 후 재사용한다.
- 기존의 전체 성공 후 원자적 교체와 실패 시 이전 캐시 보존 동작은 유지한다.

## 변경 판정 단위

캐시는 PNG 파일 한 장이 아니라 추가 이미지 `resource_id` 단위로 갱신한다.

- 같은 리소스의 PNG 여러 장 중 하나가 변경되면 해당 리소스 하나를 재압축한다.
- 리소스의 매니페스트 정의, 좌표, 블록 오프셋 또는 실행 복제본 정보가 변경되면 해당 리소스를 재압축한다.
- 원본 ISO 내부 컨테이너 해시가 달라지면 해당 리소스를 재압축하거나 지원하지 않는 ISO로 차단한다.
- 아무 입력도 변경되지 않았으면 압축 없이 기존 캐시를 그대로 유지한다.

## 증분 갱신 흐름

1. 원본 ISO SHA-256을 검증한다.
2. 현재 매니페스트에서 편집 이미지가 있는 리소스 목록을 계산한다.
3. 기존 캐시 매니페스트와 다음 식별자를 비교한다.
   - 원본 컨테이너 SHA-256
   - 리소스 정의 SHA-256
   - 적용 PNG 경로 및 SHA-256
4. 상태를 다음으로 분류한다.
   - `reuse`: 입력이 동일하며 캐시 파일도 정상
   - `rebuild`: PNG·리소스 정의·원본 컨테이너가 변경됨
   - `new`: 기존 캐시에 없는 신규 리소스
   - `remove`: 현재 매니페스트에서 제외된 과거 캐시
5. 임시 캐시 폴더를 만든다.
6. `reuse` 리소스는 기존 검증된 컨테이너를 임시 폴더로 복사한다.
7. `rebuild`와 `new` 리소스만 이미지 합성·DXT 압축·컨테이너 검증을 수행한다.
8. 현재 매니페스트에 없는 캐시는 새 캐시에 포함하지 않는다.
9. 전체 결과를 검증한 뒤 기존 캐시와 원자적으로 교체한다.
10. 실패하면 임시 결과를 정리하고 기존 캐시를 보존한다.

## GUI 변경

- `이미지 캐시 갱신` 버튼은 기존과 동일하게 사용한다.
- 시작 전에 다음 개수를 로그에 표시한다.
  - 재사용
  - 재압축
  - 신규
  - 제거
- 진행률은 전체 리소스 수가 아니라 실제 재압축 대상 수를 중심으로 표시한다.
- 완료 메시지에 재사용 수, 재압축 수, 제거 수, 전체 캐시 크기와 소요 시간을 표시한다.
- 변경된 것이 없으면 `이미지 캐시가 이미 최신입니다`로 즉시 완료한다.

## 안전 처리

- 기존 캐시 매니페스트만 믿지 않고 실제 컨테이너 파일 SHA-256을 다시 확인한다.
- 해시가 다른 캐시 파일은 재사용하지 않고 해당 리소스를 재압축한다.
- 기존 캐시 파일을 직접 수정하거나 이동하지 않고 임시 폴더에 복사한다.
- 전체 성공 전에 기존 `precompiled` 디렉터리를 제거하지 않는다.
- 하드링크는 기존 캐시 교체 및 삭제 과정에서 혼동을 줄 수 있으므로 사용하지 않고 일반 파일 복사를 사용한다.

## 검증

1. 변경 없음: 재압축 0개로 즉시 완료
2. 단일 PNG 변경: 해당 리소스만 재압축
3. 같은 리소스의 여러 PNG 중 한 장 변경: 리소스 하나만 재압축
4. 매니페스트 정의 한 항목 변경: 해당 리소스만 재압축
5. 신규 리소스 추가: 신규 리소스만 압축
6. 리소스 제거: 과거 캐시가 새 결과에서 제외됨
7. 기존 캐시 파일 손상: 손상된 리소스만 재압축
8. 재압축 강제 실패: 기존 캐시 전체 보존
9. 증분 갱신 후 캐시 상태 `최신`, 36개 확인
10. GUI 사전 검증과 ISO 빌드에서 캐시 36/36개 사용
11. 전체 재생성 캐시와 증분 갱신 캐시의 리소스별 SHA-256 일치

## 보존 사항

- 원본 ISO와 패치 ISO를 수정하지 않는다.
- 추가 이미지 매니페스트와 편집 PNG 내용은 이번 작업에서 변경하지 않는다.
- 기존 GUI 체크박스, 사전 검증 및 ISO 패치 의미를 변경하지 않는다.
- 테스트를 위해 PNG를 변경할 때는 복사본 작업공간을 사용하며 실제 편집본을 덮어쓰지 않는다.
- 새 테스트 ISO는 증분 캐시 사용 검증에 꼭 필요한 경우에만 한 개 생성한다.

## 완료 기준

- 이미지 한 장 변경 시 관련 리소스만 다시 압축된다.
- 변경이 없으면 압축 없이 즉시 완료된다.
- 실패 시 기존 캐시가 그대로 보존된다.
- GUI에서 재사용 및 재압축 수를 확인할 수 있다.
- 증분 결과가 전체 재생성 결과와 바이트 단위로 동일하다.
- 결과 문서에 성능 비교와 검증 결과를 기록한다.
