# 070. Ys VI 빈 한글 번역 필터 추가 계획

상태: 완료

## 목적

- GUI 대화 편집기에서 한글 번역문이 비어 있는 항목만 바로 확인할 수 있게 한다.
- `status`가 `draft`, `untranslated`, `override` 등 무엇이든 관계없이 번역문 자체를
  기준으로 판정한다.

## 판정 기준

1. 각 레코드의 `translation` 값을 기존 편집기 정규화 함수로 정규화한다.
2. 정규화 후 공백을 제거한 결과가 빈 문자열이면 `번역 비어 있음`으로 판정한다.
3. 상태, 역할, 원문 내용은 빈 번역 판정에 영향을 주지 않는다.
4. 검색어 및 역할 필터와 함께 선택하면 모든 조건을 동시에 만족하는 항목만 표시한다.

## 구현 범위

1. 대화 편집기의 상태 콤보박스에서는 `번역 비어 있음` 항목을 제거한다.
2. 상태 필터 옆에 `번역 비어 있음만` 독립 체크박스를 추가한다.
3. 체크박스 선택 시 `translation`이 없거나 빈 문자열 또는 공백뿐인 모든 레코드만
   표시한다.
4. 상태 콤보박스와 독립 체크박스를 동시에 적용할 수 있게 한다. 예를 들어 상태를
   `override`로 선택하고 체크박스를 켜면 빈 번역인 `override`만 표시한다.
5. 기존 `전체`, `dialogue`, 각 상태 필터의 동작은 유지한다.
6. 필터 처리를 테스트 가능한 함수로 유지해 상태 조건과 빈 번역 조건을 각각
   검증한다.

## 검증

1. 빈 문자열, 키 누락, 공백만 있는 번역이 필터에 포함되는지 확인한다.
2. 번역문이 있는 `untranslated`, `draft`, `override` 항목은 제외되는지 확인한다.
3. 체크박스만 선택하면 번역문이 빈 `untranslated`, `draft`, `override` 항목이 모두
   포함되는지 확인한다.
4. 상태 필터와 체크박스를 함께 선택했을 때 두 조건의 교집합만 표시되는지 확인한다.
5. 검색어 및 역할 필터와의 조합을 확인한다.
6. Python 구문 검사와 가능한 범위의 비GUI 단위 검증을 수행한다.

## 변경 대상

- `tools/ys6_dialogue_viewer.py`
- 필요 시 GUI 필터용 테스트 파일
- `docs/result/070-ys6-empty-korean-translation-filter.md`

## 제외 범위

- 번역 데이터와 상태 값은 변경하지 않는다.
- 대화 이외의 인물명, 아이템, 시스템 메시지 편집기 필터는 변경하지 않는다.
- 패치 빌드 및 ISO 적용 로직은 변경하지 않는다.

## 완료 기준

- GUI의 독립 체크박스로 번역 상태와 무관하게 한글 번역문이 비어 있는 대화 항목만
  필터링된다.
- 상태 필터와 빈 번역 체크박스를 함께 사용할 수 있다.
- 기존 필터와 편집·저장 동작에 회귀가 없다.
- 결과 문서에 변경 파일과 검증 결과가 기록된다.
