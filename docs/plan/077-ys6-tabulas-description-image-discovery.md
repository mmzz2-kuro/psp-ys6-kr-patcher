# 077. Ys VI 타블라스 설명 이미지 조사 계획

상태: 사용자 확인 대기

## 목적

- 게임에서 표시되는 타블라스 설명 이미지의 원본 리소스를 찾는다.
- 약 5종의 타블라스마다 이미지가 2개씩 존재하는지 실제 파일 구조로 확인한다.
- 독립 이미지 외에 맵·이벤트 아카이브에 포함된 런타임 복제본이 있는지 조사한다.
- 후속 한글 이미지 제작과 GUI 추가 이미지 패치 등록에 필요한 크기, 형식, 분할 경계 및 할당 공간을 정리한다.

## 조사 범위

1. 기존 이미지 인벤토리와 렌더 결과에서 사용자 제공 화면과 유사한 청색 배경·일본어 본문 이미지를 선별한다.
2. `PSP_GAME/USRDIR/data/image`, `data/menu`, `data/arc`, 맵 및 이벤트 관련 리소스를 파일명·크기·해시·시각적 유사도로 검색한다.
3. 후보 `.dds.z` 또는 MIG 컬렉션을 PNG로 렌더링해 실제 타블라스 설명인지 확인한다.
4. 타블라스별 이미지 수와 페이지 순서를 판정하고 다음 정보를 기록한다.
   - ISO 경로 또는 아카이브 경로
   - 아카이브 entry index와 flags
   - 이미지 크기 및 픽셀 형식
   - 압축 컨테이너 크기와 할당 공간
   - 동일 컨테이너·payload 복제본
5. 각 이미지의 일본어 본문을 판독해 페이지 대응표를 만든다.
6. 한글 패치 가능성을 판단하되 이번 조사 단계에서는 이미지를 수정하거나 ISO에 적용하지 않는다.

## 검증

- 후보 이미지가 사용자 제공 화면의 배경과 본문 배치를 실제로 포함하는지 PNG로 확인한다.
- 예상한 약 10개 이미지가 독립 파일인지, 한 텍스처 내부 페이지인지, 아카이브 entry인지 구분한다.
- 동일 파일명뿐 아니라 컨테이너 SHA-256과 압축 해제 payload SHA-256으로 복제본을 확인한다.
- 후속 패치 시 모든 런타임 소비 위치를 함께 교체할 수 있는지 확인한다.

## 예상 산출물

- 조사 미리보기 및 후보 렌더: `tools/patchdata/work/current/image-discovery/tabulas/`
- 타블라스 이미지·페이지 대응표
- 런타임 복제본 보고서
- 결과 문서: `docs/result/077-ys6-tabulas-description-image-discovery.md`

## 보존 사항

- 원본 ISO와 기존 패치 ISO는 수정하지 않는다.
- 조사 완료 및 별도 사용자 확인 전에는 한글 이미지 생성, 매니페스트 등록 및 ISO 패치를 진행하지 않는다.
- 기존 추가 이미지 좌표와 블록 오프셋 정의는 변경하지 않는다.

## 완료 기록

- 타블라스 5종, 총 14페이지와 페이지당 8개 MIG 그림 구성을 확인했다.
- 전체 런타임 아카이브 222개를 조사했으며 별도 복제본은 없었다.
- 상세 결과는 `docs/result/077-ys6-tabulas-description-image-discovery.md`에 기록했다.
