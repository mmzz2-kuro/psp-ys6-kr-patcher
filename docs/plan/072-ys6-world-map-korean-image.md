# 072. Ys VI 월드맵 한글 이미지 제작 계획

상태: 완료

## 목적

- 월드맵 이미지에 포함된 일본어 지역명을 한국어로 번역한다.
- 게임의 기존 지도 배경과 표식은 유지하고 지역명 글자만 자연스럽게 교체한다.
- 완성 이미지를 추가 이미지 패치가 읽는 수정 경로에 배치한다.

## 입력 및 출력

- 입력:
  `tools/patchdata/ys6_additional_images/source_parts/world_map/line_01.png`
- 출력:
  `tools/patchdata/ys6_additional_images/edited_parts/world_map/line_01.png`
- 원본 크기: `320x240`
- 원본 이미지는 수정하지 않는다.

## 번역 및 편집 원칙

1. 이미지의 일본어 지명은 아래 확정 표기를 그대로 사용한다. 띄어쓰기와 음역을
   임의로 바꾸지 않는다.
   - `그라나바리스`
   - `태양의 후미`
   - `카난평원`
   - `녹수동`
   - `제메스의 성지`
   - `항구도시 리모쥬`
   - `해안길`
   - `바람개비언덕`
   - `쿠아테라의 수해`
   - `다리`
   - `기도의 샘`
   - `레다마을`
   - `달의 해변`
2. `The Canaan Islands`, `Canaan`, `Zemeth`, `Quatera` 등 영어로 표시된 부분은
   번역하거나 지우지 않고 원본 그대로 보존한다.
3. 영문 장식 제목과 지도 배경, 섬 윤곽, 점·화살표·나침반 등의 표식은 유지한다.
4. 일본어 글자 영역만 한국어로 교체하고 각 명칭이 가리키는 위치와 배치를 유지한다.
5. 작은 게임 UI에서도 읽을 수 있도록 기존 흰색 계열 글자, 어두운 외곽선 및 크기를
   최대한 맞춘다.
6. `imagegen`의 `text-localization` 방식으로 원본을 편집 대상으로 사용한다.
7. 생성 결과에서 일본어 잔존, 한글 오탈자, 표식 손상 또는 배경 변형이 있으면 해당
   문제만 지정해 보정한다.

## 검증

1. 결과가 PNG이며 `320x240` 크기를 유지하는지 확인한다.
2. 원본과 비교해 지도 배경 및 표식이 불필요하게 바뀌지 않았는지 육안 검토한다.
3. 대상 일본어 지역명이 확정된 13개 한글 표기로 바뀌었는지 확인한다.
4. 원본 영어 표기가 모두 유지됐는지 확인한다.
5. 한글 표기와 글자 잘림, 겹침, 가독성을 확인한다.
6. 추가 이미지 합성 입력 경로에서 결과 파일이 인식되는지 확인한다.

## 변경 대상

- `tools/patchdata/ys6_additional_images/edited_parts/world_map/line_01.png`
- `docs/result/072-ys6-world-map-korean-image.md`

## 제외 범위

- 원본 이미지와 매니페스트의 좌표·블록 오프셋은 변경하지 않는다.
- 이번 단계에서는 ISO를 생성하거나 패치하지 않는다.
- 월드맵 이외의 추가 이미지는 변경하지 않는다.

## 완료 기준

- 월드맵 일본어 지역명이 프로젝트 표기에 맞는 한글로 교체된다.
- 수정 이미지가 지정된 `edited_parts/world_map` 경로에 저장된다.
- 크기, 가독성 및 추가 이미지 입력 인식 검증을 통과한다.
- 결과 문서에 번역 표기, 생성 방식, 저장 경로와 검증 결과를 기록한다.
