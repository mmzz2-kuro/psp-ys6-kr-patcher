# 102. Ys VI 아날로그 스틱 테스트 ISO 생성 계획

상태: 완료

## 목적

- 현재 ULJM-05009 한글 패치 전체에 101번의 아날로그 모드 유지 패치를 추가한 테스트 ISO를 만든다.
- PSP 실기 또는 PPSSPP에서 필드 이동과 입력 안정성을 확인할 수 있게 한다.
- 원본 ISO와 기존 한글 패치 ISO는 변경하지 않는다.

## 적용 내용

- 기존 GUI 빌드와 동일한 번역, 폰트, 아이템, 시스템 메시지, 이미지, 엔딩 영상 및 XMB 패치를 포함한다.
- 한글 EBOOT 생성이 끝난 뒤 101번에서 확인한 8개 명령을 추가로 변경한다.
- 변경 내용은 `sceCtrlSetSamplingMode(0)` 호출 인수를 `1`로 바꾸는 것에 한정한다.
- SPECIAL VERSION의 데드존 코드는 이번 테스트에 포함하지 않는다.

## 구현 절차

1. 아날로그 패치 도구가 원본 복호화 EBOOT뿐 아니라 검증된 한글 빌드 EBOOT에도 안전하게 적용되도록 입력 검증을 보강한다.
2. 통합 빌더에 테스트용 아날로그 패치 옵션을 추가한다.
3. 옵션 선택 시 폰트·시스템 메시지 패치 후 8개 명령을 적용한다.
4. 적용 전 각 위치의 기존 명령이 `0x00002021`인지 확인한다.
5. 아날로그 옵션 미선택 시 기존 빌드 결과가 변하지 않도록 한다.
6. 검증된 원본 ISO를 사용해 별도 테스트 ISO를 생성한다.
7. 출력 ISO에서 EBOOT을 다시 추출해 8개 명령과 전체 변경 범위를 확인한다.

## 출력

- 테스트 ISO: `patched/102-analog-stick-test/Ys VI (Japan) - 102-analog-stick-test.iso`
- 중간 EBOOT 및 보고서: `tools/patchdata/work/current/102-analog-stick-test`
- 결과 문서: `docs/result/102-ys6-analog-stick-test-iso.md`

## 안전 조건

- `roms/Ys VI - Napishtim no Hako (Japan).iso`는 읽기 전용으로 사용한다.
- 기존 빌더의 기본 동작은 변경하지 않고 아날로그 패치를 명시적으로 선택한 경우에만 적용한다.
- 테스트 ISO는 기존 출력 파일을 덮어쓰지 않는다.
- EBOOT 크기와 ISO 할당 공간을 유지한다.
- 승인된 8개 명령 이외의 아날로그 관련 코드 변경은 수행하지 않는다.

## 검증

- 아날로그 적용·미적용 사전 검증을 각각 실행한다.
- Python 문법 검사와 패치 명령 검증을 수행한다.
- 출력 ISO에서 EBOOT을 재추출해 작업 EBOOT과 SHA-256이 일치하는지 확인한다.
- ISO 차이 검증에서 허용 범위 밖 변경이 없는지 확인한다.

## 실기 시험 항목

1. 필드에서 아날로그 이동 가능 여부
2. 상하좌우 및 대각선 이동
3. 스틱 중립 상태의 드리프트
4. 전투·이벤트·맵 전환 이후 입력 유지
5. 방향키와 아날로그 병행 사용
6. 메뉴와 대화 선택에서 비정상 반복 입력 여부

## 완료 기준

- 한글 패치와 아날로그 8명령 패치가 포함된 별도 테스트 ISO가 생성된다.
- 출력 ISO의 EBOOT과 변경 범위가 검증된다.
- 사용자가 실기에서 확인할 수 있는 파일과 시험 항목을 제공한다.
