# 078. Ys VI 타블라스 설명 한글 이미지 패치 계획

상태: 사용자 확인 대기

## 목적

- 타블라스 5종의 설명 이미지 14페이지를 한국어로 번역한다.
- 배경 문양과 색상을 유지하면서 일본어 본문만 한글로 교체한다.
- 480×272 편집 이미지를 원본과 동일한 8개 MIG 그림으로 재분할해 14개 `.dds.z`에 적용한다.
- GUI의 `추가 이미지 적용` 선택에 사전검증과 ISO 패치를 함께 연동한다.

## 대상

| 타블라스 | 페이지 파일 |
|---|---|
| 블루 | `p200`, `p201` |
| 레드 | `p210`, `p211`, `p212` |
| 골드 | `p220`, `p221`, `p222` |
| 블랙 | `p230`, `p231`, `p232` |
| 화이트 | `p240`, `p241`, `p242` |

총 14페이지이며 각 페이지는 8개 MIG 그림으로 구성된다.

## 1단계: 원문 전사와 번역표 작성

1. 보정된 480×272 이미지 14개에서 일본어 본문을 줄 단위로 전사한다.
2. 페이지 순서와 문맥을 연결해 한국어 초안을 작성한다.
3. 고유명사는 기존 프로젝트 번역을 우선한다.
   - `レダ`: 레다
   - `アルマ`: 알마
   - `カナン`: 카난
   - `エメラス`: 에멜라스
4. 각 페이지의 원문·번역·권장 줄바꿈을 별도 번역표로 정리한다.
5. 이미지 생성 전에 사용자에게 전체 번역표 확인을 요청한다.

## 2단계: 한글 편집 이미지 생성

사용자 번역 확인 후 진행한다.

1. 일본어 글자와 외곽선 영역만 제거하고 주변 배경을 복원한다.
2. 480×272 전체 화면을 기준으로 한글 본문을 배치한다.
3. 글꼴은 기존 프로젝트의 Gulim 계열을 기본으로 하되 원본의 흰 글자·검은 외곽선 스타일을 재현한다.
4. 문장이 화면 밖으로 나가지 않도록 폭·행간·중앙 정렬을 페이지별로 조정한다.
5. 원본과 수정본의 배경 차이를 비교해 글자 주변 이외의 DXT1 블록이 불필요하게 변하지 않도록 한다.

## 3단계: 8조각 재분할 및 패처 확장

1. 480×272 수정본을 다음 크기로 분할한다.
   - 상단: 256×256, 128×256, 64×256, 32×256
   - 하단: 256×16, 128×16, 64×16, 32×16
2. 각 MIG 그림의 실제 픽셀 시작점 앞에 존재하는 16바이트 제어 데이터를 보존한다.
3. 기존 추가 이미지 패처에 한 컬렉션의 여러 picture index를 하나의 편집 이미지로 합성·분할하는 지원을 추가한다.
4. 매니페스트에 `tabulas_blue_01`부터 각 페이지 리소스를 등록한다.
5. 독립 리소스만 등록하며 077 조사에서 존재하지 않는 것으로 확인된 런타임 복제본은 추가하지 않는다.

## 4단계: GUI 및 ISO 패치 연동

1. 기존 GUI의 `추가 이미지 적용` 체크박스가 타블라스 이미지도 포함하도록 공통 매니페스트 경로에 등록한다.
2. 체크 시 사전검증과 ISO 패치에 14개 리소스를 포함한다.
3. 체크 해제 시 타블라스 이미지의 검증과 패치를 모두 생략한다.
4. 원본 ISO를 수정하지 않고 별도의 `/patched/078-ys6-tabulas-description-korean-image-patch/` 작업본을 생성한다.

## 검증

1. 원문 전사와 페이지 순서 확인
2. 무수정 480×272 합성·8조각 재분할 왕복 후 payload 동일성 또는 전 픽셀 동일성 확인
3. 수정본에서 일본어 잔존 픽셀과 글자 잘림 확인
4. 8개 MIG picture index별 크기·형식·제어 데이터 보존 확인
5. 14개 `.dds.z` 압축 해제 및 재렌더 검증
6. 원본 ISO 할당 공간 초과 확인
7. 특히 잔여 공간이 55바이트인 `p220.dds.z`의 고압축 결과 확인
8. GUI 사전검증 성공 및 체크박스 활성·비활성 경로 확인
9. 테스트 ISO에서 각 타블라스 페이지 표시 확인

## 보존 사항

- 번역표 사용자 확인 전에는 한글 이미지 생성과 ISO 패치를 진행하지 않는다.
- 원본 배경 전체를 블러 처리하거나 새로 생성하지 않는다.
- MIG 그림의 16바이트 제어 데이터와 기존 picture 구조를 변경하지 않는다.
- 기존 추가 이미지 리소스의 좌표·블록 오프셋·수정 이미지는 변경하지 않는다.
- 테스트 ISO는 한 개만 생성하며 결과 문서에 용도와 정리 여부를 기록한다.

## 완료 기준

- 14페이지 원문과 한국어 번역이 확정돼 있다.
- 한글 편집본 14개가 글자 잘림과 일본어 잔존 없이 생성돼 있다.
- 각 편집본이 8개 MIG 그림으로 안전하게 재분할된다.
- 14개 컨테이너가 할당 공간 안에서 재압축된다.
- GUI 패치와 테스트 ISO에서 정상 표시된다.
- 결과 문서에 변경 파일, 검증 결과 및 테스트 ISO를 기록한다.

## 완료 기록

- 사용자 확인 번역으로 한글 이미지 14개를 생성했다.
- 다중 MIG 그림 합성·재분할 패치 경로와 GUI 추가 이미지 연동을 완료했다.
- 사전검증, 할당 공간 검사, 테스트 ISO 생성 및 ISO 내부 재렌더 검증을 통과했다.
- 상세 결과는 `docs/result/078-ys6-tabulas-description-korean-image-patch.md`에 기록했다.
