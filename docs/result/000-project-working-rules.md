# 프로젝트 작업 규칙 등록 결과

## 상태

- 완료
- 사용자 승인: 2026-08-11

## 반영 내용

- 사용자용 GUI 도구는 `/tools`에 작성한다.
- 비GUI Python 스크립트는 `/tools/scripts`에 작성한다.
- Node.js 스크립트는 `/tools/scripts/nodejs`에 작성한다.
- 모든 작업은 계획 문서 작성, 사용자 확인, 작업 진행, 결과 문서 작성 순서를 따른다.
- 원본 ROM은 가급적 직접 수정하지 않는다.
- 수정 ROM은 `/patched` 아래에서 이슈별로 관리한다.
- 불필요한 수정 ROM을 반복 생성하지 않으며 임시 산출물은 이슈 완료 시 정리할 수 있게 기록한다.
