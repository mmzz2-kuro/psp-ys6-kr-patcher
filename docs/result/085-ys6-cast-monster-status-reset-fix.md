# 085. Ys VI GUI 인물·몬스터명 상태 초기화 오류 수정 결과

## 수정 결과

- 인물·몬스터명 항목을 `reviewed`로 변경한 뒤 다른 항목을 선택하면 `untranslated`로 되돌아가던 문제를 수정했다.
- 인물과 몬스터가 공용으로 사용하는 `CastNameEditor`의 선택 상태 갱신을 안전하게 변경했다.
- 실제 `tools/config/cast-names.json`은 수정하지 않았다.

## 변경 내용

### reviewed 변경 후 선택 복원

- 상태 변경 전에 현재 우측 편집 내용을 먼저 커밋한다.
- 트리에서 선택한 항목을 화면 인덱스가 아닌 고유 `identifier` 목록으로 보존한다.
- 변경 후 `refresh()`에서 현재 필터에 남아 있는 항목을 다시 선택한다.
- 우측 편집 필드는 다시 선택된 첫 항목의 갱신된 실제 값으로 다시 채운다.
- 따라서 과거 `untranslated` 값이 남아 다음 선택 시 다시 저장되지 않는다.

### 필터에서 사라지는 항목 처리

- `미번역` 필터에서 항목을 `reviewed`로 변경하면 해당 항목은 목록에서 사라진다.
- 이때 `_selected_identifier`, 원문 정보, 번역, 상태 및 메모 편집 필드를 초기화한다.
- 이후 다른 행을 선택해도 사라진 항목에 오래된 값이 커밋되지 않는다.

### 목록 재생성 안전 처리

- 트리 행을 삭제하기 전에 이전 `_selected_identifier` 연결을 끊는다.
- 트리 재생성 과정에서 지연된 선택 이벤트가 발생해도 stale 편집 값이 저장되지 않는다.
- 일반 검색·상태·분류 필터 갱신 전에는 현재 편집 내용을 먼저 커밋한다.
- 명시적으로 항목을 다시 선택할 때만 갱신 후 해당 실제 값을 우측 필드에 로딩한다.

### 다른 작업공간 열기

- 새 인물명 작업공간을 열 때 이전 파일의 `_selected_identifier`를 초기화한다.
- 이전 파일에 표시됐던 번역과 상태가 새 작업공간에 기록되지 않는다.

## ROM 및 알려진 사항

- 원본 ISO와 패치 ISO는 사용하거나 변경하지 않았다.
- 이번 수정은 GUI 편집 상태 관리에만 적용되며 패치 빌드 데이터 형식은 변경하지 않는다.
- 인물·몬스터 편집기에서 패치 적용 상태의 실제 이름은 `override`가 아니라 `reviewed`다.
