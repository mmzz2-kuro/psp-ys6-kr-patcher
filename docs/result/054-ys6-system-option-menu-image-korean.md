# 054. Ys VI 시스템 옵션 메뉴 이미지 한글화 결과

## 상태

- 진행 중
- 버튼 이미지 분리·재합성 및 GUI 패치 빌드 연동 완료
- 나머지 이미지 편집과 최종 PPSSPP 검증 대기

## 구현 내용

- `static_tex.dds.z`의 PSP DXT1 옵션 아틀라스를 정상 PNG로 추출한다.
- 202×24 메뉴 버튼을 파일별로 분리한다.
- 오른쪽에 세로 저장된 54×62 조각 4개를 216×62 편집 이미지로 결합한다.
- 수정 이미지를 검사하고 원래 좌표로 재합성한다.
- 수정 PNG는 알파 마스크로 원본과 혼합하지 않고 RGBA 픽셀을 지정 영역에
  그대로 복사한다. 따라서 사용자가 편집한 배경·문자·투명도 값이 보존된다.
- 실제로 변경된 4×4 블록만 PSP DXT1으로 다시 인코딩한다.
- 변경 블록은 Pillow DXT1 결과와 RGB565 끝점 탐색 결과를 비교하여 복원 RGB
  오차가 더 작은 블록만 채택한다. 투명 블록은 DXT1 3색+투명 모드를 유지한다.
- GUI 패치 빌드가 `edited_buttons`의 PNG를 자동 인식한다.
- 통합 빌드에서 `init.bin` 내부 `static_tex.dds.z`와 독립 `data/image/static_tex.dds.z`를 함께 교체한다.
- 압축 결과가 아카이브 및 ISO 할당 범위를 넘으면 빌드 전에 실패 처리한다.

## GUI 변경

- 패치 빌드 탭에 `메뉴 이미지 폴더` 버튼을 추가했다.
- 데이터 현황에 인식된 메뉴 이미지 수를 표시한다.
- `사전 검증`과 `패치 ISO 만들기`가 수정 PNG를 자동 포함한다.

## 현재 적용 이미지

- `bgm_volume.png` (`BGMのボリューム` → `BGM 볼륨`)
- `se_volume.png` (`効果音のボリューム` → `효과음 볼륨`)
- `voice_volume.png` (`音声のボリューム` → `음성 볼륨`)
- `reset_default.png` (`標準に戻す` → `기본값 복원`)
- `key_config.png` (`キーコンフィグ` → `키 설정`)
- `controls.png` (`操作説明` → `조작 설명`)
- `save.png` (`セーブ` → `저장`)
- `return_title.png` (`タイトル画面に戻る` → `타이틀 화면으로`)
- `dialogue_unselected.png` → `타이틀 화면으로 돌아가시겠습니까?`

`controls.png`는 이미지 편집 결과의 한글 문자 스타일을 참고하되, 압축
공간을 지키기 위해 원본 배경을 유지하고 중앙 글자 영역만 저변경 방식으로
복원·합성했다.

나머지 버튼도 생성된 한글 스타일을 기준으로 중앙 내부 영역만 교체해 원본
테두리를 유지했다. 옵션 컨테이너는 zlib level 9의 memory level 5~9를 모두
검사해 가장 작은 유효 스트림을 선택하도록 최적화했다.

사용자가 먼저 편집했던 `bgm_volume.png`도 다른 버튼과 글꼴·외곽선 스타일을
통일한 이미지로 교체했다. 이 버튼 역시 원본 테두리와 배경을 유지하고 내부
글자 영역만 합성했다.

## 검증

- Python 구문 검사 통과
- 패치 데이터 검사에서 수정 이미지 2개 인식
- 통합 사전 검증 통과
- 옵션 메뉴 이미지: 8개
- 옵션 메뉴 변경 DXT1 블록: 2,555개
- 옵션 컨테이너: 656,951 / 665,600바이트
- 옵션 컨테이너 잔여 공간: 8,649바이트
- DXT1 RGB 평균제곱오차: 65.959 → 39.612 (약 40% 감소)
- DXT1 PSNR: 29.938dB → 32.153dB
- 할당 공간 초과: 없음
- 통합 사전 검증 대상:
  - 대사 override 4,665개
  - XSO 463개
  - 런타임 아카이브 49개
  - standalone 450개
  - 인물명 58개
  - 아이템 72개
