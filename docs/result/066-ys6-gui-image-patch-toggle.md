# 066. Ys VI GUI 이미지 패치 적용 체크박스 결과

## 결과

- GUI 패치 빌드 화면에 두 개의 독립 체크박스를 추가했다.
  - `옵션 메뉴 이미지 적용`
  - `추가 이미지 적용`
- 두 체크박스는 기존 동작을 유지하도록 기본 선택 상태다.
- 체크 상태는 `사전 검증`과 `패치 ISO 만들기`에서 동일한 값으로 사용된다.
- 체크 해제된 이미지 기능은 입력 검사, 이미지 합성, 압축·할당 검증 및 ISO 교체
  대상에서 제외된다.
- 체크를 해제해도 편집 PNG는 변경하거나 삭제하지 않는다.

## 변경 내용

- `tools/ys6_dialogue_viewer.py`
  - 이미지 적용 체크박스 두 개를 추가했다.
  - 데이터 요약에 각 기능의 `적용 N` 또는 `제외` 상태를 표시한다.
  - 빌드 시작 시 체크 상태를 작업 스레드에 전달한다.
  - 빌드 중 체크 상태가 바뀌지 않도록 체크박스를 비활성화한다.
- `tools/scripts/ys6_patch_builder.py`
  - 입력 검사와 빌드 함수에 이미지별 포함 선택값을 추가했다.
  - 제외된 기능의 경로와 편집 PNG는 검사·집계하지 않는다.
  - 제외된 이미지 작업공간은 통합 빌더에 `None`으로 전달한다.
  - 명령행 제외 옵션을 추가했다.
    - `--no-option-menu-images`
    - `--no-additional-images`
- `tools/scripts/ys6_integrated_build.py`
  - 사전 검증 요약과 빌드 매니페스트에 다음 상태를 기록한다.
    - `option_menu_images_enabled`
    - `additional_images_enabled`
- `tools/scripts/tests/test_ys6_patch_builder.py`
  - 두 체크박스의 네 조합에 대한 작업공간 전달 테스트를 추가했다.

## 검증

- GUI 및 빌더 Python 구문 검사 성공.
- 관련 이미지·통합 빌더·토글 테스트 13개 통과.
- 다음 네 조합에서 통합 빌더에 전달되는 값 확인.
  - 둘 다 선택
  - 옵션 메뉴만 선택
  - 추가 이미지만 선택
  - 둘 다 해제
- 사용자용 빌더 도움말에서 두 명령행 제외 옵션 노출 확인.
- 이미지 폴더 열기 버튼은 체크 상태와 무관하게 유지했다.

## 알려진 문제

- 현재 프로젝트 대사 작업공간의 record 2776, 2788에 기존 `markup mismatch`가
  있어 실제 `inspect/preflight` 실행은 이미지 처리 전에 중단된다.
- 이 오류는 이미지 체크박스 변경과 무관하며 사용자 번역 데이터는 수정하지 않았다.
- 해당 대사 마크업을 정리한 뒤 GUI 사전 검증 및 실제 ISO 빌드를 다시 실행해야 한다.
- 원본 ISO와 이미지 편집 파일은 수정하지 않았다.
