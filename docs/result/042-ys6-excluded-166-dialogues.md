- `many_to_many`: 동일 XSO가 여러 독립 경로와 여러 런타임 아카이브에 연결되어 현재 빌더가 패치 대상을 일대일로 결정하지 못한다.
- `shared_payload_translation_conflict`: 실제로 같은 XSO payload의 같은 인덱스를 여러 맵이 공유하지만 번역 후보가 서로 다르다.
