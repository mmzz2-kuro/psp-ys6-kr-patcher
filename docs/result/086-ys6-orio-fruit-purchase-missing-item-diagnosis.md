# 086. Ys VI 오리오 열매 구매 후 아이템 미표시 문제 진단 결과

## 결론

- 한글 패치 ISO뿐 아니라 원본 일본어 ISO에서도 동일한 세이브로 같은 문제가 재현됐다.
- 사용자는 해당 세이브에 아이템 관련 치트를 사용한 이력이 있음을 확인했다.
- 이후 세이브 데이터 문제로 판명되어 사용자가 직접 처리했다.
- 따라서 한글 아이템 번역이나 ISO 패치 문제는 아니며 추가 패치 수정은 수행하지 않았다.

## 보존 사항

- 세이브 파일, 원본 ISO 및 패치 ISO를 수정하지 않았다.
- 조사용 테스트 ROM이나 세이브 복사본을 생성하지 않았다.
