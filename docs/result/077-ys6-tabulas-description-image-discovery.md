# 077. Ys VI 타블라스 설명 이미지 조사 결과

## 결론

- 사용자 제공 화면은 `PSP_GAME/USRDIR/data/image/p200.dds.z`와 일치한다.
- 타블라스는 예상대로 5종이지만 페이지는 총 14개다.
  - 블루 타블라스: 2페이지
  - 레드·골드·블랙·화이트 타블라스: 각 3페이지
- 각 페이지는 하나의 `.dds.z` 컬렉션이며, 내부의 MIG 그림 8개를 합쳐 480×272 화면을 구성한다.
- 222개 `data/arc/*.bin` 전체를 조사했으나 동일 파일명 또는 동일 컨테이너·payload 복제본은 없었다. 독립 이미지 14개만 패치하면 된다.

## 컬렉션 구조

각 파일은 다음 8개 그림으로 구성된다.

| 그림 index | 크기 | 합성 위치 |
|---:|---:|---:|
| 0 | 256×256 | x=0, y=0 |
| 1 | 128×256 | x=256, y=0 |
| 2 | 64×256 | x=384, y=0 |
| 3 | 32×256 | x=448, y=0 |
| 4 | 256×16 | x=0, y=256 |
| 5 | 128×16 | x=256, y=256 |
| 6 | 64×16 | x=384, y=256 |
| 7 | 32×16 | x=448, y=256 |

- 합성 화면: 480×272
- 픽셀 형식: PSP DXT1 (`pixel_format=8`)
- 컬렉션 내부의 각 MIG 그림에는 DXT1 픽셀 데이터 앞에 16바이트 제어 데이터가 있다. 기존 범용 렌더러가 이를 픽셀 블록 2개로 읽으면 선두에 검은 4×4 블록 두 개가 생긴다. PNG 블록을 순환 이동하면 이 검은 영역이 각 조각 끝으로 옮겨져 합성 화면 중간에 빈 공간이 생긴다. 조사 미리보기는 원본 payload에서 픽셀 시작점을 16바이트 뒤로 보정해 실제 마지막 블록까지 읽도록 수정했다.
- 후속 편집은 480×272 한 장으로 합쳐 작업한 후 동일한 8조각으로 다시 분할해 각 MIG 그림에 넣어야 한다.

## 후속 작업 시 유의점

- 현재 추가 이미지 패처는 한 리소스의 단일 MIG 그림 편집은 지원하지만, 한 `.dds.z` 컬렉션의 8개 그림을 하나의 480×272 편집 이미지로 합쳤다가 다시 나누는 리소스 정의는 아직 지원하지 않는다.
- 한글화 단계에서는 다중 그림 합성·분할 지원을 먼저 추가하고 무수정 왕복 결과가 원본 payload와 일치하는지 검증해야 한다.
- 이미지 전체를 재생성하면 배경 DXT1 블록까지 변할 수 있으므로 일본어 글자 영역만 투명 수정 레이어로 교체하는 방식이 안전하다.
