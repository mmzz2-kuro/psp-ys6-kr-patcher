# 080. Ys VI GUI 추가 이미지 캐시 원버튼 갱신 결과

## 수행 내용

- GUI 패치 빌드 화면에 `이미지 캐시 갱신` 버튼과 캐시 상태 표시를 추가했다.
- GUI에서 선택한 원본 ISO를 사용해 추가 이미지 27개를 백그라운드 작업으로 사전 컴파일하도록 연결했다.
- 갱신 중 현재 리소스 ID와 처리 개수를 로그 및 진행률 표시줄에 출력한다.
- 추가 이미지 체크 해제 시 캐시 상태를 `사용 안 함`으로 표시하고 갱신 실행을 차단한다.
- ISO 선택·데이터 다시 읽기·추가 이미지 옵션 변경 시 캐시 상태를 다시 판정한다.
- 성공 시 리소스 수, 캐시 크기, 소요 시간을 로그에 출력하고 최신 상태로 갱신한다.

## 안전 처리

- 작업공간 매니페스트에 기록된 원본 ISO SHA-256을 실제 ISO와 비교한 뒤 인코딩한다.
- 새 캐시는 `precompiled.tmp-*` 디렉터리에 모두 생성하고 검증한다.
- 전체 리소스가 성공한 뒤에만 기존 `precompiled` 디렉터리와 원자적으로 교체한다.
- 실패 시 임시 결과를 제거하고 기존 정상 캐시를 보존한다.
- 기존 캐시 교체 후 백업 디렉터리 정리는 최종 결과의 성공 여부에 영향을 주지 않게 처리했다.

## 사용 방법

1. `추가 이미지 폴더`에서 PNG를 수정하고 저장한다.
2. GUI에서 지원되는 원본 ISO를 선택한다.
3. `추가 이미지 적용`을 체크한다.
4. `이미지 캐시 갱신`을 한 번 누르고 완료 안내를 기다린다.
5. 이후 `사전 검증` 또는 `패치 ISO 만들기`를 실행한다.

이미지가 바뀌지 않은 일반 패치 작업에서는 캐시 갱신 버튼을 다시 누를 필요가 없다.

## 알려진 사항 및 테스트 ROM

- 27개 이미지를 실제로 압축하는 최초 갱신 자체는 수 분이 걸린다. GUI는 별도 작업 스레드를 사용하므로 처리 중 응답 상태를 유지한다.
- 이번 작업에서는 새 테스트 ISO를 만들지 않았다. 실제 ISO 쓰기 없이 사전 검증에서 27개 캐시 사용을 확인했다.
- 원본 ISO는 변경하지 않았다.
