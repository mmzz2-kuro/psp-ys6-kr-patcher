## 구현

`/tools/scripts/ys6_arc.py`를 추가했다.

- `info`: 파일 테이블 및 선택 엔트리 검사
- `extract`: 내장 파일 안전 추출
- `replace`: 할당 공간 내 교체와 크기 필드 갱신
- 테이블 크기, CP932 이름, 파일 범위, 0x800 정렬, 중복 오프셋, 할당 초과 및 기존 출력 보호
- 테이블 순서와 실제 데이터 오프셋 순서가 다를 수 있으므로 할당 경계는 데이터 오프셋을 별도로 정렬해 계산

테스트 `/tools/scripts/tests/test_ys6_arc.py`를 추가했다.

## ISO 검증

- 원본 ISO에서 작업 ISO를 다시 생성했다.
- ISO 내부 `s_0551.bin` 크기는 동일하여 디렉터리 크기 필드 변경이 없다.
- ISO 변경은 `s_0551.bin` 기존 extent 내부에만 존재한다.
- 허용 범위 밖 ISO 변경: 0건
- 작업 ISO 재추출 `s_0551.bin`과 준비한 수정 아카이브의 SHA-256이 일치한다.
- 재추출 아카이브의 내장 XSO와 준비한 수정 `.xso.z`의 SHA-256이 일치한다.
- 내장 `.z`의 CRC32 `63C97EC3`, 비압축 크기 4,516, zlib 종료 및 잔여 바이트 0을 확인했다.
- 재해제 문자열 인덱스 35가 `これはテスト表示です。`임을 확인했다.
- 작업 ISO의 개별 `data/map/s_05/s_0551/s_0551.xso.z`는 원본 SHA-256과 일치한다.
