# 072. Ys VI 월드맵 한글 이미지 제작 결과

## 수행 내용

- `source_parts/world_map/line_01.png`을 편집 대상으로 사용해 일본어 지역명을 한글로
  교체했다.
- `imagegen` 내장 이미지 편집의 `text-localization` 방식으로 생성했다.
- 생성본을 패치 입력 규격인 `320x240` PNG로 고품질 축소해 수정 이미지 경로에
  저장했다.
- 영어로 된 지도 제목과 `Canaan`, `Zemeth`, `Quatera` 표기는 번역하지 않았다.

## 적용 표기

- 그라나바리스
- 태양의 후미
- 카난평원
- 녹수동
- 제메스의 성지
- 항구도시 리모쥬
- 해안길
- 바람개비언덕
- 쿠아테라의 수해
- 다리
- 기도의 샘
- 레다마을
- 달의 해변

## 생성 파일

- `tools/patchdata/ys6_additional_images/edited_parts/world_map/line_01.png`

## 생성 프롬프트 요약

- 용도: Ys VI PSP 월드맵 텍스트 현지화
- 일본어 지역명 13개를 확정된 한글 표기로 교체
- 영어 표기, 지도 배경, 섬 윤곽, 위치 표식, 나침반과 테두리 보존
- 작은 흰색 글자와 어두운 외곽선으로 원본 지도 글자 스타일 유지

## 검증 결과

- 파일 형식: PNG
- 크기: `320x240`
- 한글 표기 13개 육안 확인
- 영어 표기 유지 확인
- `inspect_inputs()` 추가 이미지 인식 확인:
  `world_map/line_01.png` 포함
- 추가 이미지 수: 기존 42개에서 43개로 증가

## 보존 및 알려진 사항

- 원본 `source_parts/world_map/line_01.png`은 변경하지 않았다.
- 매니페스트의 좌표 및 블록 오프셋은 변경하지 않았다.
- 이미지 생성 모델 특성상 글자 주변의 지도 질감은 원본과 픽셀 단위로 동일하지 않다.
- ISO 생성 및 패치 적용은 수행하지 않았다.
- 생성하거나 정리할 임시 ROM은 없다.
