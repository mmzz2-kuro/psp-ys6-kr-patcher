# 081. Ys VI 제메스의 성지 석상 메시지 이미지 탐색 결과

## 결론

- 제공된 화면의 일본어 문구는 일반 대사 문자열이 아니라 투명 배경의 이미지다.
- 화면과 정확히 일치하는 리소스는 `v101.dds.z`다.
- 동일 이벤트 계열은 `v100.dds.z`부터 `v108.dds.z`까지 총 9개다.
- 각 리소스는 256×64, PSP DXT3 형식의 단일 이미지다.
- 현재 추가 이미지 매니페스트에는 이 9개가 등록돼 있지 않다.

## 확인된 문구 계열

| 리소스 | 확인 문구 |
|---|---|
| `v100` | `……よくぞ来た……` |
| `v101` | `我が名はアルマ…… / 大いなる《匣》を封印せし者……` |
| `v102` | `我が器、ここに朽ち果てるとも / その魂は子らへと受け継がれん……` |

| `v105` | `剣士よ……心せよ……` |
| `v106` | `……奪われし《黒の鍵》が / 《匣》の蓋を開こうとしている……` |
| `v107` | `……悪しき夢が……甦る前に……` |
| `v108` | 점으로만 구성된 전환 이미지 |

## 원본 위치와 실행 복제본

- 독립 원본: `PSP_GAME/USRDIR/data/image/v100.dds.z` ~ `v108.dds.z`
- 실행 아카이브: `PSP_GAME/USRDIR/data/arc/s_6600.bin`
- `v100`~`v107`은 아카이브 인덱스 143~150에 연속으로 들어 있다.
- 8개 모두 독립 원본과 압축 컨테이너 및 payload가 정확히 일치한다.
- `v108`은 `s_6600.bin`에서 같은 이름의 복제본이 발견되지 않았으며 독립 원본만 존재한다.
- 실제 패치 시 독립 원본과 `s_6600.bin` 내부 복제본을 함께 교체해야 한다. `v108`은 사용 경로를 추가 확인한 뒤 독립 원본 적용 여부를 결정한다.

## 검증 결과

- 기존 번역 작업공간 문자열 검색: 해당 문구 없음
- 원본 `.dds.z` 9개 압축 해제 및 이미지 렌더링: 성공
- 화면 문구와 `v101` 행 배치 및 글자 형태 대조: 일치
- `s_6600.bin` 실행 복제본 탐색: `v100`~`v107` 8개 확인
- 독립 원본과 실행 복제본 해시 비교: 8/8 일치
- 기존 추가 이미지 매니페스트 중복 여부: 중복 없음
- Python 구문 검사: 성공

## 후속 작업 제안

다음 작업에서는 9개 문구의 번역을 확정하고 256×64 투명 이미지로 제작한다. 이후 추가 이미지 매니페스트에 리소스를 등록하고 `s_6600.bin` 실행 복제본까지 교체하도록 패치 경로를 추가한다. 기존 GUI 캐시 갱신 대상에도 포함해야 한다.

## ROM 및 임시 파일

- 원본 ISO와 기존 패치 ISO는 변경하지 않았다.
- 새 테스트 ISO를 생성하지 않았다.
- `tools/patchdata/work/current/image-discovery/zemes-statue-messages`는 동일 조사 결과의 임시 출력이므로 후속 정리 대상이다.
