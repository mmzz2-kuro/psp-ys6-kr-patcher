# Ys VI `.z` 컨테이너 분석 도구 결과

- 완료

## 구현

- Python 비GUI 도구 `/tools/scripts/ys6_z.py`를 작성했다.
- `info`, `decompress`, `scan` 명령을 제공한다.
- 일반 출력과 UTF-8 JSON 출력을 지원한다.
- 기존 출력은 `--overwrite` 없이는 덮어쓰지 않는다.
- Python 표준 라이브러리만 사용한다.

## 확정된 `.z` 구조

| 오프셋 | 크기 | 의미 |
|---:|---:|---|
| `0x00` | 4 | 비압축 데이터 CRC32, little-endian |
| `0x04` | 4 | 비압축 크기, u32 little-endian |
| `0x08` | 가변 | zlib 스트림 |

도구는 zlib 정상 종료, 잔여 데이터, 비압축 크기 및 CRC32를 모두 검사한다.

## 실제 표본 검증

- `title_000.dds.z`: 66,316 → 132,304바이트, 정상
- `talkodo.xso.z`: 633 → 1,116바이트, 정상
- `seltalk.xso.z`: 1,692 → 4,320바이트, 정상
- 세 표본 모두 zlib 스트림이 정상 종료됐고 잔여 바이트는 0이었다.
- `title_000.dds.z` 해제본은 ISO에 함께 포함된 `title_000.dds`와 SHA-256이 일치했다.
- 세 표본의 헤더 첫 4바이트는 해제 데이터의 CRC32와 일치했다.
