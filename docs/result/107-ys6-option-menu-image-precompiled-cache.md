# 107. Ys VI 옵션 메뉴 이미지 사전 컴파일 캐시 전환 결과

상태: 완료

## 수행 내용

- `ys6_option_menu`용 사전 컴파일 캐시 생성·검증 도구를 추가했다.
- 옵션 메뉴 적용 시 일반 사전 검증과 ISO 빌드에서 DXT1 아틀라스를 매번 다시 만들지 않고 검증된 캐시를 사용하도록 통합 빌더를 변경했다.
- GUI의 기존 `이미지 캐시 갱신` 버튼이 옵션 메뉴 캐시와 추가 이미지 캐시를 순서대로 처리하도록 연결했다.
- GUI 상태 문구에서 옵션 메뉴와 추가 이미지 캐시 상태를 함께 확인할 수 있게 했다.

## 캐시 구성

- 경로: `tools/patchdata/ys6_option_menu/precompiled`
- 컨테이너: `static_tex.dds.z`
- manifest: `manifest.json`
- 캐시 identity에 다음 정보를 기록하고 검증한다.
  - 원본 ISO SHA-256
  - 원본 `static_tex.dds.z` SHA-256
  - 원본 해제 payload SHA-256
  - 옵션 메뉴 manifest SHA-256
  - 수정 PNG 9개의 경로, 크기와 SHA-256
  - DXT1·압축 알고리즘 버전
  - 독립 파일과 `init.bin` 내부 할당 크기

## 동작 방식

- 수정 PNG와 모든 identity가 같으면 캐시 컨테이너를 재사용한다.
- PNG, manifest, 원본 또는 알고리즘 버전이 달라지면 옵션 메뉴 캐시를 다시 만든다.
- 새 캐시는 임시 폴더에서 payload 왕복과 할당 크기를 검증한 후 원자적으로 교체된다.
- 실패하면 기존 정상 캐시를 보존한다.
- 캐시가 없거나 오래됐거나 변조됐으면 사전 검증과 빌드를 중단하고 캐시 갱신을 요구한다.
- 옵션 메뉴 적용을 해제하면 캐시 검증과 적용을 건너뛴다.

## GUI 변경

- `이미지 캐시 갱신`을 누르면 다음 순서로 처리한다.
  1. 선택된 경우 옵션 메뉴 캐시 갱신 또는 재사용
  2. 선택된 경우 추가 이미지 49개 캐시 증분 갱신 또는 재사용
- 옵션 메뉴 또는 추가 이미지 중 하나만 선택해도 해당 캐시를 갱신할 수 있다.
- 두 옵션이 모두 해제됐을 때만 캐시 갱신 버튼에서 선택 안내를 표시한다.
- 완료 로그에 옵션 메뉴 재사용·재생성 수와 추가 이미지 재사용·재압축 수를 구분해 표시한다.

## 알려진 사항

- 캐시 상태 검사는 원본 ISO와 내부 원본 파일까지 검증하므로 잘못된 ISO에서는 캐시를 사용할 수 없다.
- 추가 이미지 중 `init.bin/static_tex.dds.z`에 들어가는 리소스가 있으면 해당 최종 컨테이너 압축은 추가 이미지 합성 후 한 번 더 필요하다. 옵션 메뉴 DXT1 조합과 독립 옵션 컨테이너 재압축은 캐시로 생략된다.
- 이번 작업에서는 새 테스트 ISO를 생성하지 않았다.

## 정리 대상

- 원본 ISO와 사용자 수정 PNG는 변경하지 않았다.
- 격리 검증용 옵션 메뉴 작업공간 두 개는 검증 직후 삭제했다.
- 삭제 대상 임시 ROM은 없다.
