# 048. 아이템 가격·능력치 필드 경계 수정 결과

## 결과

아이템 이름 적용 후 상점 가격이 모두 0이 되던 원인을 수정했다. `invinfo.dat` 이름 필드를 52바이트로 잘못 처리한 것이 원인이었으며, 실제 구조에 맞춰 이름 32바이트와 메타데이터 44바이트로 바로잡았다.

원본 ISO와 기존 패치 ISO는 수정하지 않았고 새 ISO도 생성하지 않았다. GUI에서 다음 ISO를 빌드할 때 수정된 패처가 적용된다.

## 최종 레코드 구조

각 레코드는 184바이트다.

| 상대 위치 | 크기 | 용도 |
|---|---:|---|
| `0x00..0x1F` | 32바이트 | 이름 |
| `0x20..0x4B` | 44바이트 | 가격·능력치·리소스 ID 등 메타데이터 |
| `0x4C..0xB7` | 108바이트 | 설명 |

리소스 ID는 44바이트 메타데이터 내부의 상대 위치 `0x34`부터 시작한다.

## 변경 내용

- `tools/scripts/ys6_invinfo.py`
  - `NAME_SIZE`: 52 → 32
  - `METADATA_SIZE`: 24 → 44
  - 리소스 ID 위치를 새 메타데이터 기준으로 수정
  - 이름 교체 시 32바이트만 변경
- `tools/scripts/ys6_item_workspace.py`
  - 이름 제한을 NUL 포함 32바이트로 수정
- `tools/ys6_dialogue_viewer.py`
  - 이름 길이 표시를 `/32`로 수정

아이템 번역 문구와 상태는 변경하지 않았다.
