# 087. Ys VI 제어 키 기능 정지 메시지 이미지 탐색 결과

## 결론

- 제공된 화면과 정확히 일치하는 이미지는 `v140.dds.z`다.
- 화면 문구는 `制御キーの機能停止を確認……`이다.
- 바로 이어지는 `v141.dds.z`도 같은 제어 키 이벤트 메시지다.
- 동일한 화면 중앙 메시지 형식으로 `v150`~`v157` 8개가 추가로 존재한다.
- 총 10개 모두 256×64 투명 PSP DXT3 이미지다.
- 기존 082 패치는 `v100`~`v108`만 대상으로 했기 때문에 이 10개는 등록되지 않았다.

## 누락 원인과 후속 작업

081·082 작업은 제메스의 성지 석상 이벤트에서 발견된 `v100`~`v108` 번호 범위만 조사·적용했다. `v140` 이후 이미지는 같은 표시 형식이지만 서로 다른 후반 이벤트 아카이브에 들어 있어 당시 작업 범위에 포함되지 않았다.

후속 작업에서는 10개 문구의 한국어 번역을 확정하고 256×64 투명 이미지로 제작해야 한다. 추가 이미지 매니페스트에는 독립 원본과 위 실행 복제본을 함께 등록하고, GUI 증분 캐시 갱신 대상으로 포함해야 한다.

## ROM 및 임시 파일

- 원본 ISO와 기존 패치 ISO는 수정하지 않았다.
- 새 테스트 ISO를 생성하지 않았다.
- 이번 단계에서는 번역 이미지와 패치 매니페스트를 변경하지 않았다.
